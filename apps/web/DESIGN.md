# SunUI 設計語言

> 所有 block 都要符合這份文件。新增或重做 block 前先讀完，完成後用最後的檢查表逐項自評。

## 一句話

**紙感電商**：優惠券、收據、集點卡、票根，用黑白灰的實體紙品語言（紙、墨、齒孔、撕邊），做出安靜、一眼認得的電商互動。

## 1. 顏色

只准用下面這幾組。**不准**為了好看加漸層、光暈、模糊、彩色陰影。

| 角色 | Light | Dark | Tailwind 寫法 | 用途 |
|---|---|---|---|---|
| 介面中性色 | shadcn tokens | shadcn tokens | `bg-card` `text-muted-foreground` `border-border` | 一般 UI |
| 主要動作 | 使用者主題的 primary | 同左 | `bg-primary text-primary-foreground` | 主按鈕（尊重買家品牌） |
| 紙 | `#f7f7f7` | `#1c1c1c` | `bg-[#f7f7f7] dark:bg-[#1c1c1c]` | 票券、收據、集點卡的紙面 |
| 紙邊 | `#e2e2e2` | `#333333` | `border-[#e2e2e2] dark:border-[#333333]` | 紙的邊線、虛線 |
| 墨 | `#171717` | `#ededed` | `text-[#171717] dark:text-[#ededed]` | 紙上的印刷字 |
| 品牌專色 | 預設等於 `--primary` | 同左 | `text-[color:var(--sunui-spot,var(--primary))]`，底色配 `--sunui-spot-foreground` | 選中、折扣面額、目前進度、主要按鈕 |

- 紙與墨都是無色偏的中性灰，不用米白、暖灰、stone 色階（2026-11-06 決定：米白配赤陶橘是公認的 AI 生成樣貌，見 `reports/黑白灰視覺去AI感分析-2026-11-06.md`）。
- **品牌專色**（2026-11-08 試做，見 `reports/網站灰階單調診斷-2026-11-08.md`）：SunUI 自己不選顏色。出廠跟著主題的 `--primary`（預設主題下就是墨色），買家在 `:root` 與 `.dark` 設 `--sunui-spot`（和 `--sunui-spot-foreground`）就換成自己的品牌色。只用在「拿掉會遺失資訊」的地方：選中狀態、折扣面額、目前進度、主要按鈕。一般文字、標題、紙邊仍用墨。已改用的 block 列在 `lib/spot.ts`，其餘 block 暫時維持墨色。
- 折扣面額、促銷強調、目前步驟靠字重、尺寸、對比區分；需要區分「目前」與「其他」時，其他項目用淡墨 `#a3a3a3` / `#737373`。
- 成功、錯誤這類狀態色只在小面積文字或圖示上用（`text-emerald-700`、`text-destructive`），不鋪滿底色。
- 不准每個 block 自己挑強調色。多張券的差異用**文字與版面**區分，不用換顏色。

## 2. 材質與形狀

- **紙**：平面、1px 紙邊、無陰影或僅 `shadow-[0_1px_0_rgb(0_0_0/0.04)]`。不准毛玻璃。
- **打孔線**：`border-dashed` 加左右半圓缺口（mask），表示可撕的票根。
- **結果標記**：結果一律用共用元件 `Stamp`（`registry/free/stamp`，block 內 `import { Stamp } from "@/components/ui/stamp"`，registry item 加 `"@sunui/stamp"`）。名稱保留 stamp 以相容舊安裝，但它**不是印章**：直立的一行墨色字，正面結果前面一個勾，失效結果用淡墨。不要自己手刻結果樣式。
  - **放在動作發生的地方**，例如原本按鈕的位置、狀態欄、步驟旁。**不准壓在其他內容上**（不用 `absolute` 疊在券面、價格、進度文字上）。
  - 正面結果用預設 tone；過期、售完、結束、未中獎用 `tone="ink"`，作廢加 `void`（刪除線）。
  - `shape` 只決定附帶資訊：`date` 加印日期，`seal` 加第二行（等級、獎項）；`tick`、`box`、`chop` 只有文字。外觀都一樣。
  - 「推薦」「熱門」這類不是結果的標籤不要用它，改用墨色小標籤。
  - 同一張卡只放一個結果；列表已經說明狀態時，不在每一列重複。
  - **禁用**：傾斜角度、雜訊或墨跡紋理、`mix-blend`、雙框線、大寫加寬字距、朱紅或任何彩色。這些是 2026 年公認的 AI 樣貌（見 `reports/黑白灰視覺去AI感分析-2026-11-06.md`）。
- 圓角：紙品 `rounded-md`（6px）以下；介面按鈕跟隨主題。不用 `rounded-3xl` 大圓角。
- **密度分層**：總覽層（列表、卡片牆、儀表板）保持平面、密、好比較；較重的表現（3D、大圖表、細節動態）只放在使用者主動點開的深入層（抽屜、側邊面板、詳情頁）。兩層之間的標題、數字、配色要延續，讓人知道是同一份資料的深入版；深入層也要保留一個精確的讀法（例如切回平面、懸停顯示確切數值），不能讓表現蓋過資訊。參考：`reports/contribution-skyline 參考分析-2026-11-07.md`。

## 3. 字體

- 數字一律 `tabular-nums`，價格與面額用緊字距 `tracking-tight`。
- 優惠碼、訂單編號用 `font-mono` 加 `tracking-[0.12em]`，像印出來的序號。
- 每個 block 最多一個小字大寫標籤（eyebrow）。
- 中文文案要能直接替換：不靠英文字寬撐版面，標點與中英混排要正常。

## 4. 動畫

只有三種彈簧，直接複製使用：

```ts
const springs = {
  // 按壓回饋、小元件位移
  snappy: { type: "spring", stiffness: 520, damping: 34 },
  // 狀態切換、展開收合
  gentle: { type: "spring", stiffness: 240, damping: 30 },
  // 小元件的回彈，例如徽章數字跳動（名稱沿用 stamp，不再用於印章）
  stamp: { type: "spring", stiffness: 620, damping: 20, mass: 0.8 },
} as const;
```

規則：

1. **只在回應使用者動作或資料狀態改變時動**。不做進場淡入上浮，不做常駐循環（倒數與載入中除外）。
2. **不做慶祝**：結果用 `Stamp` 安靜地出現（150ms 淡入，勾線描出），不做縮放、彈跳、旋轉落下。不放煙火、粒子、彩帶。
3. 單次動畫 400ms 以內；`useReducedMotion()` 為真時改為立即切換，資訊不能遺失。
4. 動畫要模擬實體：撕票根是沿打孔線撕開，不做沒有物理意義的縮放閃爍。
5. **連續性**：狀態改變時讓同一個外框變形（寬高用 `gentle`），不要整塊換掉；跨狀態留一個錨點不動（縮圖、圖示、金額），視線停在錨點上，變化才讀得出是「同一個東西變了」。舊內容約 100ms 退場，新內容主文先到、副文晚約 60ms。單純交叉淡化或硬切都不夠。下拉、抽屜、手風琴還要檢查周圍：下方內容要跟著滑動，不能跳。換視角或換呈現方式時，**同一個幾何貫穿所有狀態**：點還是點，只是長高或躺平，不換成另一種圖形。**多步轉場依序做**：一次只改一個屬性（例如先收高度、再轉視角、最後補標籤），每段各自在 400ms 內，不要同時改三件事。參考做法：`registry/pro/order-island`；形變編排見 `reports/contribution-skyline 參考分析-2026-11-07.md`。

常見動效名稱（Fade Up、Odometer、Headroom、Confetti…）各自的立場與替代做法見 `/docs/motion`，資料在 `content/motion-dictionary.ts`。彈簧與允許的動態已做成 `registry/lib/sunui-motion/motion.ts`（`/r/sunui-motion.json`），新 block 優先從這裡匯入，數值不要另抄一份。

## 5. 示範（demo.tsx）

- 預覽區只放元件本身，排成**真實商店會出現的樣子**（例如活動頁的領券區）。
- 不准在預覽裡放「模擬」「重設」「切換狀態」這類測試按鈕；重播交給網站工具列的 Replay。
- 要展示多種狀態時，直接並排放出不同狀態的實例。
- 文案用真實電商語氣，不編造品牌故事；商品圖用中性實物插圖或留白，不用卡通漸層。

## 6. 程式

- 單一檔案，目標 250 行以內；只暴露真正會調的 props。
- 只依賴 `framer-motion` 與 `cn`；圖示用 inline SVG，線寬 1.5，跟隨 `currentColor`。

- [ ] 沒有進場動畫與常駐循環（倒數、載入除外）
- [ ] 結果用 `Stamp`，放在動作發生的位置，沒有壓在其他內容上；沒有手刻的印章、傾斜或紋理
- [ ] 數字 tabular-nums，代碼 font-mono
- [ ] Light 與 Dark 都截圖看過，375px 不破版
- [ ] reduced motion 下資訊完整

- [ ] 總覽層平面好比較，較重的表現只在點開後的深入層，且深入層有精確讀法

- [ ] 換成中文文案版面仍正常
