# SunUI 設計語言：質感

> 預設系列（`meta.series` 為 `craft` 或省略）的 block 都要符合這份文件。新增或重做 block 前先讀完，完成後用最後的檢查表逐項自評。
> 2026-11-19 起取代舊的「紙感電商」。紙感是對「質感」的誤讀，紙、墨、齒孔、撕邊、印章都不再是 SunUI 的語言。分析見 `reports/拋棄紙感全面改質感深度分析-2026-11-18.md`。
> 網站外殼用同一套語言，數值見 `SITE-MOTION.md` 第 5 節與 `app/globals.css`。

## 一句話

**精密的物件：有材質、有光、有手感。** 中性灰為底，一處品牌色；物件有厚度，光從正上方來，每一下互動都有重量。

質感不是更花，是更準：多出來的是厚度、光線、精度與手感，不是漸層、光暈與裝飾動畫。

## 1. 顏色與材質

block 不寫死色碼，全部讀買家的 shadcn 主題 token，裝進任何主題都成立。

| 角色 | 寫法 | 回退 | 用途 |
|---|---|---|---|
| 表面 | `bg-card` | `--card` | 卡片、券面、面板 |
| 凹面 | `bg-muted` | `--muted` | 輸入框、軌道、未選取格、分段控制底 |
| 邊線 | `border-foreground/10` | 跟主題前景色 | 所有 hairline。用透明度，放在任何底色、圖片上都乾淨 |
| 文字 | `text-foreground`、`text-muted-foreground` | shadcn | 主文與次要文字 |
| 主要動作 | `bg-primary text-primary-foreground` | shadcn | 主按鈕 |
| 品牌專色 | `text-[color:var(--sunui-spot,var(--primary))]`，底色配 `--sunui-spot-foreground` | `--primary` | 選中、折扣面額、目前進度、結果圓片 |
| 語意色：喜歡 | `text-[color:var(--sunui-like,#dc3d43)] dark:text-[color:var(--sunui-like,#ff6b70)]` | 紅 | 收藏、按讚的愛心 |
| 語意色：評分 | `text-[color:var(--sunui-rating,#e8a020)] dark:text-[color:var(--sunui-rating,#f5b84a)]` | 金 | 實心星星 |
| 語意色：成功 | `text-[color:var(--sunui-success,#1f9d55)] dark:text-[color:var(--sunui-success,#4cd68a)]` | 綠 | 完成勾、驗證成功、成功提示 |
| 語意色：危險 | `text-destructive` | shadcn | 錯誤、刪除 |

- 灰是**純中性**，不用米白、暖灰、stone 色階（米白配赤陶橘、米白配鼠尾草綠都是公認的 AI 樣貌，見 `reports/黑白灰視覺去AI感分析-2026-11-06.md`）。
- 不再使用紙感時期的寫死色碼 `#f7f7f7`、`#1c1c1c`、`#e2e2e2`、`#333333`、`#171717`、`#ededed`、`#a3a3a3`、`#737373`。既有 block 依報告 P2 批次改掉，新程式不准再出現。
- **品牌專色**（2026-11-08 起）：SunUI 自己不選顏色。出廠跟著主題的 `--primary`，買家在 `:root` 與 `.dark` 設 `--sunui-spot`（和 `--sunui-spot-foreground`）就換成自己的品牌色。只用在「拿掉會遺失資訊」的地方：選中狀態、折扣面額、目前進度、主要按鈕。一般文字、標題、邊線不用。
- **語意色**（2026-11-22 起）：全世界都認得的意思不跟品牌色走，出廠就是對的顏色，而且只有三個：紅（愛心 `--sunui-like` 與危險共用，`#dc3d43` / 深色 `#ff6b70`）、琥珀（星星 `--sunui-rating`，`#e8a020` / `#f5b84a`）、綠（成功 `--sunui-success`，`#1f9d55` / `#4cd68a`）。危險用主題的 `--destructive`，網站的 `--destructive` 也是同一個紅。買家可以用同名變數覆寫。只給這四種意思用，不要拿來當裝飾色。分析：`reports/為什麼取消黑白後還是黑白深度分析-2026-11-22.md`。
- **內容色**（2026-11-22 起，同日統一）：區塊靜止時也可以有顏色，但只給「內容」用：沒有照片的頭像、分類標籤與圓點、圖表系列。一律用**品牌專色的深淺**（`color-mix(in oklch, var(--sunui-spot, var(--primary)) N%, transparent)`，頭像依名字雜湊挑 12、20、28%；圖表五階），不用另一組色盤，所以買家換品牌色時頭像、圖表一起換。漸層頭像也是同一個色相由淺到深。唯一例外是 `person-chip`：它的用途就是在排班表上分辨不同的人，保留八色相。不要用專色深淺裝飾按鈕、背景或標題。統一的理由與盤點：`reports/色系統一深度分析-2026-11-22.md`。
- **插圖場景的物件本色**（2026-11-22 起）：畫出一個空間或一組物件的插圖場景（例如立體書房間 `popup-store-tour`），填色用**物件本色**，不用品牌專色深淺。色盤固定沿用像素圖示的 `pigments`（`registry/icons/sunui-pixel-icons.tsx`：棕木、綠葉、藍布、粉布、金燈、鋼、骨白、紅點綴），不另開色相。填色以材質角色命名（木、布、植物、玻璃、金屬、燈、點綴、陶瓷），由一張對照表決定實際顏色，與 `var(--card)` 混合（家具 70 到 90%、玻璃約 30%、牆約 16%、地板約 36%），深淺模式都可讀。線條仍是品牌專色，所以換品牌色時插圖的「筆」跟著換。只用在插圖裡，按鈕、標題、背景照舊。原因：只用專色深淺時房間裡分不出材質，使用者看了覺得單調；三套配色並排比較後選了這套。分析：`reports/立體書房間PopupBook深度分析-2026-11-22.md`。
- **整頁模板的例外**（`categories` 含 `template`）：可以有**一段**固定深色的段落（`bg-[#111111] text-[#ededed]`，深淺模式都是深色，字與線用 `currentColor`）製造明暗節奏，通常放在主視覺。不要把品牌專色鋪成整面。
- 折扣面額、促銷強調、目前步驟靠字重、尺寸、對比區分；「其他」項目用 `text-muted-foreground`。
- 成功、錯誤這類狀態色只在小面積文字或圖示上用，不鋪滿底色。不准每個 block 自己挑強調色。

## 2. 光與高度

一頁一個光源，在正上方。物件有厚度，但陰影要近乎看不見。

| 層 | 用在 | 淺色 | 深色 |
|---|---|---|---|
| e0 | 平鋪在表面上的列、分隔 | 只有邊線 | 只有邊線 |
| e1 | 卡片、券、輸入框、次按鈕 | `shadow-[0_0_0_1px_rgb(0_0_0/0.06),0_1px_2px_rgb(0_0_0/0.05)]` | `dark:shadow-[inset_0_1px_0_rgb(255_255_255/0.06),0_0_0_1px_rgb(255_255_255/0.08)]` |
| e2 | 懸停的卡片、下拉、強調的方案卡 | `shadow-[0_0_0_1px_rgb(0_0_0/0.06),0_4px_8px_-4px_rgb(0_0_0/0.06),0_12px_20px_-8px_rgb(0_0_0/0.08)]` | e1 再把表面提亮一階 |
| e3 | 面板、對話框、抽屜 | `shadow-[0_0_0_1px_rgb(0_0_0/0.06),0_16px_32px_-8px_rgb(0_0_0/0.10),0_32px_64px_-16px_rgb(0_0_0/0.10)]` | 同上，加頂邊高光 |

- 陰影**永遠和 1px 邊線一起出現**（上表第一層就是邊線，所以有陰影時不要再加 `border`）。
- 多層、負擴散、不透明度不超過 10%。不准彩色陰影、不准光暈。
- 深色模式不靠投影：表面提亮一階，加頂邊 1px 白色高光。
- **頂邊高光**：凸起的物件（主按鈕、結果圓片、選中的分段格）加 `shadow-[inset_0_1px_0_rgb(255_255_255/0.12)]` 一類的內高光。
- **凹面**：輸入框、開關軌道、進度軌道用凹面色加 `shadow-[inset_0_1px_2px_rgb(0_0_0/0.06)]`，讀起來是凹進去的。
- **模擬光的漸層可以用，裝飾性漸層不行**。允許：一般表面由上而下明度差不超過 3%、同色相；邊緣淡出遮罩（跑馬燈、捲動區兩端）；第 7 節的**材質招牌**（金屬箔、烤漆、金屬框）可以有明顯的明暗，但仍是單一色相、光從正上方來。禁止：藍紫漸層、彩虹漸層、彩色背景漸層。
- **漸層字可以用**（2026-11-22 起，使用者取消黑白灰限制）：一個畫面最多一處，用在標題裡最重要的一個詞或品牌字，兩個相鄰色相（例如青到藍），並留實色回退。不要整句、整段都漸層。
- **毛玻璃**只給浮在內容上的功能層（黏頂列、浮動工具列、彈出層），底色至少 80% 不透明。內容本身（卡片、券、表格）不用。
- 雜訊紋理、墨跡、紙紋：不用。

## 3. 形狀

- **同心圓角**：控制項 6px（`rounded-md`），卡片與券 12px（`rounded-xl`），面板與對話框 16px（`rounded-2xl`），膠囊 `rounded-full`。巢狀時內圓角 = 外圓角 − 內距，例如 12px 卡片內距 4px 的縮圖用 8px。
- 不用 `rounded-3xl` 以上的大圓角當主要外形。
- 分隔用實線 hairline（`divide-foreground/10`）。**虛線不再代表「可撕」**：沒有打孔線、半圓缺口、鋸齒撕邊這類紙品符號，題材是優惠券或取貨券也一樣（2026-11-19 決定）。要表現「揭開」「領取」，用凹面加凸起的蓋板、蓋板浮起移開，或整條滑開，不用撕。收據列印機這類以收據機器為主角的場景例外。
- **密度分層**：總覽層（列表、卡片牆、儀表板）保持安靜、密、好比較，高度最多 e1；較重的表現（3D、大圖表、細節動態）只放在使用者主動點開的深入層（抽屜、側邊面板、詳情頁）。兩層之間的標題、數字、配色要延續，深入層也要保留一個精確的讀法。參考：`reports/contribution-skyline 參考分析-2026-11-07.md`。

## 4. 字

- 不綁字體，跟買家主題。字重用四階：400、500（或可變字重的 510）、600（或 590）、700 以下。
- 字距隨字級收緊：大標 `tracking-tight`，數字面額 `tracking-tight`；中文段落不加負字距。
- 數字一律 `tabular-nums`。
- 優惠碼、訂單編號用 `font-mono` 加 `tracking-[0.12em]`，等寬好核對。
- 每個 block 最多一個小字大寫標籤（eyebrow）。
- 中文文案要能直接替換：不靠英文字寬撐版面，標點與中英混排要正常。

## 5. 手感（動畫）

只有三種彈簧，直接複製使用，或從 `registry/lib/sunui-motion/motion.ts`（`/r/sunui-motion.json`）匯入：

```ts
const springs = {
  // 按壓回饋、小元件位移
  snappy: { type: "spring", stiffness: 520, damping: 34 },
  // 狀態切換、展開收合
  gentle: { type: "spring", stiffness: 240, damping: 30 },
  // 小元件落定一次的回彈：結果圓片、徽章數字（舊名 stamp）
  pop: { type: "spring", stiffness: 620, damping: 20, mass: 0.8 },
} as const;
```

規則：

1. **每個可按的東西都有按下狀態**：`whileTap={{ scale: 0.97 }}` 配 `snappy`，或 CSS 的 `motion-safe:active:scale-[0.97]`（Tailwind v4 寫的是獨立的 `scale` 屬性，不會和 framer-motion 的 transform 打架，過渡清單要含 `scale`）。整張可點的選項卡這類大面積用 0.99。hover 進快退慢（出現 0ms，消失約 150ms）。這是 SunUI 的招牌之一：點過三個 block 就認得同一種重量。
2. **只在回應使用者動作或資料狀態改變時動**。不做裝飾性的進場淡入上浮，不做常駐呼吸、閃爍（倒數與載入中除外）。
   - **浮層落定**：彈出層、下拉、抽屜、面板開啟時可以從 `scale(0.96)` 加淡入進場，200ms 內；抽屜曲線用 `[0.32, 0.72, 0, 1]`。最小縮放 0.93，不從 0 開始。
   - **整頁模板主視覺的例外**：招牌元素可以有一個常駐循環。條件：一頁只有一個；只在進入畫面、分頁可見時播放；reduced motion 固定在第一個畫面；循環本身是內容（輪流展示真實商品），不是裝飾。
3. **結果要有落定的那一下，但不慶祝**：結果一律用共用元件 `Result`（第 6 節），圓片用 `pop` 回彈一次、勾線描出。不放煙火、粒子、彩帶，不做整塊縮放彈跳或旋轉落下。
4. **動畫要有物理**：有質量、慣性、阻尼，跟手的東西用彈簧。不做沒有物理意義的縮放閃爍。陰影本身不做動畫，要變高度就疊兩層切換透明度。
5. 單次動畫 400ms 以內；`useReducedMotion()` 為真時改為立即切換，資訊不能遺失。
6. **連續性**：狀態改變時讓同一個外框變形（寬高用 `gentle`），不要整塊換掉；跨狀態留一個錨點不動（縮圖、圖示、金額）。舊內容約 100ms 退場，新內容主文先到、副文晚約 60ms。單純交叉淡化或硬切都不夠。下拉、抽屜、手風琴還要檢查周圍：下方內容要跟著滑動，不能跳。換視角或換呈現方式時，同一個幾何貫穿所有狀態。多步轉場依序做，一次只改一個屬性，每段各自在 400ms 內。參考做法：`registry/pro/order-island`。

常見動效名稱（Fade Up、Odometer、Headroom、Confetti…）各自的立場與替代做法見 `/docs/motion`，資料在 `content/motion-dictionary.ts`。

## 6. 結果標記 Result

- 共用元件在 `registry/free/stamp`（registry 名稱與檔名維持 `stamp` 以相容舊安裝），block 內 `import { Result } from "@/components/ui/stamp"`，registry item 加 `"@sunui/stamp"`。`Stamp` 是同一個元件的舊名。
- 正面結果：品牌專色小圓片（帶頂邊高光）加勾，加一行字。失效、售完、結束、未中獎用 `tone="muted"`，作廢加 `void`（刪除線）。
- `shape` 只決定附帶資訊：`date` 加日期，`seal` 加第二行（等級、獎項）；`tick`、`box`、`chop` 只有文字。
- **放在動作發生的地方**，例如原本按鈕的位置、狀態欄、步驟旁。不准 `absolute` 疊在券面、價格、進度文字上。
- 同一張卡只放一個結果；列表已經說明狀態時，不在每一列重複。「推薦」「熱門」這類不是結果的標籤不要用它。
- 不要自己手刻結果樣式；不准傾斜、紋理、`mix-blend`、雙框線。

## 7. 招牌

紙感時期的辨識度來自票券形狀。現在的辨識度來自互動品質，每個 block 都要讓人感覺到這三件事：

1. **按壓的重量**：同一組彈簧、同一個 0.97、同一個 hover 節奏。
2. **結果落定**：`Result` 的圓片回彈與勾線、計數滾動、外框變形。
3. **一處品牌色**：只在選中、折扣、進度、結果，換成買家的顏色仍然成立。
4. **靜止時看得見的材質**（2026-11-23 起）：每個 block 至少有一個不用操作就看得到的招牌物件，例如品牌色金屬箔的券面或蓋板、烤漆轉盤加金屬框、有厚度的實體按鍵。只靠按壓手感與落定動畫，在型錄縮圖上看起來和一般 UI 沒有差別。驗收：把卡片縮到 256px 寬、遮住文字，還認得出是 SunUI。分析：`reports/元件為何普通全面深度分析-2026-11-23.md`。

### 材質配方

| 材質 | 寫法 | 用在 |
|---|---|---|
| 金屬箔 | 底色 `var(--sunui-spot, var(--primary))`；疊三層：`linear-gradient(180deg, rgb(255 255 255/0.3), transparent 45%, rgb(0 0 0/0.16))`（光從上方）、`linear-gradient(115deg, transparent 34%, rgb(255 255 255/0.3) 47%, transparent 60%)`（斜向反光，可跟指標移動）、`repeating-linear-gradient(90deg, rgb(255 255 255/0.05) 0 1px, transparent 1px 3px)`（拉絲）；陰影 `inset 0 1px 0 rgb(255 255 255/0.4), inset 0 -1px 0 rgb(0 0 0/0.18)` 加 e1 或 e2 | 券面、蓋板、刮刮卡塗層、獎勵卡、會員卡 |
| 烤漆 | 品牌色，徑向或由上而下由 `color-mix(… 62%, white)` 經品牌色到 `color-mix(… 78%, black)` | 轉盤扇形、大按鍵、圓片 |
| 金屬框 | 前景色與表面色混合，由上 8% 到下 42%，頂邊 1px 白線 | 轉盤外圈、機器外殼、儀表框 |
| 不可用 | 同一配方，底色換成 `color-mix(in oklch, var(--foreground) 14%, var(--card))`（鋼灰），字降為 `foreground/60` | 失效、售完、未解鎖 |

- 材質上的字用 `--sunui-spot-foreground`；放在材質上的次按鈕用表面色加品牌色字。
- 一個 block 一到兩處材質，其餘維持安靜的表面；不要整塊鋪滿。
- 光源固定：會轉、會翻的物件，金屬框與反光不跟著轉。
- 參考實作：`registry/pro/prize-wheel`、`registry/pro/coupon-claim-card`、`registry/pro/scratch-card`、`registry/free/coupon-wallet`。

## 8. 示範（demo.tsx）

- 預覽區只放元件本身，排成**真實產品會出現的樣子**（例如活動頁的領券區、結帳側欄）。
- 不准在預覽裡放「模擬」「重設」「切換狀態」這類測試按鈕；重播交給網站工具列的 Replay。
- 要展示多種狀態時，直接並排放出不同狀態的實例。
- 文案用真實語氣，不編造品牌故事；商品圖用中性實物照片或插圖，不用卡通漸層。

## 9. 程式

- 單一檔案，目標 250 行以內；只暴露真正會調的 props。
- 只依賴 `framer-motion` 與 `cn`；圖示用 inline SVG，線寬 1.5，跟隨 `currentColor`。
