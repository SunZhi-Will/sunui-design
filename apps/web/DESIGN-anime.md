# SunUI 動漫作畫系列（anime）

> **狀態：樣式已定（2026-11-26，使用者在 `/preview/anime-study` 選了 A 墨線硬影）。** 系列還沒有任何上架的 block。
> `lib/agent/guidelines.ts` 與 `lib/registry.ts` 的 `Series` 在第一個 anime block 上架時一起加：現在加會讓型錄與 MCP 多出一個空的系列篩選。
> 規劃與理由：`reports/動漫作畫特效元件深度分析與完整規劃-2026-11-26.md`。
> 方法參考 Sakuga VFX（MIT）的規則；程式、字與樣式都自己做，不移植。
> `meta.series: "anime"` 的 block 遵守這份文件；沒寫到的地方照 `DESIGN.md`（craft）。

## 一句話

**靜止時是普通控制項，一用就像原畫師在演一記打擊。** 特效是這個系列的本體，但每一拍都有紀律。

## 1. 和 craft 不同的地方

| 項目 | craft | anime |
|---|---|---|
| 粒子、爆點、煙、碎片 | 禁止 | 允許，受第 3 節節拍規則限制 |
| 結果 | 落定一下，不慶祝 | 可以有一記打擊，但最後仍落定成勾或 `Result` |
| 外殼 | 1px 邊線、近乎看不見的陰影 | 墨線硬影（見「外殼：墨線硬影」一節） |
| 彩色陰影 | 禁止 | 允許一種：品牌專色淡色的硬投影，這是系列招牌 |
| 擬聲字 | 無 | 一次反應最多一個，在打擊那一格 |

其他照 craft：顏色、字、三種彈簧、reduced motion、鍵盤。

## 2. 顏色（不開新色相）

- 特效亮面：白色，深淺模式都一樣；陰影面：品牌專色 24% 混白；外框：品牌專色。深色模式試過亮面用 `--card`，特效變成一個個深色的洞，亮面與陰影面也分不出來（2026-11-26 影格表）。
- 點綴楔形：語意紅 `--sunui-like`。評分用 `--sunui-rating`，成功勾用 `--sunui-success`。
- 擬聲字：墨色 `#141414` 加白邊，深淺模式都一樣（漫畫字本來就是黑白的）。
- 不用原作的紫加粉紅。換品牌色時特效的線條一起換。

## 外殼：墨線硬影

靜止時的招牌，256px 驗收靠它：

- 外框 `border-[3px] border-foreground`，圓角 14px（勾選框 8px、開關與進度條全圓）。
- 硬投影 `shadow-[4px_5px_0_color-mix(in_oklch,var(--sunui-spot,var(--primary))_38%,var(--card))]`：不模糊、不擴散，只有這一種。
- 底色 `bg-card`；開啟的開關、進度填色用品牌專色。
- 控制項上的字：斜體、800 字重（`italic font-extrabold`）；旁邊的標籤 700。
- 次要按鈕同樣的墨線，但沒有硬投影，按下只有小壓扁與三道楔形。
- 打擊那一格（約 180ms）整顆反白：底 `--foreground`、字 `--background`、拿掉投影。

## 3. 動態規則

1. **控制項先是控制項**：特效全關時仍是完整的原生元素或正確 ARIA，鍵盤、焦點、表單都可用。
2. **一個反應拆成四拍**：預備（按下）、打擊（狀態改變那一格）、餘韻（飄走的東西）、落定。每拍一到兩個特效，不是五個。
3. **狀態立刻改變**，特效只是裝飾。要讀的資訊不能靠特效。
4. **雙色加一條線**：每個畫出來的形狀是亮面、陰影面、外框，沒有漸層、沒有模糊。
5. **靠縮小或變細離場**，不改透明度。
6. **壓扁保持體積**：變矮就變寬，拉長就變細。
7. **跟手用彈簧**，拉伸來自速度：慢拖安靜，快拖才有拖影與雲。
8. **大特效放在放手、落地、狀態改變的那一刻。**
9. **靜止時沒有任何動畫**，也不畫任何東西。
10. **特效不蓋住標籤**：擬聲字放在控制項上方或標籤右邊，不壓在字上。
11. **reduced motion**：所有畫布特效關閉，彈簧與狀態變化保留。
12. **中文輸入法組字中**（`compositionstart` 到 `compositionend`）不觸發輸入框特效。

## 4. 擬聲字

六個語意槽位，依語系切換：介面是中文就用中文字，其他語系用日文（2026-11-26 預設，使用者可改）。

| 槽位 | ja | zh-TW | zh-CN |
|---|---|---|---|
| 衝擊 | ドン! | 砰! | 砰! |
| 點擊 | カチッ | 喀! | 咔! |
| 咻 | シュッ | 咻! | 咻! |
| 彈出 | ポン | 啵! | 啵! |
| 滑停 | ズザッ | 唰! | 唰! |
| 轟鳴 | ゴゴゴ | 轟轟 | 轰轰 |

- 字型只用 SIL OFL 授權的開源字型，轉成路徑放進引擎，不依賴字型下載；OFL 聲明附在引擎檔頭。
- 字樣依槽位固定（2026-11-26 預設，照 A 樣張）：衝擊、咻、彈出用實心（墨字白邊）；點擊用空心（白字墨邊）；滑停、轟鳴用網點。
- 日文字型 Dela Gothic One，中文 Noto Sans TC／SC 900（都是 SIL OFL）。
- 邊寬是字級的 5%：中文筆畫多，邊太粗會把字裡的空隙填滿。
- 中文網點字小於 48px 時引擎自動改用實心：網點小到比筆畫還粗就讀不出來。
- 擬聲字約是控制項高度的 2 倍（主按鈕的衝擊字 92px），放在控制項上方或標籤右邊。
- 落地大一號、彈簧回到原尺寸、待著時微晃、最後縮小離場。

## 5. 引擎

- 單一全頁 `position: fixed` 畫布，第一個用到時建立，沒有特效時停迴圈；需要畫在控制項後面的特效用元件內的背景畫布。
- 一個共用時鐘，所有延遲都走它（不用 `setTimeout`），所以能停住時間一格一格截圖驗收：`node apps/web/scripts/anime-frames.mjs`。
- 從控制項中心炸出的東西（碎片）改從外緣往外飛，或放在後面的層，才不會蓋到標籤。
- 已知限制要寫進每個 block 的 `meta.usage.watchOut`：畫布在最上層，特效會飛過 modal；背景特效會被 `overflow: hidden` 切掉。

## 6. 驗收

- [ ] 每個反應都看過影格表（打擊格、餘韻、離場），不是只看即時播放
- [ ] 擬聲字與特效沒有蓋到標籤
- [ ] 鍵盤完整、能進 `<form>`、375px 沒有橫向捲動
- [ ] 換 `--sunui-spot` 後特效線條一起換；深淺模式都看過
