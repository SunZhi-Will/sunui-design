## 二、別人怎麼做（切換與尺寸）

**Preview / Code 切換**：shadcn、Tailark、Aceternity、React Bits 都是工具列最左邊的分段控制（軌道 p-1，按鈕高 24 到 28px），預設 Preview。Animate UI v2 反過來，不做切換，預覽在上、程式碼在下並收合。

**尺寸切換**：
- 全部用圖示 radio group（桌機、平板、手機）。
- 寬度兩派：shadcn 用百分比（100 / 60 / 30%），React Bits 與 HyperUI 用固定 px（768 / 375，HyperUI 再加 340 / 640 / 1024）。電商區塊用固定 px 比較誠實。
- 拖曳把手：shadcn、Tailark、React Bits 都有，最窄 320px。React Bits 有寬度數字、雙擊重設、方向鍵微調（10 / 50px）、Home / End。
- 寬度變化加 300ms 過渡（HyperUI 用 `transition-[max-width]`）。

**預覽高度**：
- shadcn 固定高度（預設 930px，各 block 可覆寫）。
- Tailark 量每個 block 的高度寫進 `--iframe-height`，lg 以下退回固定 504 / 1040px。
- Magic UI、Motion Primitives、Animate UI 用 `min-h` 350 到 450px，隨內容長高。
- 我們是量內容加 64px 留白、最低 448px，屬於 Tailark 這一派，方向正確。

**其他控制**：重播一律是換 key 重掛 iframe；「新分頁開啟 / 全螢幕」幾乎每家都有；主題切換只放在網站層級，沒有人放在預覽裡。

**型錄格子**：Aceternity 1 / 2 / 3 欄（1800px 以上 4 欄），靜態圖卡；Origin 4 欄類別卡加數量；Tailark 只掛載畫面上的 iframe（8 個只掛 2 個）。即時 iframe 卡片牆只有我們在做，所以載入前的佔位特別重要。

## 三、這次已完成的改動

1. **卡片佔位**：淺色主題先顯示 `/og/blocks/<name>.jpg`（用 next/image 縮到卡片寬），深色主題顯示緩慢呼吸的骨架；iframe 淡入後佔位淡出。159 個區塊有分享圖，效果庫的單一樣式卡不套（分享圖畫的是整個庫）。
2. **手機篩選列**：sm 以下每一排改成橫向捲動的一列，隱藏捲軸、左右貼邊；sm 以上照舊換行。第一張卡回到首屏。系列說明移到篩選列下方獨立一行。
3. **區塊頁預覽工具列**：
   - 尺寸改成圖示分段控制，提示文字帶寬度（平板 · 768px）。
   - 工具列一直顯示實際寬度（例如 1182px）。
   - iframe 右緣加拖曳把手，最窄 320px，拖動時 iframe 不吃指標事件、不加過渡；雙擊回到預設寬度；方向鍵 16px、Shift 64px、Home 最窄、End 重設。手機寬不顯示把手。
   - 重播改成圖示，新增「在新分頁開啟」。
4. **展開面板**：標題列加同一組尺寸切換，平板與手機寬時兩側是斜線底紋，和區塊頁一致。
5. **開場**：標題上方加一行小字（有紙感的 React 電商區塊），指令下方加「瀏覽區塊 194 ↓」錨點連結。刻意不加按鈕列，維持開場只有一句話的份量。

新增文案（四語）：`preview.openTab`、`preview.resize`、`preview.width`。

## 四、建議的下一步（未做）

1. **開場紙牆瘦身**：只有前兩列用 eager，其他 lazy；文字提早到 1.2 秒出現（現在約 2.7 秒）。效益最大的一項。
2. **篩選列黏頂**：搜尋與方案那一排 `sticky top-14`，系列與互動收進一個「篩選」按鈕的彈出層，桌機只剩一排。
3. **區塊頁 Preview / Code 切換**：工具列最左邊加分段控制，切到 Code 直接在原位顯示原始碼，CLI 指令放工具列右側（Tailark 的排法）。
4. **寬度數字的短暫強調**：拖曳時在把手旁浮出寬度，放開 2 秒後淡掉（React Bits）。
5. **型錄卡片 hover 動作**：右上角除了展開，再加「複製安裝指令」（Origin）。
