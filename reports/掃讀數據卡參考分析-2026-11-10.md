## 2. 為什麼好用

1. **一張卡就能讀任何一天**。總覽卡通常只給一個大數字，想看某天要點進完整圖表。這裡沿著圖滑過去就讀到了，總覽層不用多開一層。
2. **痕跡告訴你剛剛經過哪裡**。掃過的柱子亮起又淡掉，眼睛可以比較「這幾天」和「游標下這一天」，比只亮一根多一層資訊，又不會常駐干擾。
3. **環的懸停有方向感**。刻度從游標處往兩側擴散，看得出這一段是從哪裡開始、範圍多大，比整段同時變色更容易對應到圖例。
4. **好數字配上讓它誠實的數字**。營收的背面是支出、觸及的背面是退追蹤。這個配對對商店很有用：營收旁邊就是退款，訪客旁邊就是放棄的購物車。

## 3. 不能照抄的地方

| 參考的做法 | 我們的規範 | 我們的版本 |
|---|---|---|
| 綠光、紅光漸層卡片底 | DESIGN.md 第 1 節：不准漸層、光暈 | 卡片是 `bg-card` 加一般邊框，平面 |
| 亮起的部分用白色、背面整片用紅色 | 狀態色只用在小面積；強調只用品牌專色 | 亮起與預設標出的那根用 `--sunui-spot`（預設等於主題 primary）；只有變化小標用綠色或紅色字 |
| 數字換值時模糊 | 不用模糊 | 舊字往上離開、新字從下方進來，逐字從個位數開始錯開，沒變的字不動 |
| 翻面是整張卡往後倒、內容淡出再長出來 | 第 4 節第 5 條：同一個外框變形、留錨點、同一個幾何貫穿所有狀態 | 外框不動，箭頭是錨點（轉 90 度）；同一組細柱、長條、刻度直接長到新數值（gentle 彈簧，由左往右錯開，總共 0.24 秒）；標題、副標、數字捲動換上，副文晚 60ms |
| 刻度約 100 根、細柱約 60 根 | 卡片寬 300px 以內要清楚 | 環 84 根，細柱建議 14 到 40 根 |
| 深色主題 | Light 與 Dark 都要成立 | 兩種都做，靜止的柱子用 `#d4d4d4 / #3d3d3d` |

## 4. 我們的版本：scrub-stat-card

### 4.1 API

- `kind`：`stems`（每日）、`bars`（每月）、`ring`（佔比）。
- `sides`：一面或兩面。每面有 `title`、`subtitle`、`delta`、`tone`、`values`、`highlight`、`center`、`stats`、`axis`、`format`。
- `tone` 讓數字上升可以是壞事：退款增加傳 `"bad"`，小標就用紅色；放棄原因減少傳 `"good"`。參考影片裡只看正負號，這在商店裡會出錯。
- `side / defaultSide / onSideChange` 受控與非受控都可以。

### 4.2 技術拆解

| 效果 | 做法 |
|---|---|
| 痕跡 | 每根一個熱度值。游標所在那根設為 1，其他每幀乘上 `exp(-dt / 0.32)`，低於 0.02 歸零；所有痕跡都退掉時停掉 requestAnimationFrame，游標停住時不會一直重畫。快速掃過時中間跳過的柱子也補亮，痕跡不會斷 |
| 亮起的樣子 | 每根畫兩層：靜止色一層、品牌專色一層，專色層的不透明度等於熱度；細柱再往上抬 3px、頂點放大。這些每幀都在變，直接寫 SVG 屬性，不交給彈簧（交給彈簧會每幀開一個新動畫） |
| 數值標籤 | 跟著游標那根移動（snappy 彈簧），數字逐字捲動 |
| 環的分段 | 依數值分配 84 根刻度，每段開頭空一根當縫；百分比用最大餘數法加總剛好 100 |
| 環的懸停 | 依游標角度找到刻度、再找到所屬的段；該段刻度伸長 7px 並換成專色，延遲依和游標那根的距離計算（每根 8ms，上限 0.22 秒），所以是從游標處往兩側擴散。其他段降到 45% |
| 翻面時環的變形 | 段的縫會移到新位置，刻度的透明度依序沿著環改變（每根延遲 k/84 × 0.2 秒），看起來像縫順著環滑過去 |

### 4.3 無障礙與鍵盤

- 細柱、長條圖可以聚焦，左右方向鍵逐點移動，Escape 清除；`aria-live` 念出「11/14：977」。
- 環的圖例是按鈕，聚焦或懸停就選取那一段，念出段名與百分比。
- 翻面鈕的 `aria-label` 是「切換到退款」這類完整說法；變化小標附上「增加 / 減少」給螢幕閱讀器。
- 觸控：`touch-pan-y`，手指橫著滑讀數字，直著滑仍然捲動頁面。
- 減少動態效果：痕跡只剩目前那根，柱子與刻度直接跳到新值，數字直接換，資訊完整。

### 4.4 示範

「本月店況」：訪客（每日細柱）翻到放棄的購物車、流量來源（環）翻到購物車被留下的原因、營收（每月長條）翻到退款。四種語言，數字用 `Intl` 依語系格式化。型錄卡片只放訪客那張。

## 5. 為什麼放 Pro

免費型錄 2026-11-06 起凍結。依四項測試：可替代性中低（圖表庫有 tooltip，但沒有會淡掉的掃讀痕跡與同幾何翻面）、自己做要處理痕跡衰減、環的分段與 hydration 精度、翻面的編排；直接用在賣家後台與會員頁；展示價值高。歸 Pro。

## 6. 網站展示版（preview.tsx）的範圍

展示版只亮游標下那一根、環亮起那一段、翻面直接換數字。痕跡、刻度依序伸長、逐字捲動、翻面變形、方向鍵讀值與 aria-live 只在授權版，展示版底下的說明文字寫了差異。
