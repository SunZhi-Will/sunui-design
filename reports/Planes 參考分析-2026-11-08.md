# Planes（useplanes.com）參考分析與實作

> 2026-11-08。來源：使用者給的網址 https://useplanes.com/ 。用 Chrome 實際瀏覽首頁、元件總覽、元件詳情頁（Receipt Printer），並讀 `llms.txt`。
>
> 標記：【已驗證】實際看到的頁面或資料；【推論】由資料推導；【建議】行動提案。遵守免費目錄凍結（不新增免費 block 與動效庫），只參考概念與字彙，不抄程式碼、文案與視覺。

## 0. 結論先講

1. **Planes 是 SunUI 目前最直接的競品，而且它的價格比我們低。** shadcn registry、React + Tailwind + Motion、MCP 與 llms.txt、一次買斷，這些全部和 SunUI 一樣；但它是 **US$99 買 180 個元件（170 Pro）**，SunUI 是 **US$129 買 72 個 Pro**【已驗證】。用「數量 / 價格」比，SunUI 會輸，不能在這個軸上比。
2. **它沒有電商與檔期。** 180 個元件分成 AI、WebGL、Media、Carousels、Controls、Physics、Text、Sections、Charts、Heroes、Navbars、Logins、Footers、Templates，沒有一個分類是購物、促銷或檔期【已驗證】。8 家競品分析的結論（電商檔期是空白）在 Planes 上依然成立。
3. **但有一批 SunUI 的 Pro 和它正面撞名。** Receipt Printer、Scratch Card、File Dropzone、FAQ、Testimonial Wall、Pricing Table、Email Capture 兩邊都有【已驗證】。這些是 SunUI 型錄排序裡的 C、D 組（通用元件），在 Planes 那邊是 $99 套組裡的一小部分。這批東西不能當 Pro 的賣點，Pro 的價值要繼續押在 A、B 組（整頁場景與獨有互動）。
4. **最值得學的是它的「價格說服」而不是元件。** 首頁一整段在處理「為什麼值 $99」：大標「比你一小時的工資還少」、終身卡視覺（Member since 2026 / Valid thru ∞）、「不到一個月的 Claude Max」錨點、30 天 22,000 人造訪的社會證明、以及**可拉動的省時計算機**。SunUI 價格頁目前只有三張方案卡與 FAQ【已驗證】，這段完全缺。
5. **本次實作兩件事**：(a) 價格頁加上以 agency 語言計算的「省下多少」計算機（8 家分析的 I3，Planes 再次證實這是標配）；(b) 從 Planes 的 Swipe Card Deck 字彙出發，做一個有電商邏輯的 Pro 場景 `swipe-shortlist`（滑卡挑品：右滑收藏、左滑略過、往上直接加入購物袋，最後落在一張可結帳的清單上）。

## 3. 元件詳情頁【已驗證】

以 Receipt Printer 為例：

- 左側是全部元件的捲動清單（分類標題 + 每一項），目前這項有色線標示。
- 中間只放大預覽，標題旁一個「Pro」小標。
- **底部一條浮動工具列**：側欄開關、logo、⌘K 搜尋、`@useplanes/receipt-printer` 安裝名稱與複製、「Copy prompt」下拉、桌機 / 平板 / 手機三種寬度、重播、全螢幕、主題切換。
- 預覽下方依序是：Installation（四種套件管理器分頁；Pro 標示需要授權，下方一張「Unlock with Planes Pro: $99 once · 170 Pro components · lifetime updates」卡）、Usage / Props 分頁（一段 import 與 JSX 範例）、**Use cases**（四個情境，每個一行標題加一句說明，例如「Checkout success pages: A tactile receipt moment after payment completes」）、Related components。

對照 SunUI 區塊頁【已驗證】：寬度切換、重播、品牌色樣本、何時用 / 注意 / 別名、複製給 agent、Pro 安裝步驟、相關區塊，**全部已經有**。SunUI 少的是全螢幕與底部浮動工具列，但這兩件對轉換沒有直接幫助，不列入。

【推論】Planes 的 Pro 頁會顯示 Usage 的 JSX 範例（只露 props 名稱，不露實作）。SunUI 的 Pro 頁目前不顯示 props，這是 `reports/` 裡 Pro 防蒸餾分析的決定，維持不變。

## 5. 價格：要不要跟著降到 $99？

【已驗證】SunUI 現價：Founding $79（11/27 開賣，150 席）、Pro $129、Team $349（5 人）。Planes：$99 終身，標「限時早鳥價」。8 家分析的價格帶是 $179 到 249。

【推論】Planes 的 $99 是早鳥價，而且它賣的是「數量」。SunUI 若降到 $99，就是接受在數量軸上競爭，但 72 對 170 怎麼比都輸。SunUI 的錨點應該是「一檔活動頁外包的成本」：一個 agency 做一頁黑五活動頁，設計加前端至少兩到三個工作天。

【建議】**不降價。** 改做三件事：

1. 價格頁加計算機，用「一年幾檔活動 × 每檔幾天 × 日薪」把 $129 換算成省下的錢（本次已做）。
2. Founding $79 開賣期間，在首頁頂端放一條常駐公告（參考 Planes 的波浪公告條，但用 SunUI 的紙邊齒孔語言），寫明「$79 終身，限 150 席，1/12 截止」。$79 剛好比 Planes 的 $99 低，是現成的反擊。11/27 開賣前做，見第 8 節。
3. 價格頁 Pro 卡下加一句錨點，用買家熟悉的東西比較。Planes 用「不到一個月 Claude Max」；SunUI 對 agency 應該是「不到一天的外包費」。這句已經包含在計算機的結論裡，不另外加。

價格與 Founding 規則的任何調整都要你決定，本次沒有改 `lib/site.ts`。

## 7. 本次實作 2：Pro 場景 `swipe-shortlist`【已完成】

### 7.1 為什麼是這個

Planes 的 Swipe Card Deck 只是「一疊可以滑走的卡」。四項測試（`reports/免費與付費切分規劃-2026-11-05.md`）：

| 測試 | 結果 |
|---|---|
| 可替代性 | 一般 swipe deck 到處都有；但「三個方向各有購物語意 + 結束時是一張可結帳的清單 + 復原」沒有現成的 |
| 自己寫要多久 | 拖曳物理、三向判定、復原堆疊、清單收合與鍵盤操作，約 1.5 到 2 天 |
| 離營收距離 | 直接：新品挑選、禮物推薦、風格測驗後的「加入購物袋」 |
| 展示價值 | 高：一眼看得懂、自動播放很好看 |

SunUI 現有的 swipe 都是相簿或通知（product-media、toast-stack、hero-billboard-carousel），沒有「用滑動做購物決定」的 block【已驗證，搜尋 registry 的 swipe / fling / throw】。

### 7.2 行為

- 一疊商品卡（4:5 照片、名稱、價格、一句說明），最上面一張可拖。
- 往右超過門檻（或速度夠快）是**收藏**、往左是**略過**、往上是**直接加入購物袋**；拖動中卡片依方向旋轉，卡角浮出對應的墨色小標籤（收藏 / 略過 / 加入購物袋），透明度跟拖動距離走。
- 鬆手沒過門檻就用 `snappy` 彈簧回位；過門檻就沿拖動方向飛出。
- 底部三顆按鈕做同一件事，另有「復原」把上一張收回來（卡片從它飛走的方向回到最上面）。
- 鍵盤：卡片可聚焦，← 略過、→ 收藏、↑ 加入購物袋、Backspace 復原。
- 全部滑完，卡疊的位置收成一張**清單**：已加入購物袋與收藏分兩段，每列縮圖、名稱、價格；收藏那列可以一鍵「加入購物袋」；底部是購物袋小計與「前往結帳」。購物袋那段的結果用 `Stamp`（放在小計旁，不壓內容）。
- 進度：卡疊上方寫「還剩 4 件」，清單狀態改成「選了 3 件」，數字用 tabular-nums。
- 清單底部的「再看一次略過的 N 件」把略過的商品重新發成一疊。
- 回呼：`onDecide(item, "save" | "skip" | "bag")`、`onUndo(item)`、`onCheckout(bagItems)`。
- reduced motion：卡片不旋轉不飛行，直接換下一張；清單直接出現。

### 7.3 設計對照

- 卡面是紙（`#f7f7f7` / `#1c1c1c`、1px 紙邊、`rounded-md`），沒有陰影、漸層、光暈。
- 方向小標籤是墨色文字加 1px 框，沒有綠色紅色；「加入購物袋」與選中狀態用品牌專色 `--sunui-spot`。
- 後面兩張卡只露出上緣（縮小與下移），不做常駐晃動。
- 示範用已追蹤在 repo 裡的產品照：檯燈、托特包、馬克杯、瓶子、外套、T 恤。

### 7.4 檔案

- `registry/pro/swipe-shortlist/swipe-shortlist.tsx`：交付給客戶的完整元件（授權後由 `/r/pro/swipe-shortlist` 發放）。
- `registry/pro/swipe-shortlist/demo.tsx`：完整 demo。
- `registry/pro/swipe-shortlist/preview.tsx`：網站展示版（寫死資料，不 import 元件本體）。
- `registry/pro/registry.json`、`registry/pro/i18n/swipe-shortlist.json`、`lib/catalog-order.ts`（B 組）。
