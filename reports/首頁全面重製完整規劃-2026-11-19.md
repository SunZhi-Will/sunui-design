# 首頁全面重製：完整規劃

2026-11-19。範圍是整個首頁（`apps/web/app/(site)/page.tsx` 與它用到的元件）。這份是規劃，還沒有動程式。需要你決定的三件事在第 7 節。

> 2026-11-19 更正：規劃裡的「暖琥珀重點色」做出來後被否決（全站是黑白灰，金色按鈕不和諧），已全部拿掉。下面提到重點色、琥珀色、色溫滑桿的地方都不再適用：首頁只用黑白灰，色溫那一格改成只有明暗的亮度滑桿。

## 1. 先講結論

前幾版一直在「同一個版面上加效果」：換字體、加陰影、把紙牆換成展示台、再加自動游標。版面本身沒有變，所以怎麼加都怪。這次要改的是三件更根本的事：

1. **首頁不是型錄。** 現在標題下面直接接 194 張卡片和一排篩選器，讀起來是工具或文件站。同類網站的首頁都是一頁「說服你」的敘事，完整型錄在另一頁。
2. **首頁上出現的東西要專門為首頁做。** 現在是把型錄裡的區塊原樣塞進框裡，風格不一（有紙感的、有星雲黑底的、有很小的按鈕），撐不起首頁。
3. **要有品牌的樣子。** 全站黑白灰、沒有任何一個屬於 SunUI 的顏色，也沒有主要按鈕，看不出是在賣設計。

## 2. 現在的首頁哪裡怪（逐段）

| 區段 | 問題 |
|---|---|
| 開場文字 | 沒有任何按鈕。主要動作是一行指令（還顯示 localhost 網址）和一個小小的「瀏覽區塊」文字連結。訪客不知道下一步 |
| 展示台 | 一個巨大的框佔滿寬度、向後仰、被螢幕下緣切掉一半；上面有分頁列、狀態列、「打開」按鈕，像開發工具的面板。自己會動的游標讓人搞不清楚是誰在操作 |
| 框裡的區塊 | 六個區塊六種風格。景深主視覺是灰底大字，玻璃方塊是黑底星雲，日夜主視覺有票券按鈕。放在一起像六個不同的產品 |
| 型錄 | 緊接在開場後面，一口氣 194 張即時預覽加四個篩選器。這是「找東西」的介面，不是「第一次來」的介面 |
| 比較示範、agent 步驟、為什麼、Pro | 排在 194 張卡片後面，幾乎沒人捲得到。三張「為什麼」是純文字卡片，Pro 區塊是一個黑框 |
| 整體 | 區段之間沒有節奏，每一段都是白底、同樣寬、同樣的灰字。沒有重點色，沒有深淺對比 |

## 3. 同類網站怎麼做（實際打開看過）

| 網站 | 開場 | 值得學的 |
|---|---|---|
| [Aceternity UI](https://ui.aceternity.com) | 深色。左邊標題、說明、兩個按鈕、使用者頭像與星等；右邊一整面成品頁面截圖往外延伸 | 文字和視覺左右分開，各自清楚。下面接品牌牆，再接「複製貼上，或交給你的 AI agent」 |
| [React Bits](https://reactbits.dev) | 深色。左上標題加兩個按鈕，下面一張招牌視覺，上面浮著程式碼、終端機、預設值三個小面板 | 一張招牌圖講完「這是可以調的動態元件」。下面是「What's inside」三張帶小動畫的卡片 |
| [Magic UI](https://magicui.design) | 淺色、置中。公告小標、兩行標題、兩個按鈕、技術圖示一排；往下是 Showcase 與推文牆 | 淺色也能成立，靠的是一個重點色和很大的留白 |
| [Linear](https://linear.app) | 深色。左對齊兩行大標題，一句說明，產品視窗從下方露出、邊緣融進背景 | 產品畫面是平的、清楚的，不傾斜、不自己動 |
| [Motion Primitives](https://motion-primitives.com) | 深色、置中。標題、兩個按鈕，下面一個深色框裡放一個做得很精緻的元件 | 只展示一個元件，但那個元件本身夠好 |
| [Animate UI](https://animate-ui.com) | 深色、置中。標題字有模糊進場，指令框在按鈕上面 | 下一段標題是「Every primitive, alive」：一格一格的小元件各自在動 |
| [Untitled UI React](https://www.untitledui.com/react) | 淺色、置中。圖示、標題、三個按鈕，下面兩張產品視窗 | 重點色紫色只用在一個按鈕上 |

共同點有六個：

1. 開場一定有**兩個按鈕**（主要：瀏覽元件；次要：GitHub、文件或購買）。
2. 標題下面一定有**一句人話說明**（多少個元件、用什麼技術、怎麼安裝）。
3. 多數是**深色**。動效和顏色在深色底上比較跳。
4. 都有**一個**品牌重點色，只用在少數地方。
5. 首頁是**敘事**：開場、裡面有什麼、成品展示、怎麼安裝或交給 agent、別人怎麼說、價格。完整型錄在 `/components` 這類頁面。
6. 開場視覺是**為首頁設計的構圖**，不是把型錄的第一張卡片放大。

SunUI 目前六點都沒做到。

## 4. 新的方向

一句話：**深色的舞台，一個暖色，東西自己在動但不搶你的滑鼠。**

- **調性**：首頁預設深色（仍可切淺色）。底色近黑，層次靠 1px 細線和頂邊高光，這套 tokens 已經有了。
- **重點色**：SunUI 的「Sun」。一個暖琥珀色，只用在主要按鈕、標題裡的一個詞、和動效裡「結果落定」的那一下。其餘維持黑白灰。不用紫色、不用漸層光暈，這仍然是和其他 AI 樣貌網站的差別。
- **字**：標題再大一級、行距更緊；中文標題改兩行固定斷句。說明文字一句，放大到 18px。
- **動效原則**：只留一招，但換一招。不要游標、不要傾斜、不要自動換頁。改成「一桌子的小物件各自活著」：每個小元件用很慢的節奏重複自己最好的那一個動作，滑鼠移上去就停下來讓你自己玩。

## 5. 新首頁的結構（由上到下）

### 5.1 頁首
維持現在的結構。右側加一個主要按鈕「取得 Pro」（重點色），GitHub 與語言維持次要。

### 5.2 開場
- 左邊（桌機佔 5/12）：
  - 小標籤：創始會員 11/27 開賣（取代頁面最上方那條橫幅，少一層）。
  - 標題兩行：少一點閃爍，多一點**手感**。（「手感」用重點色）
  - 說明一句：194 個有動效的 React 區塊，shadcn 一行安裝，或直接交給你的 coding agent。
  - 兩個按鈕：**瀏覽區塊**（主要）、**看 Pro 場景**（次要）。
  - 按鈕下面才是安裝指令（顯示正式網域，不是 localhost），當作第三層資訊。
- 右邊（7/12）：**活的標本桌**。六到七個專門為首頁做的小元件，大小不一，排成不規則但對齊格線的一組，全部同一套深色質感。每個自己慢慢重複一個動作：
  - 加入購物車按鈕：按下、變成勾、數字加一。
  - 數字滾動：價格從原價滾到折扣價。
  - 開關：切換時把手有重量。
  - 色溫滑桿：把手來回，旁邊的燈跟著變暖變冷（這是唯一有顏色的一格）。
  - 訂單通知：從小膠囊展開成一張卡再收回。
  - 步驟進度：三步依序打勾。
  - 評分星星：依序點亮。
  - 滑鼠移到哪一格，那一格就停止自動播放、交給你操作；移開幾秒後繼續。
- 這些是網站自己的元件（放在 `components/home/`），不進 registry，所以不違反免費型錄凍結。每一格右下角有小字連到對應的正式區塊。

### 5.3 相容性一排
shadcn CLI、Next.js、Tailwind v4、Motion、Claude Code、Cursor（MCP）。灰階標誌一排，不要動畫。

### 5.4 裡面有什麼
四張卡片，每張上半是一個小的即時示範，下半是數字和一句話：區塊 194、動效庫 28（各有多種樣式）、圖示、Pro 場景。點了到對應的篩選結果。

### 5.5 Pro 場景展示（旗艦）
整段比其他段更寬。標題「店面與活動頁，整頁做好」。一排大張的場景卡（六個最好的），平常顯示靜態畫面，滑鼠移上去才載入即時預覽。這裡用真的區塊，但只挑已經重做成質感風格的；還沒重做的不上首頁。

## 6. 怎麼做（分階段）

## 7. 需要你決定的三件事

1. **首頁預設深色**可以嗎？（建議：可以。同類網站多數如此，動效在深色上比較好看。淺色照樣能切。）
2. **重點色用暖琥珀色**可以嗎？（建議：可以，跟「Sun」的名字對得上，也避開所有人都在用的紫與藍。如果你有品牌色，直接給我色碼。）
3. **完整型錄搬到 `/blocks`，首頁只放 9 張精選**可以嗎？（建議：可以。這是讓首頁不再像文件站的最大一步。）

## 8. 風險

- **時間**：A 到 E 是一次完整的首頁重做，比前幾次都大。創始會員 11/27 開賣，如果時間不夠，A、B、5.5、5.9 先上，其餘沿用舊區段。
- **標本桌的品質決定成敗**：七個小元件要做到每一個都禁得起細看。寧可先做四個做好。
- **Pro 場景還是舊畫風**：5.5 需要已經重做過的場景。重做進度不夠時，這一段先放三個。
- **搬型錄影響舊連結與 SEO**：需要轉址，並確認 `llms.txt` 與 MCP 回傳的網址不受影響。
- **我看的是各站的首屏與往下一段**，不是完整逐頁研究；各站的內部實作沒有驗證。
