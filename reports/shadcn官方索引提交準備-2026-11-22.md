# shadcn 官方索引提交準備

日期：2026-11-22。依據〈為什麼建立在shadcn上-深度分析-2026-11-22〉第 7 節第 1 項。這份是送出前的全部準備，**PR 還沒開**，要使用者決定時機。

## 1. 收錄條件與 SunUI 現況

條件來自 [Registry Directory](https://ui.shadcn.com/docs/registry/registry-index)（2026-11-22 讀取）。

| 條件 | SunUI | 驗證方式 |
|---|---|---|
| 開源、公開 | 通過：GitHub repo 公開，MIT | `gh repo view` |
| registry.json 符合 schema | 通過 | 用官方 `registry.json` schema 驗證 `/r/registry.json` |
| 扁平結構：`/registry.json` 與 `/<name>.json` 在同一層 | 通過：都在 `/r/` 底下 | 實際請求 |
| `files` 不含 `content` | 通過：111 個 item 都沒有 | 檢查 `/r/registry.json` |
| 命名空間沒被用掉 | 通過：593 個裡沒有 `@sunui` | 官方 `directory.json` |
| 目錄條目格式（`validate:registries`） | 通過 | 用官方的 zod 規則驗證本條目加上現有 593 筆 |

## 2. 上線後的健康分數會看什麼

條件來自 [Registry Health](https://ui.shadcn.com/docs/registry/health)。分數影響目錄排序，同分時項目多的排前面。

| 項目 | 分數 | SunUI 預檢 |
|---|---:|---|
| 可用性（7 天、30 天） | 45 | Vercel 靜態產生，`/r/` 為 force-static |
| 正確性（索引與抽樣 item 符合 schema） | 25 | 111 個 item 全部用官方 `registry-item.json` schema 驗證通過 |
| 可安裝（`shadcn add --dry-run`） | 20 | 在乾淨的測試專案用 shadcn CLI 4.23.0 抽 13 個 dry-run，13 個通過（含依賴 `stamp` 的 item） |
| 設定（HTTPS、JSON 回應、item 名稱不重複、registry 名稱相符） | 10 | HTTPS、`content-type: application/json`、名稱不重複、`name` 為 `sunui` 與命名空間相符 |

`@sunui/stamp` 這類 SunUI 內部依賴，在發佈的 item 裡已經改寫成完整網址，所以沒設命名空間的人也裝得起來。

## 3. 這次修的地方

- `apps/web/registry.json` 的 `homepage` 從 GitHub 改成網站 `https://sunui.synvize.com`，跟目錄條目一致。**要部署後才會生效。**

## 4. 要加進 `apps/v4/registry/directory.json` 的條目

加在陣列最後（現有檔案沒有嚴格排序，最後一筆是新近加入的）：

```json
{
  "name": "@sunui",
  "homepage": "https://sunui.synvize.com",
  "url": "https://sunui.synvize.com/r/{name}.json",
  "description": "Animated React and Tailwind blocks built with craft: real springs, a pressed state on everything, quiet layered shadows. Product pages, campaigns, feedback, navigation and free motion libraries under MIT, with Pro scenes behind a license key.",
  "logo": "<svg xmlns='http://www.w3.org/2000/svg' viewBox='0 0 24 24' fill='var(--foreground)' stroke='var(--foreground)' stroke-width='2' stroke-linecap='round'><circle cx='12' cy='12' r='5' stroke='none'/><path fill='none' d='M12 1.5v2.5M12 20v2.5M1.5 12H4M20 12h2.5M4.6 4.6l1.8 1.8M17.6 17.6l1.8 1.8M4.6 19.4l1.8-1.8M17.6 6.4l1.8-1.8'/></svg>"
}
```

- logo 是網站 favicon（`app/icon.svg`）的太陽，改成單色並用 `var(--foreground)`，跟其他條目一樣能跟著深淺色。
- `author` 是選填，目前沒填。要不要放名字或 GitHub 帳號由使用者決定。

## 5. PR 內容草稿

**標題**：`feat(registry): add @sunui`

**內文**：

```
Adds @sunui to the registry directory.

SunUI is an open source (MIT) registry of animated React and Tailwind blocks: product pages,
campaigns, feedback, navigation and motion libraries. Items read the shadcn theme tokens, depend
only on framer-motion and utils, and are flat at https://sunui.synvize.com/r/{name}.json.

Checked before submitting:
- pnpm validate:registries passes with the new entry
- /r/registry.json and all items validate against the registry and registry-item schemas
- files in /r/registry.json have no content
- shadcn add --dry-run passes on a sample of items in a clean project

Homepage: https://sunui.synvize.com
Source: https://github.com/SunZhi-Will/sunui-design
```

## 6. 送出步驟

1. **先部署**，讓 `homepage` 修正與 11-22 恢復的三個區塊上線。
2. fork `shadcn-ui/ui`，在 `apps/v4/registry/directory.json` 最後加入第 4 節的條目。
3. 在 `apps/v4` 執行 `pnpm install` 與 `pnpm validate:registries`。
4. 開 PR 到 `shadcn-ui/ui` 的 `main`，標題與內文用第 5 節。
5. 合併後立即生效；健康監測會先「觀察」24 小時，再給出狀態。
