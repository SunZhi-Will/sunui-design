# 全像券化成粒子飛進總額：參考分析與實作

來源：X 貼文 AetherMaker（Mehran），2026-11-20，「i like this even more in light mode」。一支 2.8 秒、2160×2160 的手機錄影，206 讚、107 收藏（收藏數接近讚數的一半，代表大家是存起來要抄的）。

## 1. 逐格拆解（30fps，共 83 格）

| 時間 | 畫面 | 手法 |
|---|---|---|
| 0.0 到 0.7 秒 | 「Add coupon」頁，中間一張全像券 MOCHI70 / 70%，下方「Already in your saved coupons.」與黑色「Apply to order」按鈕 | 券面是厚的果凍感全像材質：粉、紫、青的油膜色，邊緣有一圈亮的厚度高光；券慢慢往上漂，表面光澤隨角度流動 |
| 0.7 到 1.0 秒 | 手指按下按鈕 | 按鈕內容淡出，寬度收成一顆圓（載入中的圓） |
| 1.0 到 1.4 秒 | 券從左到右化掉 | 掃描線從左往右走，走過的地方券面裂成幾千顆小點，點的顏色就是券面那一處的顏色；右側 70% 最後才化 |
| 1.4 到 1.7 秒 | 整頁交叉換到結帳頁（配送、付款、摘要） | 粒子雲沒有消失，浮在新頁面上 |
| 1.7 到 2.2 秒 | 粒子拉成一條彎曲的流，從右上往左下灌進底部的總額 | 路徑是一條往右鼓再往左下收的曲線，像被吸進去；尾端有幾顆十字星 |
| 2.2 到 2.4 秒 | 底部總額左邊出現一張迷你券 MOCHI70 70% | 粒子在目標處重組成同一張券的縮小版 |
| 2.4 到 2.8 秒 | 摘要多一行「Coupon - MOCHI70  -£93.80」，Total 與底部總額 £134.00 滾到 £40.20，下方綠字「You save £93.80」 | 每一位數字各自垂直滾動，滾動時有動態模糊；兩處總額同步滾 |

## 2. 為什麼好看（拆成可以抄的原則）

1. **同一個物件從頭走到尾**。券沒有被「關掉」再「出現一個折扣列」，而是券本身的物質被搬到總額旁邊。使用者不用讀字就知道「券用掉了，錢變少了」。這跟 `DESIGN.md` 第 5 節第 6 條「連續性：同一個幾何貫穿所有狀態」是同一件事，只是做得更徹底。
2. **因果順序清楚**：按鈕回饋 → 券化掉 → 流向目的地 → 落地重組 → 數字才開始滾。每一段只改一件事，時間點錯開。
3. **粒子顏色取自券面**。不是另外撒彩色亮片，是券「拆開」的樣子，所以不像慶祝特效。
4. **數字滾動帶模糊**。數字是錢，滾動讓人看見「從多少變成多少」；模糊讓滾動有速度感，結束時一格一格停穩。
5. **淺色模式比深色好看**（作者自己說的）：全像材質在白底上是柔和的油膜色，在黑底上會變成霓虹感。

## 3. 和 SunUI 規則的衝突與取捨

| 參考的做法 | SunUI 規則 | 決定 |
|---|---|---|
| 粉紫青全像漸層 | `DESIGN.md` 禁止兩種色相以上的漸層、藍紫漸層 | 預設改成**銀箔**（中性灰的金屬箔，光澤跟游標走）。全像當成選項 `finish="holo"`，買家自己決定要不要。demo 兩種並排給你比 |
| 粒子 | 禁止「彩帶煙火粒子」 | 這裡的粒子不是慶祝，是券的物質搬家，符合連續性原則。限制：顏色只取券面、只在套用的那一次、reduced motion 完全不出現。這是對規則的解讀，若不接受，可改成券整張縮小飛過去（同一條路徑，不拆成點） |
| 券的半圓缺口 | 不准打孔線、缺口（2026-11-19） | 拿掉缺口，用厚邊高光表現果凍厚度，面額用一條 hairline 分隔 |
| 換頁到結帳頁 | 網頁沒有換頁 | 改成**同一張結帳摘要卡**：券在上方，總額在下方，粒子在卡內飛。網頁上更常見（結帳側欄），也更連續 |
| 粒子十字星 | 裝飾 | 不做 |
| 綠字 You save | 狀態色只用在小面積文字 | 保留，小字 |
| 套用後 | 結果用 `Result` 放在動作發生處 | 券的位置收合成一行 `Result`「MOCHI70 已套用」 |

## 4. 定位：Pro 場景，不是免費 block

- 免費型錄凍結到 2027-01-12（`free-catalog-freeze`）。
- 四項測試：可替代性低（沒有人免費給「券化粒子飛進總額 + 數字滾動」這組），自己做要 1 到 2 天（粒子取樣、遮罩掃描、路徑、滾動數字、狀態機、錯誤重試），離營收近（結帳轉換的主角就是折扣），demo 價值高（這支影片 107 收藏）。
- 名稱 `coupon-apply`，`registry/pro/coupon-apply/`。和既有的分工：`coupon-claim-card` 是「領券」，`peel-sticker-coupon` 是「拿到券」，`coupon-apply` 是「把券用掉」。三個剛好是一張券的一生，之後可以組成一個 campaign 場景。

## 5. 實作規格

- 狀態：`idle` → `applying`（按鈕收成圓、等伺服器）→ `dissolving`（遮罩從左往右掃，掃過處生粒子）→ `landed`（七成粒子到達，迷你券用 pop 彈出）→ `done`（折扣列展開、券區收成 `Result`、總額滾動、You save 出現）。失敗回到可重試，按鈕寫「再試一次」。
- 粒子：canvas 疊在卡片上，每 3px 一顆，約 2000 到 3000 顆。出生時間依 x 座標（掃描線），先往上微飄 120ms，再沿二次貝茲曲線（控制點在右側，做出往右鼓的弧）飛 520 到 720ms，到達前淡出。一個 RAF 同時驅動遮罩和粒子，結束就停。
- 折扣由 `onApply(code)` 回傳，**金額由伺服器決定**，元件不自己算百分比。
- 數字：`Intl.NumberFormat` 依 locale 與幣別格式化，每位數字一欄 0 到 9 用 `gentle` 彈簧滾，右到左錯開 30ms，滾動時模糊 1.5px。
- reduced motion：沒有粒子、沒有滾動，券直接換成 `Result`，總額直接換新值，資訊一樣完整。
- 無障礙：polite live region 播報「已套用 MOCHI70，省下 £93.80，新總額 £40.20」。
- 每段動畫各自在 400ms 左右；整段從按下到滾完約 1.6 秒（伺服器回應時間另計）。

## 6. 變化（2026-11-22 追加）

使用者要求「製作更多變化」。在同一個 block 上加兩個維度（demo 後來依使用者要求只放一張，預設 sweep 加銀箔，其他用 props 切換）：

| effect | 拆開方式 | 飛行路徑 | 遮罩 |
|---|---|---|---|
| `sweep`（預設） | 掃描線由左到右 | 共用往右鼓的控制點，匯成一條彎流 | 90 度線性 |
| `burst` | 從中心往外一圈圈散開，先往外推 14 到 40px | 控制點在中點加大幅亂數，像一群飛過去 | 中心放射 |
| `sand` | 由上往下崩，先受重力往下掉 | 控制點貼著目標高度，掉下來再橫滑進去 | 180 度線性 |
| `pixel` | 券直接換成 5px 方塊，隨機順序離開 | 低弧線，位置吸附 4px 格線，一格一格跳 | 不用遮罩，畫布重畫整張券 |

| finish | 材質 | 粒子顏色 |
|---|---|---|
| `silver`（預設） | 中性灰金屬箔 | 灰階 |
| `spot` | 買家品牌色（`--sunui-spot`，回退 `--primary`）混白 | 同色三階明度，執行時解析 color-mix |
| `graphite` | 深色煙燻箔，白字 | 深灰階 |
| `holo` | 全像油膜，多色相，選用 | 只用券面的青、藍紫、淡紫、粉 |

`spot` 是最符合 `DESIGN.md` 的一款（一處品牌色）；沒設品牌色時跟著 `--primary`，預設主題下會是灰。

另外同日依使用者要求「高度要固定」：券區從 168px 縮到 140px，剛好讓出折扣列的 28px，兩者用同一條彈簧同時變化，卡片高度與總計列位置全程不動。
