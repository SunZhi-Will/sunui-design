# 側邊欄開關不要跳、動態分頁：深度分析與實作（2026-11-22）

來源：Threads @diegohaz（Ariakit 共同創辦人）的串文，標題 "Stop making your sidebar toggle jump around. App shell UI design in detail. Dynamic tabs and collapsible sidebar."，影片 40 秒，720×900，發文 12 小時約 2 萬次瀏覽、340 讚。以下是逐格看完影片後的整理。

## 1. 影片在講什麼（逐段）

畫面是一個筆記 app 的外框：左上一顆側邊欄開關，旁邊是品牌「Notes」，右邊是一排可關閉的分頁（Trip、Ideas、+）。下半部是放大鏡頭，標出尺寸並以 0.1 倍速重播。

| 時間 | 內容 | 重點 |
|---|---|---|
| 0 到 8 秒 | 收合與展開側邊欄 | 開關一直在最左上；品牌「Notes」從側邊欄移進分頁列的最前面，第一個分頁跟著往左滑 |
| 1、5、32、38 秒 | 放大分頁和內容面板的接縫 | 選中的分頁跟內容面板是一個形狀：兩側各一個 14px 的反向圓角，面板左上角也是 14px，三個圓角半徑一致 |
| 3、35 秒 | 只看面板左上角 | 側邊欄展開時面板左上角是 14px 圓角，計時條約 250 到 285ms 完成，代表整個收合動作約 0.25 秒 |
| 11 秒 | 反例一 | 開關放在側邊欄標題列右側，收合後跑到內容區，游標要移動 192px |
| 14 秒 | 反例二 | 開關在分頁列裡，分頁數量一變，位置跟著變，同樣 192px |
| 17 秒 | 正解 | 標示「0 px」：不論展開或收合，開關都在同一點 |
| 20 到 26 秒 | 分頁溢出 | 分頁太多時出現左右箭頭，邊緣淡出；+ 永遠留在最右 |
| 23、29 秒 | 滑過與切換 | 未選中分頁滑過時出現淡底色塊，分頁間的分隔線在選中或滑過的分頁兩側消失；切換時選中形狀滑到新分頁 |

作者在第二則補充：他正在做一套「給 agent 重用的設計規則與程式配方」，年底推出。

## 2. 拆成可以照做的設計規則

1. **開關錨定**：會反覆按的開關，位置不能因為它造成的狀態改變而改變。按完立刻再按一次（後悔、來回比較）是最常見的操作，位置一變，第二下就按空。
2. **一顆按鈕，不是兩顆**：展開與收合是同一個控制項，用 `aria-expanded` 表示狀態，圖示原地交叉淡入。兩顆按鈕輪流出現，對螢幕閱讀器也是兩個不同的東西。
3. **會移動的是內容，不是控制**：收合時讓品牌、分頁這些「內容」讓位或搬家，開關本身不動。
4. **圓角半徑統一**：分頁的反向圓角、面板圓角用同一個半徑，接縫才看起來是一塊。
5. **分頁的細節**：分隔線在選中或滑過的分頁兩側隱藏；溢出時給箭頭加淡出，新增鍵固定在最右。

## 3. 對照 SunUI 現況

| 規則 | SunUI 現況 | 結論 |
|---|---|---|
| 開關錨定 | `app-shell` 正是影片反例一：收合鍵在側邊欄標題列右側（約 x=200），收合後換成另一顆「展開」鍵出現在內容區左上（約 x=64），游標要移約 140px，而且是兩顆不同的按鈕 | **有問題，已修** |
| 一顆按鈕 | 同上，兩顆按鈕輪流用 `aria-hidden` 藏起來 | **已修** |
| 選中分頁接面板、反向圓角 | `sliding-tabs` 的 `folder` 樣式已經有（選中分頁與面板同一形狀，兩側反向圓角，指示器會滑動） | 已具備 |
| 可關閉、可新增、溢出箭頭的動態分頁 | 沒有。`sliding-tabs` 是固定選項的切換器，不是瀏覽器式分頁管理 | 缺口，見第 5 節 |
| 品牌搬進分頁列 | 沒有（`app-shell` 沒有分頁列） | 跟動態分頁一起處理 |

## 4. 這次的實作

改了 `apps/web/registry/free/app-shell/app-shell.tsx` 的桌面側邊欄：

- 標題列改成「開關、品牌」的順序。開關在最左，跟下方導覽圖示同一條中線；收合成圖示欄時，開關剛好落在圖示欄正中，位置完全不變。
- 只留一顆按鈕：`aria-expanded` 隨狀態切換，`aria-label` 在「收合側邊欄」與「展開側邊欄」間切換，⌘B 提示保留，兩個圖示原地交叉淡入（150ms，減少動態時直接切換）。
- 刪掉原本掛在內容區左上的第二顆「展開」鍵。
- 品牌（logo 與名稱）跟其他文字一起淡出，收合時不可聚焦。
- 重截了 `public/og/blocks/app-shell.jpg`。

驗證：在本機預覽頁量測，收合前後開關都在 (394, 111)，是同一個 DOM 節點，`aria-expanded` 從 true 變 false。`tsc --noEmit` 通過。

取捨：收合成圖示欄時看不到品牌 logo 了。圖示欄最上方現在是開關，身分由下面的工作區切換器提供（有傳 `workspace` 時）。這跟影片做法一致，也跟 Linear、Notion 收合後的樣子接近。若要在圖示欄保留 logo，可以把 logo 放到開關下一列，但那會讓導覽整體下移一列，這次不做。

## 5. 還沒做的：動態分頁

免費型錄凍結到 2027-01-12，動態分頁是新元件，不能直接加成免費 block。建議路線：

1. **做成 Pro 場景**（建議）：「工作區分頁」放在 product 系列，把影片裡全部細節做齊：可關閉與新增、拖曳排序、溢出箭頭與邊緣淡出、分隔線規則、選中形狀滑動、側邊欄收合時品牌搬進分頁列、開關錨定。它通過四項測試裡的「單一免費元件組不出來」：需要 `app-shell` 與分頁列彼此協調。
2. PH 上線後若要釋出免費原子，可以從這個 Pro 場景抽出「可關閉分頁列」，或讓 `sliding-tabs` 的 `folder` 加上 `onClose`、`onAdd`。
