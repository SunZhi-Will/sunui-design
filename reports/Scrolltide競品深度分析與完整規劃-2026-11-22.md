# Scrolltide 競品深度分析與完整規劃（2026-11-22）

對象：https://www.scrolltide.co/
方法：用 Chrome 以 1512px 寬實際打開，逐段捲動截圖，量字型、動效曲線、影片載入方式，並走過首頁、模板詳情、/templates、/free、/pricing、/mcp、/why-scrolltide、/components、/shaders、/ebook。
截圖：`reports/scrolltide-截圖-2026-11-22/`（01 到 10 是對方，11 是 SunUI 目前首屏）。

---

## 一、一句話結論

Scrolltide 好看的原因不是網站外框，而是**外框極度克制、內容極度飽滿**：深色、幾乎單色的殼，裡面塞滿一百多支全彩、各有美術方向的循環影片。首頁就是一份「型錄試吃盤」，六個帶狀區塊，每塊同一個公式。這正好就是我們 11-20 記下的方向（「首頁不要發明，把標準展示做整齊，用挑過的真區塊」），Scrolltide 是這條路做到位的樣子。

但它賣的是 **prompt**（貼進 Claude 讓 AI 重新生成），SunUI 賣的是**已經寫好、裝了就一樣的程式碼**。這是我們最大的差異點，規劃要「版面學它，定位反著打」。

## 二、它是什麼產品

| 項目 | 內容 |
|---|---|
| 賣什麼 | 「Build prompt」：一段很長、很具體的提示詞，貼進 Claude / Cursor / v0 生成整頁或單一元件。標榜也附完整原始碼 |
| 數量 | 模板 154（8 個免費）、元件 122、Shader 背景 55、Sections（footer、pricing、CTA 等）、UI 後台畫面 14 |
| 節奏 | 「Fresh drops every Friday」，每週約 8 個新的 |
| 社會證明 | 13,500+ builders，頭像疊、五星評語 |
| 其他產品 | MCP 伺服器（Yearly / Lifetime 才有，每 24 小時最多 40 個）、電子書《Prompt to Motion》$49、接案（「The Studio」） |
| 價格 | Monthly $39（原 $59，每週只能複製 10 個，不含 3D / UI / Shader / MCP）；Yearly $144（$12/月）；Lifetime $299（原 $449，標「Most Popular」） |
| 急迫感 | 頂部漸層橫幅「EARLY ACCESS · Lifetime $299 · 01:25:21 left · Claim」倒數計時 |

觀察：Monthly 被刻意做殘（限量、缺 3D），唯一作用是把人推去 Yearly 和 Lifetime。Lifetime 是被設計成主力的那一張。

## 三、視覺系統（看圖，不是看文字結構）

### 3.1 外框
- 底色接近純黑，卡片底是再淺一階的黑，邊框是 1px 半透明白。整站幾乎只有黑白灰。
- **唯一的顏色**：標題最後一個字「tide.」的青到藍漸層，和頂部倒數橫幅。顏色只出現在品牌字和促銷，其他地方的顏色全部來自內容（影片）。
- 這和我們「網站只用黑白灰」的規則是同一件事。差別是：我們的卡片內容也偏灰，他們的卡片內容是全彩照片、3D、插畫。**殼單色、內容彩色**才是對的組合。

### 3.2 字型三件組
| 用途 | 字型 | 寫法 |
|---|---|---|
| 大標 | Bricolage Grotesque，粗，字距收緊 | 首屏約 64px，兩行 |
| 內文 | Inter | 灰色，行高寬 |
| 眉標、數字標籤 | Space Mono，全大寫，字距拉開，小字 | 「154 TEMPLATES IN THE LIBRARY」「FRESH DROPS EVERY FRIDAY」「THE WORKFLOW 01 / 03」 |

等寬小字眉標是它「有質感」的關鍵之一：每個區塊上方都有一行，帶一個真實數字。

### 3.3 首屏（截圖 01）
- 全寬 canvas：左邊暖橘霧、右邊冷藍霧，散著慢慢閃的星點。標題置中。
- 一顆小膠囊「● FRESH DROPS EVERY FRIDAY →」，兩顆按鈕（白實心 + 黑描邊），頭像疊 + 人數，再一顆「Why Scrolltide? 3 min 35 sec watch」影片膠囊。
- 首屏底部一條技術跑馬燈（REACT ✦ NEXT.JS ✦ GSAP ✦ THREE.JS ...），等寬字。
- 首屏沒有任何產品畫面。產品從第二屏才開始，而且一出來就是滿滿一格。

### 3.4 每個帶狀區塊同一個公式（截圖 02 到 04）
```
[等寬眉標：N XXX IN THE LIBRARY]
[H2 左]                              [一段說明 右，灰字]
[篩選膠囊：All / Button / 3D / ...]  [Featured / Popular / Recent 切換]
[三欄格，卡片 16:10，間距一致]
[Browse all N → 按鈕]
```
六個帶狀：模板「The library, at a glance」、元件「One piece at a time」、Shader「Motion behind everything」、Sections「Build a page a band at a time」、UI「The screen behind the landing page」、流程「Copy, paste, launch.」。
每個 H2 都是一句有畫面的話，不是分類名。

### 3.5 卡片（截圖 10）
- 卡片本體：圓角約 12px，裡面是**循環靜音 MP4**（Cloudflare R2），`preload="none"` + poster 圖，捲進畫面才播。首頁共 109 支影片、0 個 iframe、只有 1 個 canvas（首屏）。
- 卡片下方：左邊名稱（一個有畫面的單字：Aerie、Solano、Perch、Murk）+ 灰色分類；右邊「Premium」描邊小標。
- Hover：影片放大，0.7s `cubic-bezier(0.22, 1, 0.36, 1)`；左下淡入「Preview →」膠囊（0.35s）。我們的 `EASE_SITE` 是 `[0.23, 1, 0.32, 1]`，幾乎一樣，曲線不用改。
- 格子裡混一張**非產品卡**：「THE STUDIO · Want a one-of-a-kind site built for you? Start a project →」，深色、等寬眉標，和產品卡同尺寸。

### 3.6 收尾（截圖 05）
- 三步驟卡（01 Pick / 02 Paste / 03 Launch），卡片背景有巨大淡色數字。
- 一排四個數字：154 / 8 / 13,500+ / 100%，第一個數字用品牌漸層。
- 「Ride the tide.」+ 訂閱電子報。
- Footer 底部一個佔滿寬度、極淡的巨大「scrolltide」字。

## 四、其他頁面

### 4.1 模板詳情頁（截圖 06）
麵包屑 → 兩顆標籤（3D Website / Premium）→ 大標 → **一支大影片佔滿內容寬** → 左邊一段像影評的描述（「一部以水晶白頭鷹為主角的捲動電影，從雲海爬到黃金時刻再到夜晚……」），右邊 Stack 標籤（threejs、lenis、scroll ...）→ 付費提示 → 「More 3D website templates」。
**描述寫的是故事和畫面，不是功能清單**，這是它每張卡都讓人想點的原因。

### 4.2 /templates、/free、/components、/shaders
都是「SEO 長文開頭 + 格子」：先兩三段真的在講道理的文字（「Hero 是每個訪客都會看到的唯一一塊……大部分都浪費了」），再接卡片，每張卡下面多一段描述。標題直接是搜尋關鍵字：「Animated hero section templates」「Free hero section templates」。
/shaders 說明每個背景給三種格式：MP4、靜態圖（拿去當 OG 圖）、React 元件（單檔、無依賴、離開畫面自動暫停）。

### 4.3 /why-scrolltide（截圖 08、09）
整站唯一換風格的頁：**米白底 + 襯線斜體大標**，一封長銷售信。開頭直接把買家心裡的反對意見當標題：
「Why would I pay for a prompt when I can just ask Claude to build it myself?」
接著：一個假的對話視窗，自動打出 14 輪「再高級一點」「為什麼全部都是紫色」的修改要求（重現痛點）→ 左右對照「空白對話 vs 我們的 build prompt」→ 五步驟 → 對照表（從空白開始 vs 從模板開始）→ 評語牆 → 價格 → FAQ。底部一條固定的小 CTA 列「Start from a design, not a blank chat. From $39」。
這頁是它的轉換主力，每個頁面的「Why Scrolltide? 3 min 35 sec」膠囊都指向這裡。

### 4.4 /mcp
大標「The design library your AI was missing.」→ 一排模板影片跑馬燈 → 四步驟安裝：選工具（Claude Code / Cursor / Codex / VS Code / Claude app / Other 分頁）→ 一行指令 + Copy → 瀏覽器登入按 Approve（OAuth，不用貼 API key）→ 完成。下面「Good to know」四格：每次請求都驗證方案、每日上限、唯讀、只限 Yearly/Lifetime。

### 4.5 /pricing（截圖 07）
三張深色卡並排，劃線原價 + 折扣標，Lifetime 卡帶暖色光暈。功能列表用打勾 / 打叉，Monthly 那張一排叉。下面一段把公平使用規則講得非常清楚（免費的不算、重開不算、每週重置、頁面上看得到剩幾個）。

## 六、不能照抄的地方（跟既有決定衝突）

1. ~~品牌漸層字「tide.」違反黑白灰規則~~：2026-11-22 使用者決定全面取消黑白灰限制，漸層字可以用（一個畫面一處、標題裡一個詞），規則已寫進 `DESIGN.md` 第 2 節。
2. **新增 Shader 免費類別**：免費型錄凍結到 2027-01-12。要做只能做 Pro（例如「Pro 背景包」，跟 Pro 圖示包同一個邏輯）。
3. **賣 prompt**：不跟。我們的定位反過來打。
4. **假評語、假人數**：它的 13,500+ 和評語我們無法驗證，我們沒有就不放，用真的數字（區塊數、動效庫數、裝過的次數若有統計）。
5. **電子書、接案**：現在不做，時間給 Pro 場景和上線。接案卡的「格子裡混一張非產品卡」手法可以拿來放「創始會員」或「Pro 場景」。

## 七、完整規劃

原則：版面學 Scrolltide，定位反著打。距 Product Hunt（2027-01-12）約七週。

### 階段 0：先拍板的三件事（本週）
1. **格子卡片改用循環影片嗎？** 建議：是。型錄與首頁的卡片用錄好的 MP4（poster + `preload="none"` + 進畫面才播 + hover 放大），詳情頁和「在這裡直接試」維持即時元件。這會推翻目前文案「這些是元件正在跑，不是影片」，那句改放在詳情頁。需要一支錄影腳本（Playwright 錄每個區塊 demo 6 到 8 秒循環）。
2. **主打句要不要正面對打 prompt 庫？** 建議主軸：「不是 prompt，是寫好的程式碼。裝了就跟你看到的一樣。」
3. **價格要不要調？** 建議：Monthly 做成「入門」（只含免費以外的一部分，或每週上限），把 Lifetime 標成主力；金額先不動，等創始會員結束再評估。這件事和 `訂閱自動續扣實作計畫-2026-11-20.md` 一起改。

### 階段 1：首頁改成「帶狀型錄」（第 1 到 2 週）
把現在八種長相的段落，收斂成同一個公式的帶狀，順序：
1. 首屏：保留 point-cloud。下方加等寬眉標膠囊（例如「每週一個新 Pro 場景」），加一條技術跑馬燈（React、Next.js、Tailwind、Motion、shadcn、Three.js）。
2. 帶狀「Pro 場景」：最搶眼的放第一，三欄影片卡，混一張創始會員卡。
3. 帶狀「區塊」：篩選膠囊（Hero、商品、導覽、圖表、主題切換……）。
4. 帶狀「動效庫」：28 套，對應它的 Shaders 段。
5. 帶狀「圖示」：對應它的 UI 段，用 /icons 的牆。
6. 帶狀「三步驟」：01 找區塊 / 02 一行指令或叫 agent / 03 上線。下方一排四個真實數字。
7. 收尾：一句話 + 等候名單。Footer 加滿寬淡色「SunUI」大字。

每個帶狀固定：等寬眉標（帶數字）→ 左 H2（一句有畫面的話）右說明 → 篩選膠囊 → 三欄 16:10 卡 → 「看全部 N 個 →」。
二十微互動牆、差在哪裡、agent 段：移到 /why 頁（見階段 3），首頁不再放。
字型：大標換成有個性的 grotesque（候選 Bricolage Grotesque、或現有字型加粗收字距），眉標加一套等寬字。改字型前做並排比較頁。

### 階段 2：卡片與詳情頁（第 2 到 3 週）
- 卡片：16:10、圓角一致、下方名稱 + 分類 + Free / Pro 小標；hover 用 `EASE_SITE` 0.7s 放大 + 「預覽 →」膠囊。
- **卡片內容要有顏色**：每個 demo 檢查縮到卡片大小時有沒有照片、插畫或大塊明暗；太灰的先不放首頁。
- 詳情頁：大預覽佔滿內容寬（即時元件）→ 左邊影評式描述、右邊技術標籤 + 安裝指令 → 「同類還有」。
- 每個區塊補一段**畫面描述**（`meta.usage` 之外另加，或改寫現有 description），四種語言。先從首頁會出現的 30 個開始。

### 階段 3：/why 頁（第 3 週）
整站唯一換氣氛的頁（仍然黑白灰，可以用米白底 + 襯線大標）。結構照它，內容換成我們的論點：
1. 標題就是反對意見：「Claude 都會寫了，為什麼還要裝區塊？」
2. 重現痛點：一個對話視窗自動打出十幾輪「再有質感一點」「動畫怪怪的」。
3. 對照：Prompt 庫（每次生成不一樣、要再修）vs SunUI（寫好的程式碼、裝了就一樣、agent 透過 MCP 直接拿）。
4. 搬過來的段落：二十微互動牆、差在哪裡、agent 段。
5. 價格 + FAQ，底部固定小 CTA 列。
全站加一顆「為什麼是 SunUI」膠囊指到這頁（首屏、價格頁、詳情頁）。

### 階段 4：導覽與分類頁（第 4 週）
- 頂部導覽改成：Pro 場景 / 區塊 / 動效庫 / 圖示 / MCP / 價格 / 文件。
- 每個分類一頁，開頭兩三段真的有內容的文字，標題用搜尋關鍵字（「React 動態 Hero 區塊」「免費 React 動效元件」）。
- 新增 /free：75 個免費區塊的入口頁，當 SEO 落地頁。
- 新增 /mcp 行銷頁：工具分頁（Claude Code / Cursor / Codex / VS Code）+ 一行指令 + 複製 + 「Good to know」四格。

### 階段 5：價格頁與節奏（第 5 週）
- 價格頁三卡：劃線原價（若有）、Lifetime 主力光暈改成黑白可行的做法（較亮的邊框或白底反白）、打勾打叉列表、公平使用規則寫清楚。
- 對外承諾「每週一個 Pro 場景」，加 /changelog 和電子報（等候名單表單已經有）。
- 頂部橫幅：創始會員開賣期間放倒數。

### 階段 6：上線前收尾（第 6 到 7 週）
效能（影片大小、LCP）、四語文案、OG 圖（可以用卡片影片的靜態幀）、手機版每個帶狀的排法。

## 八、先做哪一個

如果只做一件：**首頁帶狀化 + 卡片影片化**。這兩件做完，視覺落差會收掉大半，其他都是在這個殼上加頁面。建議先做一個並排比較頁（左 Scrolltide 截圖、右我們新首頁的第一個帶狀），確認方向再全部展開。
