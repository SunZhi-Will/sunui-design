# Block 去留分析

> 2026-11-05。範圍：全部 164 個 block（free 140、pro 24）。判斷基準來自 `reports/SunUI 商業化深度規劃.md` 的定位：「給電商與行銷活動用的 production-ready 動畫區塊」，以及路線圖的「少而精」。

## 1. 結論

你的直覺是對的。目前型錄是「把每個專案做過的 UI 都搬進來」，不是「買家會需要的東西」。164 個裡：

| 決定 | 數量 | 意思 |
|---|---|---|
| 留 | 78 | 符合電商、行銷活動、或任何網站都會用到的通用介面 |
| 合併 | 14 | 功能重複，併進同類的另一個 block |
| 移出主型錄 | 12 | 敘事遊戲 UI，買家不同，另外包成套件或封存 |
| 刪除 | 60 | 只有原專案用得到，或本身就是裝飾特效 |

精簡後主型錄約 **78 個**，每一個都說得出「誰會買、放在哪個頁面」。

## 2. 判斷標準

一個 block 要留下，至少要符合一項，而且不能和型錄裡另一個重複：

1. **電商或活動頁會用到**：商品、購物車、結帳、優惠、會員、檔期。
2. **任何產品都會用到**：導覽、表單、狀態、通知、空狀態。
3. **SunUI 獨有的賣點**：紙感、印章、中日文排版，別家做不出來。

刪除的訊號：

- **綁死原專案的領域**：螢幕錄影、程式碼掃描、排班、分帳、無限畫布。買家不會剛好在做同一種 app。
- **純裝飾**：沒有資訊、沒有互動，換一個網站就沒意義（Portal Threshold、粒子、傾斜跑馬燈）。
- **一個 app 的零件**：拆出來單獨賣沒有用（CardFlow 的 13 個畫布工具，要做畫布的人會直接用 tldraw 或 React Flow）。
- **紅海**：形象頁 3D 特效是 Aceternity、Magic UI 的主場，對方有幾千個，SunUI 多 7 個不會贏。

## 4. 合併（14 併進 8 個）

| 併入 | 被合併的 | 做法 |
|---|---|---|
| `jobs-tray` | job-panel、job-row、job-tile | 同一個「背景工作進度」做了四種外觀，留一個加 `variant` |
| `story-player` | recap-active-month、recap-keyword-cloud、recap-percentile-ring、recap-streak-flame | 四張回顧投影片改成 story-player 的範例投影片 |
| `toast-stack` | undo-toast | toast-stack 已經有復原動作，把 `useUndoable` hook 搬過去 |
| `countdown-banner` | honest-countdown | 「hydration 前只顯示日期、分頁隱藏時暫停」本來就該是預設行為 |
| `skeleton-set` | loading-state | 同樣是載入骨架 |
| `content-gate` | preview-paywall | 同一個「付費牆」，一個是頁內、一個是疊在播放器上，用 `variant` 區分 |
| `browser-frame` | window-frame | 兩個都是視窗外框 |
| `person-chip` | app-chip | 兩個都是「彩色點 + 名稱」膠囊 |
| `variant-picker` | segmented-control | 都是商品規格選擇 |

## 5. 移出主型錄：敘事遊戲 UI（12）

choice-cards、dialogue-box、pause-menu、save-load-panel、notice-queue、motion-clip-tabs、hold-to-redeem、ink-fate-dial、records-thread-board、archive-cabinet、cg-gallery、bookshelf-3d

這組做得很完整，也有統一的 `--story-*` 主題，但**買家完全不同**：做視覺小說的人多半用 Ren'Py 或 Unity，不是 React 電商網站。放在主型錄會稀釋「電商動畫區塊」的定位。

兩個選擇：

- **獨立成「SunUI Story Kit」**：另一個頁面、另一個價格，適合網頁遊戲與互動小說平台。
- **封存**：從網站移除、保留在 git 歷史。

## 7. 邊緣案例（可以再討論）

- **book-3d、cloth-curtain**：用途不明確，但是技術上最難、最有話題性，適合當 X 上的展示影片。建議留作招牌。
- **story-player**：Instagram 限動播放器，不完全是電商，但「年度回顧」「新品故事」很常見，所以留下。
- **scripted-demo、capsule-nav、scroll-story**：SaaS 形象頁用的，屬紅海，但品質高且不是純裝飾。
- **content-gate、upgrade-modal**：原本是賣課程用的，數位商品賣家也用得到。

## 8. 執行建議

1. 先做**刪除**：每個 block 刪資料夾、`registry.json` 條目、`content/registry-i18n/<name>.json`，再重新產生預覽。成本低、可從 git 還原。
2. 再做**合併**：需要改程式與 API，一次一組，並保留舊名稱的匯出一個版本。
3. 遊戲 UI 決定獨立或封存後再處理。
4. 首頁數字（目前寫 163 個 block）要一起更新。
