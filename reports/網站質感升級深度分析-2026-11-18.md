# 從紙感到質感：網站 UI/UX 深度分析（2026-11-18）

範圍：`apps/web` 網站外殼（首頁、型錄、區塊頁、定價），以及 block 設計語言的影響。
方法：本機實測 1440x900 淺色與深色，用 `getComputedStyle` 抽樣；外部研究直接下載 linear.app、vercel.com、resend.com、stripe.com 的正式環境 CSS 取出變數（2026-11-18），其餘來自文章與官方文件。標【未驗證】的項目沒找到一手來源。

## 一、結論

1. **質感不是更花，是更準。** Linear、Vercel、Stripe、Resend 都不比 SunUI 吵：沒有彩色漸層、光暈、毛玻璃內容層。它們多出來的是「深度與精度」：極淡的多層陰影永遠配 1px 邊、帶角色的灰階級距（底、hover、active 各一階）、可變字重與隨字級收緊的字距、同心圓角、深色模式的頂邊高光。
2. **SunUI 目前缺的正好是這幾樣。** 實測主內容 136 個元素陰影全是 `none`，字重只有 400 / 500 / 600 三種，邊框是實色 `#e4e4e4`，圓角只有 0 / 6 / 8px。紙感規則「無陰影、rounded-md 以下、平面」把物件的厚度全部拿掉，於是看起來像線稿，不像產品。
3. **最大的單一問題是一個 bug：Geist 字體沒有套到全站。** 字體檔有載入，變數掛在 `<body>`，但內文實際在用系統字體（見二之 1）。修這一行，質感立刻上一階，而且零風險。
4. **建議的路線：保留克制，換掉平面。** 去 AI 感的禁令（漸層、光暈、彩色陰影、紫色、毛玻璃內容層）全部保留，因為這些正是 2026 年公認的 AI 樣貌；要改的只有「完全不准陰影」與「圓角上限 6px」這兩條，改成「陰影只當作近乎看不見的層次，而且一定配邊線」。
5. **這會碰到 11-13 剛定的定位**（主詞是「紙感與動效」）。網站外殼可以先做，不影響定位；block 與首頁文案要不要從「紙感」改成「質感」，需要你決定（見六）。

## 二、現況診斷（實測）

### 1. 字體 bug 的原因

`@theme inline` 會把 `--font-sans` 直接內嵌進工具類別，不會在 `:root` 產生 `--font-sans` 變數（實測 `:root` 與 `body` 上都讀不到）。所以 `body { font-family: var(--font-sans) }` 是無效值，退回繼承 `html` 的 Tailwind 預設字體。`font-mono` 正常，因為它走工具類別。修法擇一：

- `body` 改寫 `font-family: var(--font-geist-sans), ui-sans-serif, system-ui, sans-serif;`
- 或 `layout.tsx` 的 `<body>` 加 `font-sans` 類別。

`(preview)` 版面也要一起看，block 預覽 iframe 應該跟著修。

## 三、別人怎麼做（重點數字）

### 陰影：多層、極淡、負擴散、一定配邊

- **Vercel Geist**（正式 CSS）：卡片 `0 0 0 1px #00000014, 0 2px 2px #0000000a, 0 8px 8px -8px #0000000a`。不透明度 2% 到 6%，負擴散讓大模糊藏在物件底下，側面不會出現灰暈。浮層用 12px 圓角、卡片與控制項 6px。
- **Linear**：`--shadow-stack-low` 是五層加底部內陰影，讀起來像可以按下去的實體；部分主題把陰影設成 `none`，深色模式改用表面變亮表示高度。
- **Stripe**：陰影帶藏青色（`rgba(50,50,93,.25)`），不是純黑。
- **Josh Comeau**：同一頁只有一個光源；層數倍增（1 / 2 / 4 / 8 / 16px）；不要動畫多層陰影。https://www.joshwcomeau.com/css/designing-shadows/
- **Vercel Web Interface Guidelines**：至少兩層陰影（環境光加直射光），邊線與陰影並用，半透明邊線。https://vercel.com/design/guidelines

### 邊線與高光

- 邊線用透明度而不是實色：Linear `#0000000d` / `#00000014`，深色 `#ffffff0d` / `#ffffff14`。同一個值在紙、卡、圖片上都對。
- 深色模式頂邊 1px 白色高光：Linear 有整組 edge-highlight 變數（`#ffffff14`），Resend 用 `inset 0 0 0 1px #ffffff1a`。
- 焦點環（Vercel）：`0 0 0 2px 背景色, 0 0 0 4px 焦點色`，先留一圈底色間隙。

### 圓角

- 同心規則：內圓角 = 外圓角 − 內距（Apple WWDC25 Liquid Glass、Vercel 準則都這樣要求）。https://developer.apple.com/videos/play/wwdc2025/356/
- Linear 卡片 12px、Vercel 浮層 12px 控制項 6px。SunUI 的 6px 上限比兩家都緊。

### 顏色

- Vercel 的灰是**純中性**（HSL 飽和度 0%），所以質感不需要暖灰或冷灰；關鍵是每一階有角色：100 到 300 是底色（預設、hover、active），400 到 600 是邊線（預設、hover、active），900 到 1000 是文字。另有一組 alpha 灰給浮層與陰影。https://vercel.com/geist/colors
- Linear 的文字略帶冷色（`#282a30`），主題從 HSL 改到 LCH，變數從 98 個減到 3 個。https://linear.app/now/how-we-redesigned-the-linear-ui
- 這和 SunUI「純中性灰，不用米白暖灰」的決定相容，不用推翻。

### 字體

- Linear 用 Inter Variable 的非整數字重：medium **510**、semibold **590**、bold 680。比 500 / 600 略重，又不顯粗，是招牌手法。
- 字距隨字級收緊：13 到 15px 約 `-0.01em`，24px `-0.012em`，32px 以上 `-0.022em`，行高 1.0 到 1.125。
- Stripe、Vercel 對所有數字開 `tabular-nums`。
- Resend 用一款有個性的標題字（Domaine serif）扛品牌。

### 動效

- SunUI 現在的 `cubic-bezier(0.23, 1, 0.32, 1)` 就是 Linear 定義的 ease-out-quint，方向正確。
- Linear hover：出現 0ms、消失 150ms（進快退慢）。
- Emil Kowalski：按下 `scale(0.97)`；不要從 `scale(0)` 開始，最低 0.93；連續提示框第二個起立即顯示；高頻動作不加動畫；內容交叉淡化可加 `blur(2px)` 遮接縫。https://emilkowal.ski/ui/7-practical-animation-tips
- Vercel 浮層從 `scale(.96)` 進場；抽屜用 `cubic-bezier(.32,.72,0,1)`（Vaul 與 iOS sheet 的曲線）。

### 材質

- 雜訊紋理只用在主視覺插圖（Resend 的 noise.png 加 soft-light），不鋪全站。
- 毛玻璃只給浮在內容上的功能層（黏頂頁首、浮動工具列），Apple HIG 明說不要用在內容層。
- 漸層只當遮罩用（邊緣淡出、跑馬燈淡出），不當填色。

### 要避開的 2026 年 AI 樣貌

藍紫漸層、只用 Inter、置中的通用 hero、三張等寬卡片、裝飾性動畫、毛玻璃、光暈、等距 bento 格、標題漸層字（https://www.utsubo.com/blog/built-with-ai-trust-signals-2026 、https://superdesign.dev/blog/why-ai-design-looks-generic ）。另外要注意新的陳腔濫調：**米白底、襯線字、鼠尾草綠**（https://claudecodehq.com/playbooks/unslop-ui ）。也就是說「質感」不能靠換成暖色調高級感來做，那只是從一個預設換到另一個預設。

## 四、「質感」設計語言提案

一句話：**精密的物件，不是平面的紙。** 黑白灰與克制照舊，加上厚度、光線與精度。

### 1. 灰階：保留純中性，補上角色級距

| 角色 | Light | Dark |
|---|---|---|
| 底 bg-100 / bg-200 | `#ffffff` / `#fafafa` | `#0a0a0a` / `#111111` |
| 表面 surface / hover / active | `#ffffff` / `#f5f5f5` / `#ededed` | `#141414` / `#1a1a1a` / `#222222` |
| 邊線（alpha）預設 / hover / strong | `rgb(0 0 0/.08)` / `.12` / `.18` | `rgb(255 255 255/.08)` / `.12` / `.18` |
| 文字 1 / 2 / 3 | `#0a0a0a` / `#525252` / `#8a8a8a` | `#ededed` / `#a1a1a1` / `#6b6b6b` |

`--line` 改成 alpha 值；舞台、圖片、深色反白區塊上的邊線就不會髒。

### 2. 高度：四階陰影，永遠帶 hairline

```css
--shadow-hair:  0 0 0 1px var(--line);
--shadow-1: var(--shadow-hair), 0 1px 2px rgb(0 0 0/.04);                       /* 卡片、輸入框 */
--shadow-2: var(--shadow-hair), 0 1px 1px rgb(0 0 0/.02), 0 4px 8px -4px rgb(0 0 0/.05), 0 12px 20px -8px rgb(0 0 0/.06); /* hover 卡片、下拉 */
--shadow-3: var(--shadow-hair), 0 2px 4px rgb(0 0 0/.03), 0 16px 32px -8px rgb(0 0 0/.08), 0 32px 64px -16px rgb(0 0 0/.08); /* 面板、對話框 */
/* 深色：不用投影，改成頂邊高光加表面提亮一階 */
--shadow-1-dark: inset 0 1px 0 rgb(255 255 255/.06), 0 0 0 1px rgb(255 255 255/.08);
```

規則：一頁一個光源（正上方）；陰影不做動畫，hover 用兩層疊加後切換 opacity；不准彩色陰影。

### 3. 圓角：同心體系

- 控制項 6px、卡片與預覽框 12px、面板與對話框 16px、膠囊 9999px。
- 巢狀時 `內 = max(0px, 外 − 內距)`，例如 12px 卡片內距 4px 的縮圖用 8px。
- 型錄卡片（現在 10px）與徽章（2px）統一到這個表。

### 4. 字體

- 修好 Geist（二之 1）。
- 字重改成 400 / 510 / 590 / 680（Geist 是 100 到 900 可變字重，支援非整數）。
- 字距表：12 到 15px `-0.006em`，16 到 20px `-0.011em`，24px `-0.015em`，32px 以上 `-0.022em` 行高 1.1。
- 按鈕 14px / 510，不是 16px / 400。
- 中文段落不加負字距（CJK 加負字距會擠）；可用 `:lang(zh)` 歸零。
- 所有價格、數量、寬度數字 `tabular-nums`。

### 5. 互動狀態

- 按鈕：靜止 `--shadow-1`，hover 底色升一階，按下 `scale(.97)` 100ms。
- 主按鈕加 1px 內高光：`inset 0 1px 0 rgb(255 255 255/.12)`（淺色主題的黑按鈕會多一點立體）。
- 焦點：`0 0 0 2px var(--bg), 0 0 0 4px var(--fg)`。
- hover 底色出現 0ms、消失 150ms。

### 6. 材質

- 黏頂頁首已有 `bg/80` 加模糊，保留，補一條 hairline 下邊線。
- 首頁紙牆：淺色版加 `--shadow-2` 讓每張卡有厚度，對比問題自然改善。
- 雜訊、漸層填色、光暈：仍禁止。

### 7. 動效

現有 `SITE-MOTION.md` 已經接近業界最佳實踐，只補三條：浮層從 `scale(.96)` 進場、抽屜改用 `cubic-bezier(.32,.72,0,1)`、連續提示框免延遲。

## 五、對 block 的影響

block 安裝到買家專案要吃對方的 shadcn 主題，所以 block 端的改法要更保守：

- **可以直接改**：陰影改用 `shadow-sm` 加 `ring-1 ring-foreground/5` 這類跟主題走的寫法；圓角改跟 `--radius`（shadcn 預設 0.625rem = 10px）而不是寫死 6px 上限；同心圓角。
- **要保留**：紙、墨、品牌專色、`Stamp`、不慶祝、三種彈簧。這些是 SunUI 被認出來的地方。
- **新增一個系列而不是改掉 paper**：例如 `DESIGN-craft.md`（或直接讓 product 系列承接），paper 系列繼續存在給票券、收據這類真正需要紙的題材。這樣不必回頭改 75 個免費 block（凍結期也不允許大改），Pro 新場景直接用新語言。

## 六、要你決定的事

1. **定位句要不要改。** 11-13 才把主詞定為「紙感與動效」，首頁 h1 上方仍寫「有紙感的 React 動態區塊」。若要改成「質感」，要動 `messages.ts` 四語、`AGENTS.md`、`DESIGN.md`、`guidelines.ts`、`llms.txt`、MCP 自我介紹。建議：Founding 開賣（11-27）前不換主詞，只做外殼質感；11-27 到 PH（2027-01-12）之間再換文案。
2. **block 的範圍。** 建議只讓 Pro 新場景與網站外殼採用新語言，免費 block 不動。

## 八、限制

- Raycast、cal.com 的 CSS 沒抓到，rauno.me/craft/interfaces 回 500；family.co、Framer、Apple 產品頁與其他 UI 庫沒有實測。
- Tailwind Plus 的 `ring-gray-900/5` 寫法是記憶，未驗證；Emil Kowalski 的按壓時長只見於社群轉述。
- 本機實測只在 Chrome / macOS；Windows 上字體 bug 的影響更大，沒有實機確認。
- 沒有使用者測試，「更有質感」的判斷是對標加設計推論。
