# 迷你圖表參考分析（2026-11-08）

參考：April Zhu 的 Minicharts demo（april-zhu.com/minichartsdemo）。副標是「Charts that build up from your numbers. Touch any part to read it.」
本文件只描述觀察到的做法，實作全部自寫，成品為 Pro block `count-chart`（`apps/web/registry/pro/count-chart/`）。沒有使用、描摹或重製對方任何一張插圖、配色或文案。

## 1. 網站逐段觀察

| 區段 | 觀察 |
|---|---|
| 版面 | 左側固定清單列出 18 種圖表，每項是「圖表名稱 + 一句生活情境」（例如 Hexbin：one frame of honeycomb）。右側一張卡片：左邊插圖，右邊標題、副標、一句讀法說明，底部 Replay、Pause（或 Play all）與「2 of 18」 |
| 18 種圖表 | 甜甜圈、六角格、月曆熱圖、泡泡、堆疊長條、雷達、圓餅、漏斗、瀑布、方格（waffle）、K 線、棒棒糖、小提琴、山脊、桑基、旭日、儀表、文字雲 |
| 情境 | 每張圖都換成一個實物：一盒 12 個甜甜圈、一片蜂巢、六月的步行公里數、巧克力廚房一週的產量、一個雨水桶、100 份週日早餐、溫室一週的溫度。資料就是那些東西本身 |
| 播放 | 進入某張圖時，圖會「長出來」：堆疊長條是一片一片巧克力疊上去，數字標籤先在位置上。全部播放會自動輪播 18 張 |
| 觸碰 | 點任何一塊，其他部分降到約 36% 透明，被點的那一塊沿自己的方向位移幾像素浮起；右側說明換成一句白話，例如「Friday, dark: 35 bars, seven slabs」 |
| 常駐小動態 | 蜜蜂嗡嗡、蒸氣、雨滴、燭火、植物搖擺，各自一個 CSS keyframes 迴圈 |

## 2. 拆解：它到底做了什麼

用 DOM 與樣式表檢查：

1. **全部是 inline SVG，沒有 canvas、沒有點陣圖**。每張圖一個 `viewBox="0 0 520 420"` 的 SVG，路徑數從 59（山脊）到 9,814（甜甜圈）不等。沒有 SVG filter。
2. **手繪質感來自一張紙紋圖樣**。`<defs>` 裡有一張 346×346 的 PNG 紙紋（`#tooth`），每個顏色是一個 `<pattern>`：底色 `rect` 加上 `use href="#tooth"`。所以每塊色面都帶同一張紙的顆粒。邊線用細的多段折線，轉角有輕微不規則。
3. **可觸碰的部分是 `g.p`**：`tabindex="0" role="button" aria-label` 寫好整句說明，inline style 帶 `--dx`、`--dy`（被選中時往哪個方向浮起）。CSS 只有三條：`.live .p:not(.on) { opacity: .36 }`、`.p.on { transform: translate(var(--dx), var(--dy)) }`、`transition: transform .22s cubic-bezier(.3,.8,.3,1)`。互動非常薄，價值在「每一塊都寫好一句人話」。
4. **字體分工**：標題 Young Serif，說明手寫體 Gaegu，介面 DM Sans。手寫字讓「念給你聽」的語氣成立。
5. **`prefers-reduced-motion` 有處理**：常駐動態與浮起都關掉。
6. **卡片用 `content-visibility: auto`**，18 張圖同時在 DOM 裡但只畫看得到的那張。

## 3. 為什麼值得做

- **「件數就是圖」降低讀圖門檻**。一般圖表要先讀刻度再換算；這裡一片就是五條巧克力，數得出來。電商頁的讀者不是分析師，這個方向對。
- **一句白話的讀法**是整個網站最有價值的設計：每一塊都知道自己是什麼，點下去不是跳出數字 tooltip，而是一句完整的話。這同時解決了無障礙（`aria-label` 就是那句話）。
- **和 SunUI 的紙感語言接得上**：紙、層疊、實物，跟優惠券、收據、禮盒同一個家族。
- **有明確的付費場景**：價格透明（每 100 元花在哪）、小店週報、禮盒內容，都是商店頁真的會放、而且免費圖表庫不會幫你做成「實物」的地方。

## 5. 我們的版本：count-chart

### 5.1 三種形式，同一套互動

| kind | 一件是什麼 | 商店場景 |
|---|---|---|
| `stack` | 一片（`per` 決定一片代表幾件），由下往上疊，欄頂是總數 | 每天做了或賣了多少、各尺寸預購、各項目捐款 |
| `waffle` | 一枚硬幣或一格，預設 100 格，最大餘數法分配讓總和剛好 100 | 價格透明：每 100 元的材料、製作、運費與稅、利潤 |
| `box` | 盒裡一個紙杯一顆，預設 12 格 | 禮盒、組合包、訂閱盒的內容 |

`columns` 是一欄一疊、一張 100 格或一盒；多欄就並排比較（連帽衫對托特包）。

### 5.2 讀法（參考網站的核心，完整保留並加深）

- 點任何一組：其他組降到 32% 透明，被選的那組浮起 4px（stack）或 2px（格狀）並描上墨線，下方 `figcaption` 用 `aria-live="polite"` 念出一句話。
- 三個層級：點一組（某天某口味）、點欄名（整天）、點圖例（整個口味跨所有天）。參考網站只有第一層。
- `read` 讓買家用自己的單位寫那句話（「週五，牛奶：45 條，9 片」「托特包，我們的利潤：每 NT$1,000 裡的 NT$460」）；不傳就用內建的四語預設句。
- 選取在資料改變後保留：換週時那一句會跟著新資料重念（「週五，牛奶：40 條，8 片」），讀者不用重點一次。
- 鍵盤：每組是 `role="button"`，方向鍵在組之間移動（stack 的上下是往上疊、往下疊），Enter 念出，Escape 清除。另有隱藏表格帶全部數字。

### 5.3 動態（只回應資料改變與點擊）

| 時機 | 做法 |
|---|---|
| 掛載 | 不動，直接是完成狀態（`AnimatePresence initial={false}`） |
| 資料改變 | 新增的件由上方 18px 落下（stamp 彈簧），依在疊裡的順序錯開，總錯開時間上限 0.5 秒；減少的件往上淡出 120ms；其餘件用同一個彈簧滑到新位置 |
| 點選 | 整組一起浮起與淡化（snappy 彈簧），不是每一件各自動，所以不會跟著數的錯開延遲 |
| 減少動態效果 | 全部改為立即切換，資訊不變 |

每一件的手疊感來自位置上 ±1.2px 的固定抖動（由欄、系列、序號雜湊），重新整理不會跳。

### 5.4 示範

一家巧克力店的頁面：上方廚房週報（本週、上週切換，切換就是重新數一次的時機，不需要測試按鈕）；下方左邊連帽衫與托特包的售價拆解，右邊十二入禮盒（經典、黑巧控切換）。型錄卡片只放廚房週報。

## 6. 和現有 block 的分界

- `chart-effects`（免費）：七種一般圖表的進場效果，給儀表板用，有座標意義、沒有實物。
- `tiny-chart`（免費）：流程與狀態機的小圖。
- `price-history`（Pro）：價格走勢線。
- `count-chart`（Pro）：件數就是圖，重點是「點一下念一句話」與資料改變時只數新的。三者不重疊，型錄排序上 `count-chart` 放在 B 組 `sticker-board` 之後，不靠近 `chart-effects`。
