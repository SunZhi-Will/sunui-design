# Contribution Skyline 參考分析（2026-11-07，逐格修訂版）

來源：Divan Raj（@desdivj）2026-11-05 的貼文「Turned a contribution graph into a skyline.」，附一段 8.0 秒、1324×1080、無聲、無縫循環的影片。

## 一句話結論

這支影片真正的功夫不是「把點陣做成 3D」，而是**同一個幾何從頭到尾沒有被換掉**：點陣的圓點先平躺在等角地板上，再沿時間軸長成圓柱；切回 Grid 時圓柱先縮回、地板再轉正成俯視。每個轉場都拆成先後兩三段，各段很短。資料密度的分層（總覽平面、深入層才 3D）是它的骨架，連續的形變編排才是讓人收藏的原因。

## 0. 勘誤（第一版寫錯或漏掉的）

第一版只用大約 1 秒一格抽樣，漏掉大部分轉場。這版用 JS 暫停影片、逐格跳到指定時間點（關鍵段 0.1 秒一格）重新觀察。

## 3. 為什麼有效

1. **一個幾何，三個狀態**。圓點、地板上的圓片、圓柱是同一個東西。使用者從頭到尾追的是「同一個點」，所以 3D 不像換了一張圖，而像同一份資料站了起來。第一版說的「三個面的方塊」會破壞這件事，因為方塊的頂面不是圓點。
2. **轉場分段，一次只改一件事**。切 Grid 時先拿掉高度、再轉視角、最後補標籤，而不是三件事同時發生。每段都短，眼睛跟得上；如果同時縮高又轉正，畫面會糊成一團。
3. **錯開方向有意義**。圓柱從 7 月長到 1 月，跟時間同方向。錯開不只是裝飾節奏，而是在重述資料的時間軸。
4. **漸進揭露的密度分配**。儀表板上點陣最省空間、最好比較；使用者主動點開才有注意力看 3D。
5. **語意連續，不是空間連續**。卡片標題、總數 1,516、配色、時間範圍都延續到面板，但面板裡的點陣**不是從卡片飛過去的**，而是在面板裡重新長出來。鏡頭拉遠加面板滑入撐住了位置感，所以不需要共享元素動畫。
6. **3D 沒有犧牲可讀性**。懸停變色加提示給確切數值，統計列直接給結論，Grid 給精確閱讀。
7. **影片的拍法**。8 秒、無聲、循環、鏡頭先推近再拉遠、每個互動都有點擊漣漪。滑時間軸的人不開聲音也看得懂。

## 4. 弱點與不該照抄的地方

- **它是 SaaS 分析儀表板，不是商務或活動頁**，不在 SunUI 的定位內。
- **毛玻璃桌布、柔和陰影、漸層面**都違反 `DESIGN.md` 紙感規則。
- **總長度超過我們的上限**：切 Grid 整段約 0.7 秒，SunUI 規定單次動畫 400ms 以內。拆開看每段約 0.2 秒是合規的，但整串加起來偏長，重複切換會覺得慢。
- **想法不新**：GitHub 2021 年就做過 Skyline。新的是放進產品介面的深入層，以及形變編排。
- **假資料很好看，真資料常常不好看**。真實分布可能大半是零。
- 182 根圓柱在手機上幾乎無法懸停，影片只展示桌面版。

## 5. 對 SunUI 的意義

### 5.1 立刻可用：宣傳影片的拍法（直接服務 PH 上線）

1. 長度 8 秒左右，無聲可懂，最後一格等於第一格，無縫循環。
2. 先給完整場景，鏡頭推近主角；展開深入層時鏡頭同步拉遠。
3. 每次點擊都有漣漪，一次只示範一個互動。
4. 結尾展示「同一份東西的另一種視角」，再把畫面收回起點。
5. 目標是書籤，不是喜歡。

適合套用的 SunUI 素材：Pro 的 `cart-drawer`、`order-tracker`、`self-building-page`，都有「小卡片展開到完整面板」的故事。

### 5.2 已寫入設計文件：密度分層

已加入 `apps/web/DESIGN.md`（材質與形狀、檢查表）與 `apps/web/lib/agent/guidelines.ts`（共用規則）。

這次逐格觀察還多出兩條做法，已補進兩份文件的「連續性」規則：

- **同一個幾何貫穿所有狀態**：換視角時保留元素本身的形狀（點還是點，只是長高或躺平），不要換成另一種圖形。
- **多步轉場依序做**：一次只改一個屬性（先高度、再視角、再標籤），每段在 400ms 規則內。

### 5.3 做成 block：先不做，列為候選

**凍結期規則**：免費目錄凍結到 2027-01-12，不新增免費的 contribution skyline。

唯一說得通的形式是**商務化的 Pro 場景**：

- **年度購物回顧（Year in Review）**：顧客一年的訂單做成天際線，最高那根是雙 11。
- **大促時段熱度戰報**：雙 11 或黑五 24 小時 × 7 天的成交量城市。

四問檢查（`免費與付費切分規劃-2026-11-05.md`）：

| 問題 | 判斷 |
|---|---|
| 可替代性 | shadcn、Magic UI、React Bits 沒有等角貢獻城市，有差異 |
| 製作時間 | 2 到 3 天（逐格看完後上修：完整做出三段形變比第一版估的複雜）。`tiny-chart` 的 `layoutIso` 可借投影；`dialog-sheet` 或 `side-panel` 當深入面板 |
| 離營收距離 | 偏遠。年度回顧的主要使用者是平台方，不是接案做活動頁的工作室 |
| 展示價值 | 高，很適合當 PH 影片素材 |

結論不變：**現在不做**，放進上線後的候選清單。

### 5.4 如果之後真的要做：紙感翻譯與技術要點

| 影片做法 | SunUI 紙感翻譯 |
|---|---|
| 橘色深淺、柔和陰影 | 墨色深淺；圓柱側面比頂面深一階，無漸層、無陰影 |
| 毛玻璃桌布、面板背後淡化 | 拿掉桌布；背後用平面墨色遮罩（`dialog-sheet` 現成做法） |
| 懸停時圓柱變近黑色 | 懸停那根用全墨，其餘不變；提示用 `bg-card` 加 1px 邊框 |
| 橘色「Busiest」標籤 | 墨色小標籤，不用顏色 |
| 圓柱依序長出 | `gentle` 彈簧，依週次錯開，從最早一週往最近一週 |

技術上，照影片的三段來拆：

1. **共用一個狀態參數**：每個點有 `tilt`（0 俯視、1 等角）與 `height`（0 到資料值）兩個參數。Grid 是 `tilt=0, height=0`，3D 是 `tilt=1, height=值`，中間的「平躺地板」是 `tilt=1, height=0`。
2. **切換時依序動**：到 Grid 先把 `height` 歸零，再把 `tilt` 轉到 0，最後淡入標籤；到 3D 反過來。每段 `gentle` 彈簧，約 200ms。
3. **用 SVG 畫圓柱**：頂面是橢圓（等角下的圓），側面是兩條直線加底部半橢圓圍成的路徑；由後往前排序繪製，懸停用每根的路徑命中。
4. **外框跟著內容**：Grid 比 3D 矮，圖表卡高度用 `gentle` 補間，下方卡片滑動而不是跳。
5. **減少動態偏好**：預設顯示 Grid，切換時直接換狀態，不播長出動畫。
6. **無障礙**：Grid 版本就是無障礙版本，方向鍵在格子間移動、每格有 aria label；3D 版本附隱藏的資料表。
7. **資料稀疏時**：零值留在地板上當淡色圓片，統計列先給結論。
