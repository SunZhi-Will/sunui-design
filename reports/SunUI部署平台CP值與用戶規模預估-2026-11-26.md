# SunUI 部署平台 CP 值與用戶規模預估

日期：2026-11-26
前一份：`reports/部署平台流量爆量與是否換平台深度分析-2026-11-26.md`（Vercel Hobby 因 beacon 吃 CPU 被停權到 12/25）
前提：使用者不想付 Vercel Pro 的每月 20 美元。

## 一句話結論

**SunUI 不需要因為 beacon 搬去 Google 就跟著搬，兩者花錢的地方不一樣。** beacon 貴在 CPU，SunUI 貴在頻寬（卡片影片和圖片），而 Google 的出站流量是要收費的。

不付 20 美元的前提下，CP 值最高的組合是：

1. **影片和圖片搬到 Cloudflare R2，網域開 Cloudflare 代理快取**（兩個網域本來就在 Cloudflare DNS 上，出站不收費）。不管最後放哪個平台都該做。
2. **主機用 Google Cloud Run，前面掛 Cloudflare。** 每月 300K 訪客以內估計 0 到 10 美元，跟 beacon 共用同一份免費額度，遷移約 1 到 2 天，而且**做完 SunUI 馬上恢復上線，不用等到 12/25**。
3. **不建議現在搬 Cloudflare Workers**：長期最便宜（約 5 美元），但 SunUI 的伺服器輸出有 139MB，Workers 單一程式上限是 10MB，還要改掉執行期讀檔，離 Product Hunt 只剩 47 天，風險太高。

## 1. SunUI 的負載長什麼樣（本機正式版實測）

### 哪些頁面每次都要算

`lib/i18n-server.ts` 用 cookie 和 `Accept-Language` 判斷語言，所以**首頁、`/blocks`、`/docs/*`、`/pricing`、`/icons` 每次瀏覽都是動態渲染**（build 表上是 `ƒ`），會吃 CPU。區塊頁 `/blocks/[slug]`、`/preview/*`、`/r/*.json`、`llms*.txt` 是預先產好的靜態檔，幾乎不吃 CPU。

### 每種請求的重量

| 路徑 | 原始大小 | gzip 後 | 本機渲染時間 |
|---|---|---|---|
| `/` 首頁 | 299KB | 63KB | 18ms |
| `/blocks` 目錄 | 1.5MB | 182KB | 41ms |
| `/blocks/<slug>` 區塊頁 | 573KB | 74KB | 靜態 |
| 首頁的 JS（27 個檔） | | 301KB | 靜態，第二次造訪走快取 |
| `/llms-full.txt` | 449KB | | 靜態 |
| `/r/<name>.json`（一次安裝） | 22KB | | 靜態 |
| MCP `tools/list` | 8KB | | 動態 |

媒體才是大宗：

| 資料夾 | 大小 | 說明 |
|---|---|---|
| `public/cards` 影片 | 24MB（212 支，平均 113KB）+ 480p 9.7MB | 目錄卡片捲到才載入 |
| `public/cards` 圖 | 9.8MB | 首頁一次 33 張 |
| `public/og/blocks*` 海報 | 每張約 96KB，兩套共 420 張 | 已改成直接送原檔（不走圖片優化） |

### 換算成「每個訪客」

| 項目 | 估算 | 依據 |
|---|---|---|
| 每次造訪的動態頁 | 約 3 頁 | 首頁、目錄、價格或文件 |
| 每次造訪 CPU | 約 0.15 秒 | 雲端機器比本機慢，每頁抓 50ms |
| 每次造訪流量（媒體放主機上） | 約 4MB | 首頁圖 1.5MB、幾支影片、JS、HTML |
| 每次造訪流量（媒體搬到 R2） | 約 0.6MB | 只剩 HTML、JS、RSC |
| 主機出站（R2 加上 Cloudflare 快取靜態檔） | 約 0.25MB | 只剩動態 HTML |

**結論：SunUI 一個訪客的 CPU 很便宜，流量很貴，而且貴在媒體。**

## 2. 用戶規模預估

| 情境 | 每月訪客 | 什麼時候會發生 |
|---|---|---|
| A. 現在 | 約 3K | 上線前，只有自己、少量搜尋 |
| B. PH 當月／穩定期 | 約 30K | 1/12 PH 當天 5K 到 20K，之後回落；小眾 shadcn registry 穩定期常見量級 |
| C. 成長順利 | 約 100K | 被收進 shadcn 目錄、被 AI 工具常推薦、社群轉發 |
| D. 爆紅 | 約 300K | 像頭部動畫元件庫那樣的量；第一年不太可能，但要知道上限在哪 |

AI 代理的流量（MCP、`llms-full.txt`、`/r/*.json`）每次只有幾 KB 到幾百 KB，而且都是靜態檔，對成本影響很小，先併入上面的估計。

## 3. 各平台在各規模下的月成本

### Vercel Hobby（免費）

| | A | B | C | D |
|---|---|---|---|---|
| 媒體放主機 | 可 | **爆頻寬（120GB 大於 100GB）停權** | 停權 | 停權 |
| 媒體搬 R2 | 可 | 可 | **爆 CPU（4.2 小時大於 4 小時）停權** | 停權 |

免費，但：不准商用（SunUI 有賣 Pro）、超過就整個帳號停權（20 多個專案一起停）。**PH 當月就可能再停一次。**

### Vercel Pro

每月 20 美元，D 規模也只多 1 到 2 美元（含 1TB 頻寬，CPU 超量每小時約 0.13 美元）。零遷移、有 preview 部署、超量是收費而不是停權。**最省事，但你不想付。**

### Google Cloud Run（前面掛 Cloudflare，媒體在 R2）

| | A | B | C | D |
|---|---|---|---|---|
| 主機出站 | 0.75GB | 7.5GB | 25GB | 75GB |
| CPU（vCPU 秒，每月免費約 18 萬） | 約 900 | 約 9K | 約 30K | 約 90K |
| **月成本** | **約 0** | **約 1 美元** | **約 3 美元** | **約 10 美元** |

- beacon 這 30 天約用 2 萬 vCPU 秒，同一個帳單帳戶共用免費額度，加上 SunUI 的 D 規模還在免費額度內。
- 出站以每 GB 約 0.12 美元估（亞洲區域較貴，以 Google 計價頁為準）。
- **如果媒體沒搬、也沒掛 Cloudflare**：B 規模約 14 美元，D 規模約 140 美元。所以搬 Google 的前提一定是媒體先離開主機。
- 缺點：沒有流量時會冷啟動（第一個請求慢 2 到 4 秒）；只有一個區域，所以靜態檔一定要交給 Cloudflare 快取，美國和歐洲的 PH 訪客才不會慢；沒有 Vercel 那種每個分支一個 preview 網址。

### Cloudflare Workers（付費方案）

所有規模約 **5 美元**（D 規模約 150 萬次請求，含量 1,000 萬；CPU 超出約 0.3 美元；靜態檔與 R2 出站不收費）。免費方案每個請求只給 10ms CPU，`/blocks` 渲染就超過，不能用。

**長期 CP 值最高，但遷移成本也最高**：
- 伺服器輸出 139MB（`.next-prod/server`），Workers 單一程式上限 10MB，預先渲染的頁面要另外放，Pro 原始碼又不能放在公開靜態檔。
- 區塊頁、MCP、`/r/` 端點在執行期用 `fs` 讀 `registry/` 和 `content/`（`next.config.ts` 的 `outputFileTracingIncludes`），Workers 沒有檔案系統，要改成打包時內嵌。
- 估計 1 到 2 週，還有做到一半卡住的風險。

### Netlify 免費方案

免費方案准商用，但額度用完一樣是「暫停到下個週期」，跟這次的失敗模式相同，不解決問題，不列入建議。

### 總表

| 平台 | A 3K | B 30K | C 100K | D 300K | 遷移 | 超量時 |
|---|---|---|---|---|---|---|
| Vercel Hobby（媒體搬 R2） | 0 | 0 | 停權 | 停權 | 無 | **停權**，且違反商用條款 |
| Vercel Pro | 20 | 20 | 20 | 約 22 | 無 | 收費 |
| **Cloud Run 加 Cloudflare** | **0** | **約 1** | **約 3** | **約 10** | 1 到 2 天 | 收費 |
| Cloudflare Workers | 5 | 5 | 5 | 約 5 | 1 到 2 週，有風險 | 收費 |

（單位：美元每月，皆為估算。）

Cloud Run 要到每月約 50 萬訪客以上才會比 Vercel Pro 貴。

## 4. 建議

### 現在就做（任何平台都受益）

1. **卡片影片、卡片圖、海報搬到 Cloudflare R2**，掛在 `media.synvize.com` 之類的子網域。R2 出站不收費，前 10GB 儲存免費，SunUI 的媒體約 80MB。主機流量會降到原本的約 15%。
2. **Cloudflare 代理快取 `/_next/static/*`**：檔名有內容雜湊，可以永久快取，主機就不用一直送 JS。

### 主機：Cloud Run，不等 12/25

- 在 `next.config.ts` 開 `output: "standalone"`，加一個 Dockerfile。`outputFileTracingIncludes` 在 standalone 下照樣有效，執行期讀檔不用改。
- Pro 原始碼（`registry/pro`，私有 repo）在 Cloud Build 裡用 secret 拉，跟現在 Vercel 的 `scripts/fetch-pro.mjs` 一樣。
- `vercel.json` 的續訂 cron 改用 Cloud Scheduler（每個帳戶 3 個免費排程）。
- 區域選 `asia-east1`（台灣）或 `us-central1`，看 Pro 買家主要在哪；有 Cloudflare 擋在前面，靜態檔都在邊緣，差別不大。
- 開「啟動時加速 CPU」降低冷啟動；不開最小實例（開了每月會多付約 10 美元，就不划算了）。

**做完 SunUI 就恢復上線，不用等 Vercel 解除停權。**

### 之後再考慮

- **語言判斷改到網址或前端**：現在因為讀 cookie，主要頁面都是動態渲染。改成靜態後 CPU 幾乎歸零，在哪個平台都更便宜，但改動較大，PH 之後再做。
- **什麼時候改用 Vercel Pro**：Pro 授權每月穩定有收入、想要 preview 部署和零維運時。20 美元大約就是一份 Pro 授權的錢。
- **什麼時候改 Cloudflare Workers**：真的到 D 規模以上，或 Cloud Run 帳單穩定超過 20 美元時。
