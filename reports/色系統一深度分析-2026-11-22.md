# 色系統一：深度分析與實作

> 日期：2026-11-22
> 起因：鈷藍、語意色、內容色三步做完後，使用者說「色系請統一化，而不是大雜燴」。
> 前一份：`reports/為什麼取消黑白後還是黑白深度分析-2026-11-22.md`。

## 1. 結論

**問題不是顏色太多，是顏色沒有共同的來源。** 今天加顏色的三步，每一步各自挑了一組色碼，加上之前就存在的幾組，網站上同時有十幾套互不相干的顏色。看起來雜，是因為它們的色相、明度、彩度都不一樣，而且同一個意思（藍、紅、綠）在不同地方是不同的色碼。

**統一的做法：一個品牌色 + 三個語意色，其他全部從這四個推導。**

| 角色 | 顏色 | 淺色 | 深色 | 用在 |
|---|---|---|---|---|
| 品牌 | 鈷藍 | `#2f6bff` | `#7aa2ff` | 選中、進度、主要動作、資訊、內容色、圖表、頭像 |
| 成功 | 綠 | `#1f9d55` | `#4cd68a` | 完成、驗證、成功提示、省下的錢 |
| 提醒 | 琥珀 | `#e8a020` | `#f5b84a` | 星星評分、警告 |
| 危險 | 紅 | `#dc3d43` | `#ff6b70` | 錯誤、刪除、愛心、通知數字 |

- 內容色（頭像、標籤、圖表系列）不再用八個色相，改成**鈷藍的深淺**。一頁上只有一個色相在當主角，語意色只在有意思的地方出現。
- 愛心與危險共用同一個紅，星星與警告共用同一個琥珀。意思接近的不再各有一個色碼。

## 2. 盤點：現在有哪些顏色

| 來源 | 色碼 | 問題 |
|---|---|---|
| 網站強調色 | 鈷藍 `#2f6bff` | 正確，是基準 |
| 首頁牆 | `#3b6cf6`（另一個藍）、橘 `#f97316`、紅 `#f43f5e`、綠 `#22a06b`、通知頭像的紫藍漸層 `#7c83ff` | 藍有兩種；每格各挑一個顏色 |
| 預覽示範色 | 酒紅、森林綠、洋紅 | 型錄每三張就有一張被換成這些顏色，一整面看下去最雜 |
| 語意色 | 愛心 `#e5484d`、星星 `#f5a524`、成功 `#15803d` | 和網站的危險紅 `#b42318`、價格頁的省錢綠 `#059669` 是同意思不同色 |
| 內容色 | 八個色相（OKLCH 0.62 0.08） | 頭像、圖表一次出現五到八個顏色 |
| 圖表預設 | 鈷藍 + 青、黃、陶土、綠 | 同上 |
| 漸層頭像 | 八組雙色漸層（橘紅、藍、紫、綠……） | 飽和度最高，最像 AI |
| 價格頁 | 靛藍到青色漸層、省錢綠 `#059669` | 靛藍偏紫，是公認的 AI 色；和鈷藍不同 |
| status-dot | 成功、警告、危險各一組，資訊是靛藍 `#4F46E5` | 又一組 |
| 區塊插圖（書、推薦卡、輪播） | 金棕色系 | 是商品畫面的內容，不算介面色，這次不動 |
| Pro 區塊、像素圖示 | 各自的配色 | 不在這次範圍（見第 5 節） |

## 3. 原則

1. **一個色相當主角。** 介面上除了語意色，所有顏色都是鈷藍或它的深淺。
2. **語意色只有三個，而且只在有意思時出現。** 愛心是「喜歡」不是裝飾，所以用紅；星星是評分，用琥珀；完成用綠。
3. **同意思同色碼。** 網站外殼、區塊、價格頁讀同一組值。
4. **區塊跟著買家的品牌色。** 內容色與圖表從 `--sunui-spot` 推導，買家換品牌色時，頭像和圖表一起換，不會留下一組 SunUI 自己挑的色盤。
5. **漸層只在同一個色相內。** 頭像漸層、價格漸層都改成鈷藍的深淺，不跨色相。

## 4. 實作

| 項目 | 改成 |
|---|---|
| `globals.css` | 新增四個網站色 token；`--destructive` 改成統一的紅；網站也設 `--sunui-like`、`--sunui-rating`、`--sunui-success` 為統一值 |
| 區塊預設值 | 愛心 `#dc3d43`、星星 `#e8a020`、成功 `#1f9d55`（深色亮一階），和網站同一組 |
| avatar-stack、notification-bell 頭像 | 八色相改成品牌專色的深淺（依名字雜湊挑深淺） |
| avatar-stack `fallback="gradient"`、Pro team-invite | 八組漸層改成品牌專色由淺到深 |
| chart-effects 預設系列 | 品牌專色的五階深淺 |
| status-dot | 資訊改讀品牌專色，其他用統一的三個語意色 |
| 首頁牆 | 拿掉逐格指定的顏色（網站本身就是鈷藍），通知頭像改鈷藍深淺，商品縮圖改中性灰 |
| 型錄 | 拿掉「每三張換一個示範色」，整面都是鈷藍；預覽工具列的示範色保留，要使用者自己點 |
| 價格頁 | 金額漸層改成鈷藍由深到淺，省錢改統一的綠 |
| DESIGN.md、guidelines.ts | 內容色規則改成「品牌專色的深淺」，語意色改成統一值 |

例外：`person-chip` 保留八色相。它的用途就是在排班表上分辨不同的人，換成同一色相會失去功能。

## 5. 不在這次範圍

- **Pro 區塊**：98 個裡有 45 個寫死色碼。等這套在免費層確定之後，逐批改。
- **像素圖示的本色**：`/icons` 的像素圖示預設彩色是另一個決定（記憶 icons-pixel-first），維持。
- **區塊裡的商品插圖**：書本、推薦卡的金棕色是畫面內容，不是介面色。
- **型錄預覽圖**：這次改完再重拍深淺兩套。
