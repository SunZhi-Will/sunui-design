# 像素施工進度條參考分析（2026-11-10）

參考：noclipepe（@noclipepe）2026-11-10 在 X 發布的「I made a loading bar you can't stop watching」，40 秒影片（1800×1200）。
本文件只描述觀察到的互動與節奏，畫面、角色、配色與程式全部自寫。成品是 Pro block `pixel-build-progress`（`apps/web/registry/pro/pixel-build-progress/`），不是免費 block（免費型錄凍結中，見 AGENTS.md）。

## 1. 影片逐段觀察

以 0.5 到 5 秒間隔逐格截圖：

| 時間 | 畫面 |
|---|---|
| 0–1 s | 圓角膠囊裡是白天的像素工地：藍天、白雲、太陽、遠方城市、右端一間小屋與黑貓。左端搭著鷹架，旗桿上的看板寫「0%」。下方狀態字「Installing update...」 |
| 1–20 s | 工人一起從左往右砌磚牆，牆的前緣就是進度。看板跟著前緣走，22%、53%、91%。地面軌道在砌好的部分變成黃色。牆最後佔滿整個膠囊高度 |
| 20–29 s | 停在 99%。頂排留一個黑色缺口，上面一個黃色箭頭上下跳。工人坐在牆頭等，後來全部擠到缺口旁邊。狀態字「99%. Any minute now.」 |
| 30–31 s | 100%，「Done!」。工人跳起來，彩紙落滿畫面 |
| 32–34 s | 牆從右往左崩塌成碎磚，看板倒數 73%、0%。狀態字變成「Installing update 2 of 47」 |
| 35–40 s | 回到空地與鷹架，重新開始 |

## 2. 為什麼讓人看不停

1. **進度有實體**。一般進度條只是填色；這裡每 1% 都是幾塊磚被放上去，看得到「誰在做、做到哪」，等待變成在看別人工作。
2. **前緣有焦點**。看板、工人、磚堆都跟著前緣走，眼睛不必掃整條，只要盯著前緣。
3. **99% 的笑點**。所有人都經歷過卡在 99%。作者把它變成一個看得見的原因：少一塊磚，箭頭指著它。等待變成懸念。
4. **完成有份量，重來也有份量**。到 100 有慶祝；下一個工作開始時牆倒掉，數字倒數，「2 of 47」是第二個笑點。
5. **小細節獎勵重看**：黑貓、雲在飄、工人動作不同步。

## 3. 拆解與 SunUI 做法

| 效果 | 參考的樣子 | SunUI 做法 |
|---|---|---|
| 畫面 | 白天藍天的像素工地 | 一張高 36 個美術像素的畫布，每格用 fillRect 畫，CSS `image-rendering: pixelated` 放大 3 倍。寬度跟著容器變，場景依寬度重新排磚與城市 |
| 配色 | 亮藍天、紅磚 | 改成兩個自己的主題：**ink 夜班**（深藍夜空、月亮、城市窗燈是唯一暖色，強調色走 `#c9a063`）與 **rice 日班**（宣紙天色、淡日頭）。不用參考的配色 |
| 砌牆 | 前緣直直往右推 | 6 排磚、交錯半塊。每排的完成線 = 前緣 − 排數 × 1.2 像素，下排先砌，前緣有一點階梯；越接近完成階梯越小，99% 時收齊。新磚從 4 像素高處落下（200ms ease-out） |
| 數值 | 動畫自己跑 | 跟著 `value` 走。往上最快每秒 30%、往下 75%，接近時放慢但不低於每秒 6%，不會拖尾到不了 |
| 看板 | 旗桿上的白牌 | 自己畫的 3×5 像素數字，% 用 5 格寬（3 格會糊）。看板跟著前緣，兩端夾住不被圓角切掉 |
| 99% 缺口 | 頂排缺一塊、箭頭跳 | 99% 到 100 之間，頂排一個固定位置不放磚，畫成深色缺口，上面金色箭頭上下 2 像素。位置刻意避開右端圓角和停在右邊的看板 |
| 工人 | 鷹架、搬磚、坐牆頭 | 5×9 的程式化小人（安全帽、臉、衣服、腿），兩格走路。狀態機：走到前緣附近隨機點 → 敲打或站著 → 再選點；往前走時六成機率頭上扛磚。前緣旁有一堆磚。數值停住 3 秒以上，工人坐下等 |
| 完成 | 跳躍、彩紙 | 最後一塊磚落進缺口，工人跳 2.2 秒，46 片彩紙飄落；`onComplete` 只呼叫一次，螢幕閱讀器報讀一次「完成」 |
| 倒塌 | 從右往左崩成碎磚 | 不是另做一段動畫：數值往下掉時，前緣往回退，超出前緣的磚自動變成碎磚（往外拋、落地彈一下、閃爍消失），加兩顆灰塵。數字跟著倒數 |

### 我們跟參考不一樣的地方

- **它是真的進度條**。參考是一段寫死的影片。這裡進度完全由 `value` 決定，元件不會自己假裝前進，99% 的停頓只會在真實進度停在 99 時出現。watchOut 寫明：量不出進度的等待請用轉圈或骨架。
- **停滯時坐下**取代參考的「坐牆頭」：牆頭位置會隨寬度變，坐地上比較穩，也更好畫。
- **省電**：畫面外或分頁隱藏時不畫；完成後慶祝結束、碎片落完就停止迴圈，不常駐。
- 沒有鷹架、小屋、黑貓、吊車：這些是參考作者的造型，我們只留「砌牆 = 進度」這個機制。

## 4. 和 SunUI 規範的對照

- 系列：`story`（DESIGN-story.md）。外框與字走 `--story-*` 變數；畫布色階跟著 `theme` 換。強調色只有 `--story-accent`（軌道、箭頭）。
- 語意：外框是 `role="progressbar"`，帶 `aria-valuenow`；畫布 `aria-hidden`；狀態字是使用者傳入的 `label`；完成用 polite live region 報讀一次。
- reduced motion：牆直接跳到目前數值，沒有落磚、工人不動、沒有彩紙與碎磚，雲不飄。
- 四種語言：progressbar 名稱與完成句內建 en、zh-TW、zh-CN、ja，可用 `labels` 覆寫。
- 375px 不破版；寬度低於約 280px 時看板會擠到兩端（寫在 watchOut）。

## 6. 為什麼是 Pro，不是免費 block

免費型錄在 2027-01-12 Product Hunt 上市前凍結。這是一個完整的敘事場景（角色、狀態機、完成與重來的節奏），符合「Pro 賣組合好的場景」的切分；跟 `pixel-boss-sale`、`pixel-level-track` 同一個像素系列，適合放進活動與下載頁。
