# 八家 UI 元件庫競品分析與 SunUI 全方位規劃

> 2026-11-07。來源：Nero（@neropursue）11/06 的推文「The best UI components ready to use. Save this」，列了 8 個站。本文逐站拆解（實際抓取首頁與定價頁），歸納市場共通做法，再對照 SunUI 現況，給出「優化 / 改良 / 新增 / 不做」四類規劃與到 2027-01-12 Product Hunt 的排程。
>
> 標記：【已驗證】實際抓到的頁面或 repo 內容；【推論】由資料推導；【建議】行動提案。所有規劃遵守免費目錄凍結（不新增免費 block 與動效庫）。

## 0. 結論先講

1. **這則推文本身就是 SunUI 該上的通路。** 1 萬次瀏覽、451 收藏、304 讚【已驗證】，收藏多於讚，代表讀者是「存起來下次用」的開發者，正是 SunUI 的買家。上一份報告說上游沒人找得到 SunUI，這類「Save this」清單就是上游。
2. **8 家裡有 5 家在搶 AI agent 介面（agent 監控、thinking loader、chat composer），沒有一家做電商與檔期頁。** 這證實 SunUI 的垂直定位是真空白，也提醒：不要被這波潮流拉去做 agent UI。
3. **「AI agent 可直接用」已經是基本配備，不再是賣點。** 8 家幾乎都有 MCP、llms.txt、shadcn registry 或 skill。SunUI 這塊做得早、做得好，但對外文案不能再拿它當主打，要改拿「檔期」與「一整頁一致」當主打。
4. **市場價格錨點落在 US$179 到 249 買斷。** SunUI 的 Pro US$129、Team US$349（5 人）偏低且結構單一。建議改成「一年更新 / 終身更新」雙軌，這同時是上一份報告指出「沒有回購」的部分解法。
5. **最值得抄的三個做法：** libraries.dev 的「複製 prompt」一鍵按鈕、beUI 的單套模板單賣（US$39 到 99）、libraries.dev 的 Studio（免費給程式碼，付費賣客製化工具）。三者分別對應 SunUI 的轉換、回購與 agency 客群。

## 2. 市場共通模式

### 2.1 已成標配（SunUI 都有，不能再當差異化）

- shadcn registry 安裝、MCP server、llms.txt、給 agent 讀的 Markdown 文件。SunUI【已驗證】有 `/mcp`（4 個工具）、`llms.txt`、`llms-full.txt`、`skills/`、`/r/`。
- 免費層 + Pro 買斷，「程式碼歸你、無限專案」。
- reduced-motion、深色模式、TypeScript。

### 2.2 正在形成的新標配（SunUI 還沒有）

| 做法 | 誰在做 | SunUI 現況 |
|---|---|---|
| 一鍵複製給 agent 的 prompt | libraries.dev、kobra | 區塊頁只有安裝指令與原始碼【已驗證】 |
| 一年更新 / 終身更新雙軌價 | beUI、BoardUI | 單一 $129 買斷 |
| 按席位的團隊價 | kobra（2 到 25 席）、beUI、BoardUI | Team 固定 5 人 $349 |
| 單套模板單賣 | beUI（$39 到 99） | 無 |
| Compare / Alternatives 頁 | Arc、affectUI、Watermelon | 無 |
| 公開的免費 / Pro 數量 | Arc、affectUI | 首頁有總數，未拆成一條清楚的對照 |
| 社會證明（安裝數、購買人數、名人推薦） | libraries.dev、Arc | 無安裝量測（上一份報告已指出） |
| Figma 檔 | BoardUI、kobra | 無 |
| 可調參數的 playground / Studio | libraries.dev | 無 |

### 2.3 價格帶

【已驗證】單人終身：kobra $199、BoardUI €199、beUI $179（Web）/ $249（Web+Mobile）、Arc $249、affectUI $249 起。年費：beUI $129、BoardUI €149。

【推論】SunUI 的 $129 剛好落在「別人的年費價」。對 agency 客群來說價格不是阻力，反而太便宜會讓人以為內容少。Founding $79 是限時限量，不受影響。

### 2.4 題材分布

【已驗證】AI agent 介面：libraries.dev、BoardUI、affectUI、kobra、Arc 都把 agent 元件放在首頁最顯眼處。通用與 SaaS 儀表板：Arc、BoardUI、Watermelon。微互動：bencho、libraries.dev。**電商、檔期、促銷：0 家。**

【推論】SunUI 在這張圖上是唯一的「賣東西的頁面」。對外第一句話應該直接寫出差異，例如：「別人做 agent 介面，SunUI 做會賣東西的頁面。」

## 3. 全方位規劃

### 3.1 優化（現有東西做得更好，成本低）

| # | 項目 | 做法 | 依據 | 工時 |
|---|---|---|---|---|
| O1 | 區塊頁加「複製給 agent」按鈕 | 一顆按鈕把安裝指令、`meta.usage`（whenToUse / watchOut）、props 摘要、對應系列的設計規則重點，組成一段 prompt。Pro 區塊附授權金鑰設定步驟 | libraries.dev、kobra | 0.5 天 |
| O2 | 首頁加免費 / Pro 數量對照條 | 「74 免費、37 Pro、28 動效庫」一條，Pro 那欄點下去到價格頁 | Arc | 0.5 天 |
| O3 | 每個 Pro 區塊一句畫面化敘述 | 改寫 `meta.description`：寫「它在頁面上做了什麼」，不寫「它是什麼元件」。四語同步 | affectUI | 1 天 |
| O4 | MCP 工具描述與 llms.txt 開頭改主打檔期 | 首句從「136 paper-feel blocks」改成「為電商檔期頁而做的 blocks」，讓 agent 在使用者說「黑五頁」時優先選中 | Watermelon 的 llms.txt「When to use」段落 | 0.5 天 |
| O5 | 安裝量測 | `app/r/[name]` 記錄次數（只計數，不存個資），達到門檻後在首頁顯示 | libraries.dev 安裝數 | 1 天 |
| O6 | Changelog 改成「新品上線才通知」訂閱 | waitlist 表單文案改成這個承諾 | BoardUI | 0.5 天 |

### 3.2 改良（結構性調整）

**I1. 價格改成雙軌 + 席位制【建議】**

| 方案 | 現在 | 建議 | 理由 |
|---|---|---|---|
| Founding | $79 終身，150 席 | 不變 | 早鳥錨點，PH 前收第一批付費者 |
| Pro | $129 買斷 | **Pro 一年更新 $129 / Pro 終身 $199** | 保留 $129 入口；終身版對齊市場錨點；一年後更新到期，是第一個「回購」理由 |
| Team | $349 / 5 人 | **按席位：3 席 $399、10 席 $899** | agency 人數不一；按席計價比固定 5 人好賣 |

注意：價格頁四語文案、`lib/site.ts` 的 `prices`、Polar 產品設定、FAQ 都要一起改。建議等 Founding 賣出第一批再切，用真實轉換率驗證，而不是現在就改。

**I2. 首頁定位語改寫【建議】**

把「agent-ready」從主標退到副標或 FAQ。主標講檔期：例如「黑五、雙 11、聖誕、過年，每一檔都要的活動頁，裝上就能開賣。」副標再補「你的 coding agent 也能直接裝」。

**I3. 價格頁加 agency 版省時計算機【建議】**

beUI 算的是「從零寫要幾小時」。SunUI 改成 agency 語言：「一年接幾檔活動 x 每檔省幾天 x 日薪」。這直接對準上一份報告定的主客群 A。

**I4. Compare 頁（SEO + 定位）【建議】**

三頁就夠：SunUI vs Magic UI / Aceternity（通用動效庫）、SunUI vs beUI / Arc（付費 blocks）、SunUI vs 自己叫 agent 寫。每頁的結論都是同一句：它們不做檔期頁，SunUI 只做這個。Watermelon 靠這類頁吃搜尋流量【已驗證】。

| # | 項目 | 內容 | 對應弱點 | 優先 |

不建議新增：React Native 版、ML 模型、agent 介面元件（理由見 3.4）。

### 3.4 不做（以及為什麼）

| 不做 | 理由 |
|---|---|
| 追 AI agent 介面題材 | 8 家有 5 家在做，紅海；會稀釋「檔期」定位 |
| 新增免費 block 或動效庫 | 11/06 凍結決定，到 PH 前不變 |
| React Native / SwiftUI | beUI 剛推 mobile，但 SunUI 的客群做的是網頁活動頁 |
| 「零相依、單檔」改寫 | affectUI 的賣點，但要重寫全部 block，成本遠大於收益；改成在區塊頁清楚列出相依即可 |
| 公開目錄 API / OpenAPI | Watermelon 的做法，對付費轉換沒有直接幫助 |

## 4. 通路：把 SunUI 送上這類清單

【已驗證】Nero 的自介是「AI tools and guides」，清單型貼文的收藏率高。【建議】

1. **準備一份給策展帳號的素材包**：一句話定位、一支 15 秒檔期頁組裝影片、一張 OG 圖、網址。前提是正式網域已部署（上一份報告列為未完成，本文未重新驗證）。
2. **SunUI 自己發「Save this」清單**：例如「黑五頁必備的 8 個 block」，每項附 GIF，最後一則放網址。格式直接沿用這則推文的成功模式。
3. **主動聯繫策展人**：私訊與寄送內容需要你本人操作，我不代發。
4. **Product Hunt 頁的截圖順序**參考 beUI：庫存數字、模板、價格雙軌、省錢計算機。
