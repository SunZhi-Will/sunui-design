# 21st.dev 參考分析

> 2026-11-08。來源：https://21st.dev/ 首頁、`/community/components` 與 40 個分類頁（hero、gallery、testimonials、shader、card、number、steps、upload-download 等）、`/pricing`。分類頁的伺服器資料含每個元件的名稱、描述、`downloads_count`、`likes_count`，共取得 1,921 個不重複元件；精選分類頁另有收藏數。
>
> 標記：【已驗證】實際看到的頁面或資料；【推論】由資料推導；【建議】行動提案。所有建議遵守免費目錄凍結（2026-11-06 起到 2027-01-12 PH 上線前，不新增免費 block 與動效庫；新免費項目只能是 Pro 場景拆出的原子）。
>
> 樣本限制：1,921 個是 40 個分類頁首屏的元件，不是全站 12K。數字用來看相對熱度，不是全站統計。

## 0. 結論先講

1. **21st.dev 是 SaaS 與 AI 落地頁的元件市集，不是 SunUI 的直接對手。** 樣本 1,921 個元件裡，跟電商有關的（checkout、cart、product card、order tracking、coupon、shop）只有 22 個（1.1%），平均下載 36 次，是全體平均 88 次的四成【已驗證】。熱門的是背景、hero、邊框光效、AI 輸入框。電商不是它的強項，也不是它的使用者在找的東西【推論】。
2. **它最熱門的「形式」可以借，內容要換成電商。** 收藏榜前段是 Scroll Morph Hero（6.4K）、Interactive Image Accordion（4.3K）、Card Fan Carousel（4.0K）、3D Gallery（3.4K）【已驗證】。這些都是「一堆圖怎麼排、怎麼捲動進場」的形式，換成商品、系列、型錄，就是 SunUI 缺的 Pro 場景。§3 列出 5 個。
3. **最熱門的視覺潮流不要追。** Liquid Glass Button（6.8K 收藏）、Liquid Metal Button（3.5K）、Aurora 背景（7.5K 下載）是第一名，但跟紙感品牌相反，而且 Magic UI、Aceternity 早就免費提供同款【推論】。
4. **它的市集欄位支援付費元件。** 元件資料裡有 `payment_url`、`pro_preview_image_url`、`is_free_for_marketplace`、`license` 欄位，也有 `/publish` 投稿入口【已驗證】。SunUI 可以把幾個免費動效庫上架到 21st 當曝光管道，連回 Pro【建議】，見 §5。
5. **它的商業模式是訂閱制加每日複製上限。** 免費每天複製 2 個，Builder 年繳每月 $6 解除上限，再往上賣 AI 額度與 PR 設計審查機器人【已驗證】。這條路建立在「程式碼不是 MIT 開放」上，SunUI 的免費層是 MIT，照搬行不通，維持一次性買斷是對的【推論】。

### 2.3 讀法【推論】

- **「圖片怎麼排」是最大的需求。** Gallery 前 8 名都破 2K 收藏，而且每一個都是捲動或拖曳驅動的排列（聚合、展開、扇形、球面、滾筒）。這是 SunUI 在電商最該補的形式，因為商品頁、系列頁、型錄的本質就是「一堆圖」。
- **數字類下載高（228）**：計數、倒數、價格跳動。SunUI 已有 `animated-number`、`count-chart`，夠用，只需小改（§4）。
- **電商冷門的原因是受眾，不是需求不存在。** 21st 的人在做 SaaS 和 AI 產品。這反過來說明 SunUI 的電商定位在這個生態裡沒有人卡位。

## 3. 可以變成 Pro 場景的 5 個方向【建議】

以下都通過四項測試（替代性、製作時間、離營收距離、展示價值）的初判，且不與現有 61 個 Pro 重複。每個都列出它借的 21st 形式、換成什麼電商內容、會用到哪些既有免費原子。

### 3.1 `lookbook-expand-hero`：系列聚合展開 hero（優先度最高）

- **借的形式**：Scroll Morph Hero（6.4K，第一名）、Scroll media expansion hero（2.6K 下載）、Hero Scrub。
- **電商版本**：首屏散落 8 到 12 張穿搭或商品小圖，往下捲時聚合成一張滿版主視覺，接著在圖上浮出 2 到 3 個熱點（品名、價格、加入購物車），再捲則縮回網格、換下一個系列。
- **跟現有的差別**：`showcase-mosaic` 是靜態牆，`launch-stage-hero`、`drop-release-hero` 是單品發表。這個是「一季多個系列」的換季首屏。
- **原子**：`hotspots`、`scroll-effects`、`product-media`、`add-to-cart-button`。
- **注意**：必須有 `prefers-reduced-motion` 退回靜態網格；手機上聚合改成單張淡入，不做長捲動劫持。

### 3.2 `collection-accordion`：館別 / 系列手風琴

- **借的形式**：Interactive Image Accordion（4.3K）、lumina interactive list（2.8K）、Cinematic List。
- **電商版本**：週年慶的「館別」或活動的「分類入口」。橫向排 4 到 6 條直幅圖，滑過或點擊的那條展開，顯示館別名、折扣區間、品項數、逛這館。手機改直向列表，點擊展開。
- **在地優勢**：百貨週年慶的樓層館別（美妝館、家電館、童裝館）在台灣、日本都是固定版型，英文庫沒有人做這個語境。
- **原子**：`sliding-tabs` 的指示器邏輯、`cjk-heading`、`countdown-banner`。可直接收進 `campaign-landing` 當一個段落。

### 3.3 `catalog-flipbook`：可購物的電子型錄 DM

- **借的形式**：3D Journal Page Carousel（左右兩疊紙頁、中間攤開、拖曳翻頁）。
- **電商版本**：超市、量販、百貨的每週 DM（日本叫チラシ）。攤開的跨頁上每個商品都是熱點，點了出現價格與加入購物車；下方縮圖列跳頁；右上角顯示「本期 DM 11/8 到 11/14」。
- **為什麼值得**：紙感品牌最自然的延伸；DM 是華語與日語市場每週都在做的東西，目前沒有 React 元件好好做過【推論】。
- **原子**：`book-3d`（已有，翻頁邏輯可沿用）、`hotspots`、`stamp`（「本週特價」印章）。

### 3.4 `shoppable-story`：可購物的編輯文章

- **借的形式**：Hover Preview（文字連結滑過出現圖片）、Interactive Hover Links。
- **電商版本**：品牌誌或選物文章，內文的商品名滑過時浮出商品小卡（手機改點擊開底部抽屜）；右側或底部有一個「本文提到的商品」托盤，讀到哪就亮到哪，可一鍵全加入購物車。
- **跟現有的差別**：`scroll-story` 是敘事捲動，沒有購物；`ask-to-shop` 是搜尋。這個補「內容電商」這一塊，代理商接案很常見。
- **原子**：`hover-card`、`scroll-story`、`toc-scrollspy`（托盤亮燈）、`add-to-cart-button`。

### 3.5 `gift-guide-fan`：送禮指南扇形牌堆

- **借的形式**：Card Fan Carousel（4.0K）、Stacked Card Image Carousel（像散落的相片，甩掉最上面一張就滑到底下）、Display Cards（2.6K 下載）。
- **電商版本**：送禮指南。上方選「送給誰」「預算」，下方商品卡扇形重排；甩掉一張表示「不要這個」，按心形就收進「候選清單」，最後一鍵分享清單或結帳。
- **季節性**：聖誕、情人節、母親節、中秋都能換皮，正好放進季節包。
- **跟現有的差別**：`card-dock` 是會員卡或禮物卡挑選，不是商品；`lineup-shelf` 是產品線並排。
- **原子**：`favorite-button`、`variant-picker` 的篩選片語、`spring-rig`（甩牌的彈簧）。

### 3.6 建議順序

1. `lookbook-expand-hero`：第一名的形式，展示價值最高，適合當 PH 上線截圖。
2. `catalog-flipbook`：最有在地差異，紙感最一致。
3. `collection-accordion`：做小，可直接併進 `campaign-landing`。
4. `shoppable-story`、`gift-guide-fan`：上線後排季節包時再做。

## 4. 不新增項目，只強化既有的 4 件事【建議】

| 既有項目 | 借的 21st 元件 | 改什麼 |
|---|---|---|
| `animated-number`（免費） | Animated Blur Number | 加一個模式：只有變動的位數做彈簧加模糊，其他位數不動。限時價格跳動時更乾淨 |
| `product-filter-grid`（Pro） | Range Slider（帶直方圖） | 價格區間下面加一條商品分布直方圖，選取範圍內的柱子著墨 |
| `scratch-card`（Pro） | Foggy Window Wipe、Ink Reveal | 加「起霧玻璃」覆蓋模式，給冬季與聖誕季節包用 |
| `loop-shader-hero` 等 shader 場景（Pro） | Shader Builder（即時調參再複製） | 預覽頁加一個調色與速度面板，調完複製 props。是銷售展示，不是新元件 |

這四件都不是新增免費項目，不違反凍結。

## 5. 21st 當作曝光管道【建議，需要你決定】

- **觀察【已驗證】**：21st 收錄整套第三方庫（Aceternity、Magic UI、Kokonut 等都有 library 頁），元件資料有 `payment_url` 與 `pro_preview_image_url`，有 `/publish` 投稿入口，並宣稱 460 萬使用者。
- **想法【推論】**：把 3 到 5 個最有辨識度的免費動效庫（例如 `spring-rig`、`brush-reveal`、`compare-slider`、`pixel-fx`）以 SunUI library 的名義上架，描述與預覽連回 sunui 站與對應的 Pro 場景。21st 的使用者不是電商受眾，所以目的是讓設計師與代理商看見品牌，不是直接賣。
- **時機**：PH 上線（2027-01-12）前兩到四週上架，讓上線當天有外部頁面可以引用。
- **要先確認的**：投稿條款對授權與轉載的要求、`payment_url` 是否開放給一般投稿者。這屬於對外發佈，要你同意才做。

## 6. 不建議做的【建議】

| 方向 | 21st 熱度 | 不做的理由 |
|---|---|---|
| Liquid Glass / Liquid Metal 按鈕 | 6.8K、3.5K 收藏 | 跟紙感相反；同款到處免費 |
| AI 聊天與輸入框 | 315 個元件 | 紅海，《八家 UI 元件庫競品分析》已排除；`ask-to-shop` 已用電商語言處理 |
| 極光、光束、漸層背景 | 前三名 2.5K 到 7.5K | `background-effects`、`gradient-backdrop` 已有；量的競爭贏不了 |
| 3D、圓形評價牆 | 3.5K、3.2K | `testimonial-wall` 已有，且旋轉評價讀起來吃力 |
| 翻牌倒數 | 數量多 | 《七個普通元件重做分析》已列為套路；`launch-countdown-wall` 已有 |
| 地球加即時觀看人數 | Globe Live Badge | 假社會證明容易變暗黑模式 |
| 訂閱制加每日複製上限 | 21st 的主模式 | SunUI 免費層是 MIT，無法限制複製；已決定一次性買斷 |
