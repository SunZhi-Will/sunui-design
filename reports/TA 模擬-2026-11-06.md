## 0. 結論先講

1. **網站在講兩個不同的產品。** 首頁標題說「優惠券、收據、印章」「不發光、不灑彩帶、不循環動畫」，但標題正下方的型錄前 24 張卡有 21 張是動效庫（aurora、glitch、粒子、游標特效）。紙感買家會覺得走錯地方，動效收藏家會覺得標題跟自己無關。兩群人都被推開。
2. **免費動效正在吃掉 Pro 的位置，而不是導流給 Pro。** 型錄依新增時間排序，第一張 Pro 卡在第 103 張；agent 搜「Black Friday hero」時，前兩名是免費的 `gradient-backdrop`、`background-effects`，Pro 的 `flash-sale-hero` 排第五。切分規劃的方案 C（免費原子帶動付費場景）目前沒有任何「場景」可以接住流量：Pro 26 個全是紙感，沒有一個用到動效。
3. **最有錢的人在最難被找到的地方。** 七位人物裡付費意願最高的是 headless 電商接案公司老闆（每月都有檔期，Team 方案毫不猶豫），但他是從「範本頁」和「整頁示範」做判斷，不是從 313 張元件卡。
4. **時間點對不上檔期。** Founding 開賣是 11-27 台北時間，剛好是黑五當天；雙 11 剩 5 天。今年要做黑五頁的人，現在就需要，而現在買不到。
5. **好消息**：agent 路徑品質很好。七組自然語言查詢（英、中、日）全部回到合理的 block，`meta.usage` 的投資是值得的。問題不在「找得到」，在「找到之後選了免費的」。

## 3. 逐一模擬

### G. 動效收藏家，Kai【模擬】

**情境**：React Bits、Magic UI、Aceternity 都收藏了。在 X 看到 `gradient-backdrop` 的 plasma shader，點進來。

**前 30 秒**：首頁標題寫優惠券和收據，他以為點錯。往下捲看到 `Text Effects · glitch`、`Background Effects · meteors`，「喔，在這裡」。一路捲到第 60 張都是他要的東西。

**會做的事**：複製 3 到 4 個效果的安裝指令，收藏網站，轉發原本那支影片。不會打開 pricing。

**內心台詞**：「效果做得比 React Bits 細，reduced motion 也有處理。但這站到底是賣什麼的？」

**破口**：
- 他是**流量**，不是客戶。方案 C 的假設是「免費越強，Pro 場景越有說服力」，但他連 Pro 的存在都沒看到（第 103 張）。
- 他帶來的分享會讓 SunUI 在 X 上被認識成「又一個動效庫」，和紙感電商的定位競爭心智。

### H. 設計工程師，Noa【模擬】

**情境**：追 Rauno、Emil Kowalski，自己也寫動效文章。看 UI 庫只看三件事：曲線、節制、一致性。

**前 30 秒**：讀到「Calm by default. No glows, no confetti, no looping motion.」，往下看到 `glitch`、`meteors`、`particles`、`dot glow`、`kaleidoscope`。

**內心台詞**：「標題說不發光，型錄第一頁就在發光。要嘛文案沒更新，要嘛作者自己也不知道要做什麼。」

**會做的事**：截兩張圖並排發一則帶點嘲諷的貼文。或者，如果打開 `add-to-cart-button`、`stamp`、`tiny-chart` 看細節，會真心讚美紙感那條線，那條線是他少見的「有觀點」的作品。

**破口**：這是**一則貼文就能定調**的人。文案和型錄的矛盾，是本輪最便宜也最危險的破口。修法不一定是刪動效，而是讓首頁說清楚有兩條線、各自的原則是什麼。

### I. Headless 電商接案公司老闆，Ray【模擬】

**情境**：6 人工作室，客戶是 Shopify Plus 品牌，用 Hydrogen 或 Next.js Commerce。每年 11 月同時跑 5 到 8 個檔期頁，報價每頁 US$3,000 起。

**前 30 秒**：Google 進來，想找「整頁範本」。首頁沒有範本入口，型錄搜尋「template」才找到 `campaign-landing`（Pro，看不到程式碼，只能看 demo）。

**判斷**：「demo 是紙感，我的客戶有自己的 VI。換色之後還好看嗎？」打開 demo 想換主題，沒有切換。翻 docs 看到「Themeable: blocks use shadcn tokens」，半信半疑。

**會問的問題**：
- 「Team 5 席，$349，一頁的報價就回本了。但我要先確定能換成客戶品牌。」
- 「有沒有 Hydrogen 的整合範例？購物車資料怎麼接？」
- 「黑五前我要交 6 頁，你們 27 號才開賣？」

**付費結論**：**會買 Team，而且不看價格**。卡點只有兩個：看不到換色後的樣子、買不到。

**破口**：
- 他是本輪最該被服務的人，卻要搜尋才找得到他要的東西。313 張卡對他是噪音。
- 他買的是「整頁 + 主題化能力 + 能接資料」，現在 Pro 只有 1 個整頁範本。

### J. 不寫程式的創業者，Mina【模擬】

**情境**：在 Lovable 做自己的保養品牌網站。她會說「做一個像這個網站的優惠券」並貼上 SunUI 網址。

**模擬流程**：
1. 工具抓網頁，看到的是 block 頁的說明文字與 iframe 預覽。iframe 裡的動畫抓不到，只能從文字猜。
2. 有些工具（v0）支援從 shadcn registry URL 匯入。若她貼的是 `/r/coupon-wallet.json`，可以直接進來；若貼的是 block 頁，就只能「照樣子重寫」。
3. 重寫出來的版本沒有撕線動畫，也沒有 reduced motion。她覺得「好像沒那麼厲害」。

**破口**：
- block 頁沒有「Open in v0」或「複製 registry URL 給 AI 工具」的按鈕。這群人增長最快，而且不會開終端機。
- 她不會付錢買授權金鑰（不知道 `.env.local` 是什麼），但會付錢給工具。長期值得看 Pro 能不能透過 v0 / Lovable 的 registry 匯入走授權，短期至少讓免費 block 能一鍵送進去。

### K. AI agent，Claude Code【已驗證 + 模擬】

用本機 SunUI MCP 的 `search_blocks` 實際跑了六組使用者可能說的話：

| 使用者說 | 前三名 | 判讀 |
|---|---|---|
| Black Friday hero section with countdown and animated background | campaign-landing（Pro）、**gradient-backdrop（免費）**、**background-effects（免費）**；flash-sale-hero 第 5 | 找得到 Pro，但 agent 傾向先裝免費的組合，因為不用金鑰 |
| SaaS pricing page with plan toggle and usage meter | pricing-cards（Pro）、quota-meter、plan-comparison（Pro） | 合理。但 `quota-meter` 描述裡有「About N images left」「check in today」，是原專案殘留，SaaS 使用者會困惑 |
| 會員集點卡 蓋章 | stamp-card（Pro）第 1 | 中文查詢很準 |
| product launch landing page with scroll animation | depth-hero、scroll-effects（皆免費）、launch-countdown-wall（Pro） | 上市頁沒有 Pro 場景可以接 |
| 新商品のティザーページ、文字アニメーション | animate-presets、animated-number、motion-principles、text-effects | 日文可搜，但全是零件，沒有「頁」 |
| explain how our product works, animated walkthrough demo | scripted-demo、step-demo、tiny-chart | 很準，而且三個都是 SunUI 獨有的強項 |

**模擬 agent 的決策**：使用者說「做一個黑五主視覺，要有倒數和會動的背景」。agent 看到 `campaign-landing` 是 Pro、沒有金鑰，下一步最合理的做法是：用免費的 `gradient-backdrop` 加免費的 `countdown-banner` 自己組。**結果是一個能用、免費、而且沒有轉換成 Pro 的頁面。**

**破口**：免費動效庫 + 免費紙感零件，已經足夠讓 agent 組出「堪用的檔期頁」。Pro 要贏，必須提供 agent 組不出來的東西（完整狀態、真實結束時間、整頁節奏、主題預設），而且要讓 agent 在說明裡講得出差別。

### L. 中國大陸前端，阿哲【模擬】

**情境**：在杭州電商公司做双 11 會場頁，技術棧 React + Tailwind，看到 zh-CN 介面很驚喜。

**卡點依序**：
1. 「双 11」只剩 5 天，會場頁早就在 9 月做完了。今年用不上，明年 9 月才會再找。
2. 公司實際用的是 Taro、uni-app 或自研低代碼，React web 頁只佔一部分。
3. 付款：Polar 走信用卡，沒有支付寶、微信支付，公司報帳要發票。
4. framer-motion 在大陸 npm 鏡像可裝，這點沒問題；但官網若放在被干擾的 CDN 或字型服務上會變慢。

**付費結論**：個人不會付，公司採購流程走不通。

**破口**：zh-CN 介面的成本已經付出去了，但轉換路徑在付款端斷掉。**zh-CN 的價值是口碑與 SEO，不是營收**，資源分配要照這個判斷，不要為它做支付整合。另外「双 11」範例文案對大陸讀者是錯的時間感（他們 9 月就做完），對台灣讀者也已過時，可改成「下一檔活動」的中性說法或依日期切換。

### M. 台灣品牌內部前端，小林【模擬】

**情境**：自架 Next.js 的服飾品牌，主管看到 SunUI 的 `coupon-wallet` 連結，要她週年慶頁用類似的。

**流程**：免費的 `coupon-wallet`、`countdown-banner`、`low-stock-indicator` 直接裝，cjk-heading 讓她很開心。想要 `flash-sale-hero`，是 Pro。

**會問的問題**：
- 「公司要開發票才能請款，Polar 的收據可以嗎？」
- 「我現在就要，27 號才開賣，能不能先用 $129 買？」pricing 頁沒寫 Pro 現在能不能買（Polar 結帳連結未設定時顯示 waitlist）。

**破口**：她已經在用免費版、已經想要 Pro、預算也有，卻只能加 waitlist。這是**已經走到漏斗最下層卻被擋下的人**。

## 4. 跨 TA 洞察

### 4.1 兩群人，一個首頁

| | 紙感電商線（I、M、L、昨天的 A、E） | 動效庫線（G、H 的一半、J） |
|---|---|---|
| 要的是 | 能上線的檔期頁、狀態完整、可換品牌 | 效果多、好看、可複製 |
| 付費意願 | 高 | 低 |
| 帶來的 | 營收 | 流量與聲量 |
| 看首頁時的感受 | 被 211 張動效卡淹沒 | 標題跟自己無關 |

同一個首頁要同時服務兩者，結果是兩邊都打折。H 會把這個矛盾公開說出來。

### 4.2 漏斗在哪裡斷

```
被看到 ──> 理解在賣什麼 ──> 找到 Pro ──> 確認適合自己 ──> 買得到
  G✓ H✓       G✗ H✗           I△ K✗        I✗(換色)        M✗ I✗(11-27)
```

- **理解**：首頁文案和型錄矛盾（G、H）。
- **找到 Pro**：第 103 張，agent 先選免費（I、K）。
- **確認適合**：沒有換色示範、整頁範本只有 1 個（I）。
- **買得到**：11-27 才開，且結帳未設定（M、I）。

昨天那輪修的是「確認適合」的一小段（授權條款放到 block 頁）。這輪發現前後兩段斷得更嚴重。

### 4.3 免費動效對 Pro 的真實效果

方案 C 的邏輯是對的（效果本身不值得收費），但它假設有「場景」接住流量。現在：

- 免費動效 211 張卡 vs Pro 場景 0 個用到動效。
- agent 拿免費動效 + 免費零件就能組出堪用的頁面。

所以在 Pro 補出動效場景之前，動效庫越多，Pro 的相對價值越低。

## 6. 這輪模擬回答不了的事

- 動效收藏家（G）有多少比例會在之後變成紙感或 Pro 的使用者。需要上線後看 `/blocks` 到 `/pricing` 的路徑資料。
- 接案公司（I）對「整頁範本」和「元件」的付費意願差距有多大。建議第 5 週訪談至少找一位 headless 接案公司。
- v0 / Lovable 目前對私有 registry 授權的支援程度。要實際查證再決定建議 6 的範圍。
- 首頁改成「精選 24 張」後，SEO 與 agent 抓取是否受影響（`/blocks` 仍保留完整清單應可避免）。
