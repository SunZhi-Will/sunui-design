# AI 光環衝擊波：拆解、優化與元件化（2026-11-09）

來源：枯白啃设计 @Kubai087 的貼文〈有物理質感的衝擊波（含扭曲與通道分離）〉，2026-11-08，以及作者附在回覆裡的完整 prompt。成品：Pro showcase 場景 `ask-ai-halo`。

## 原作在做什麼

點「Ask AI」膠囊，膠囊沉一下再彈開成輸入卡，同時一道光環從頁面底部升起掃過整頁。作者把它拆成 6 層：

1. 頁面快照：把頁面轉成圖，當後面幾層的取樣來源（建議用 Chrome 的 HTML-in-Canvas）
2. 透鏡扭曲：整個光環是一片透鏡，外側拉伸、內側壓縮
3. 通道分離：紅、藍的位移比綠多、少 8%
4. 色環：四道色環平滑過渡；淺色模式染色，深色模式 screen 加光
5. 邊緣折射：到內容區邊緣時像玻璃斜邊往外拉
6. 邊線反光：分割線與描邊在光環經過時提亮

時間曲線：半徑 `650 + 800 * (1 - 2^(-9t)) / (1 - 2^-9)`，強度 `min(1, t/0.03) * (1 - t^2.2)`，1 秒。輸入卡彈簧 `1 - exp(-8t) cos(6t)`，580ms。

## 好在哪裡

- 光環「整體當一片透鏡」，不是一圈一圈的水波，所以讀起來是空間被推開，不是水面。
- 時間曲線前快後慢、強度在慢的那段淡出，眼睛只看到「一下」，不會覺得拖。
- 淺色染色、深色加光，兩種模式各調一版色，這是很多同類效果漏掉的。
- 邊線反光讓頁面的結構參與進來，比單純一層光暈有物理感。

## 原作的問題（以實作角度看）

| 問題 | 影響 |
|---|---|
| 依賴頁面快照 | HTML-in-Canvas 只有 Chromium 旗標或新版才有；html-to-image 要幾十到幾百 ms，點下去會延遲，且圖片、字型要同源，backdrop-filter 會畫錯 |
| 快照是靜態的 | 光環跑的那一秒內頁面若有變化（游標、輸入卡本身在長大），快照與真實頁面對不上 |
| 起點與範圍寫死 650 / 800px | 換成手機寬度或很高的頁面，光環不是太早結束就是還沒掃到頂 |
| 淺色模式的通道分離 | 白底上的 1px 深色線會被拆成紅藍斷續的虛線（實測確認），文字周圍也會出現彩邊 |
| 6 層全開才成立 | 邊緣斜邊折射在 1 秒內幾乎看不到，卻要第二張邊線快照與額外運算 |

## 這個元件怎麼改

1. **不截圖，直接彎折真實 DOM**。把一張靜態的「方向場」圖（R、G 是離中心的方向，B 是距離）丟進 SVG 濾鏡，每一幀只改 `feComponentTransfer` 的 tableValues（把透鏡剖面移到目前半徑）和 `feDisplacementMap` 的 scale（強度）。沒有快照、沒有非同步、點下去當下就開始，頁面是活的，所有現代瀏覽器都支援 HTML 上的 SVG 濾鏡。方向場在閒置時先算好，尺寸改變才重算。
2. **起點與範圍自動算**。原點是觸發的元素（預設是輸入卡），在頁面下四分之一就把圓心放到頁面下方（距離取寬度的 2/3，夾在 240 到 650px），結束半徑取最遠角落再加兩個環寬，所以 375px 手機和 1440px 桌機都剛好掃完。
3. **通道分離只在深色頁開**。深色頁上分離讀起來像一絲光暈；淺色頁上它會把線條拆成彩色虛線，所以關掉。
4. **邊線反光不要第二張快照**。標了 `data-halo-line` 的元素每幀依「與光環前緣的距離」把邊框色 `color-mix` 往色環色推，結束後還原 inline 樣式。任何既有頁面都能用，文字和圖示不會亮。
5. **邊緣斜邊折射簡化為一條細光線**。只在左右與底邊畫一道 2.5px 的亮線，頂端不畫（那裡接工具列）。透鏡在最後 56px 漸弱，窗框保持直線。
6. **色環用半解析度 Canvas 2D 畫**。色環是低頻的，半解析度看不出差別，成本約四分之一；深色頁用 `mix-blend-mode: screen`，數學上等於原作的 screen 公式。
7. **只在跑的時候存在**。靜止時濾鏡移除、canvas 隱藏，零成本；分頁切走時 rAF 停止，回來就直接結束。
8. **重複觸發**：前半段的重複觸發忽略，後半段重新開始；送出問題時再發一道 0.6 強度的光環，讓光環代表「AI 收到了」，不只是開場裝飾。
9. **輸入卡**：顏色用 `light-dark()`，跟著周圍的 color-scheme，深色網站裡的淺色區塊也會拿到淺色輸入卡；Esc 關閉並把焦點還給膠囊，⌘J / Ctrl+J 切換，空白時點外面關閉，聲音與附件按鈕只有接了 handler 才出現（不放假按鈕）。
10. **減少動態**：不彎折、不反光、不分離，光在原地以一半強度 600ms 淡入淡出，輸入卡直接打開。

## 放在哪裡

免費目錄凍結到 2027-01-12，所以它是 Pro 的 showcase 場景，不是新的免費效果。網站預覽是 `preview.tsx` 展示版（不匯出 HaloStage 與 API），完整元件只由 `/r/pro/ask-ai-halo` 授權後交付。

## 已知限制

- 距離存在 8-bit 通道裡，極大的舞台（例如 2000px 以上）透鏡會出現細微的階梯；目前 1440px 以內看不出來。
- Safari 對 HTML 上的 SVG 位移濾鏡支援較慢，這次只在 Chromium 驗證過；如果效能不佳，用 `layers={{ bend: false }}` 退回只有光的版本。
- 舞台內含影片或大型 canvas 時，濾鏡會讓它們在那一秒內重新柵格化，建議關掉彎折。
