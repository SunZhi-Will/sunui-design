# card-dock 光池選卡參考分析

> 2026-11-08。來源是 Marcelo Cedeno（@marcelodesignxh）在 Threads 的貼文「The elastic effect feels so smooth!」，一支 11 秒、1280×720 的錄影（threads.com/@marcelodesignxh/post/DfcXLhUoWek）。沒有公開原始碼，所以技術拆解是逐格看錄影推回來的。這份回答四件事：錄影裡有什麼、哪一招值得帶走、怎麼元件化成能賣的商業場景、實作取捨。【已驗證】表示這次在瀏覽器實際看過；【推論】是從錄影反推；【估算】【建議】是判斷。

## 0. 結論先講

1. **招牌只有一個：一池會被卡片壓凹的光。** 卡片本身很普通（玻璃卡、晶片、線稿圖示、卡名），全部的「好滑」都來自卡片底下那團光的上緣：卡片壓著它時往下凹成一道微笑弧，卡片離開時被黏著往上拉，換卡後彈幾下才停。這是一個低阻尼彈簧，不是緩動曲線。【推論】
2. **已元件化成 Pro 場景 `card-dock`（showcase 系列）。** 商業用途改成「會員卡分級選擇」：每一級是一張卡，右側面板放價格、權益與選擇按鈕。同一個元件也能做禮物卡款式、聯名卡上市頁。符合免費凍結規則（不新增免費項目）與「Pro 賣組好的場景」。【已驗證】
3. **不照抄長相。** 原作是純黑底加紫、綠、橘、藍霓虹光，正好踩到 `PORTING.md` 3.1 的禁止清單（紫靛漸層、彩色外發光）。帶走的是「光膜彈簧」這個行為，顏色收斂成低彩度材質色（米白、玉綠、紅銅、琥珀），卡名、圖示、文案全部重做。
4. **零相依、只在動的時候畫。** 一層 Canvas 2D 畫光，卡片是 DOM（transform 與 mask 由 rAF 直接寫），沒有 WebGL，靜止時不跑任何迴圈，所以也不需要動態開關（WCAG 2.2.2 只管自動播放超過 5 秒的動態）。

## 1. 錄影逐項拆解

逐格取樣 0.2、1.5、3、4.5、5.6、6.6、7.8、9、10.5 秒。【已驗證】

| 觀察 | 怎麼做的（推論） | 判斷 |
|---|---|---|
| 目前的卡停在畫面中下，下半截被一團強光蓋住，光的上緣是下凹的弧 | 一個填色區塊，上緣是二次曲線，控制點往下拉；卡是半透明玻璃，所以光透過卡片看得到 | **帶走**，這就是招牌 |
| 弧線正下方是一條飽和色帶，再往下是白色核心，最後淡出 | 垂直漸層：飽和色 → 白 → 色 → 透明，整塊模糊 | 帶走，改成材質色 |
| 光沿著卡片兩側往下，再往外散到畫面底部兩角，邊上有兩道細亮線 | 兩條往外彎的貝茲曲線，本體模糊、邊線不模糊 | 帶走 |
| 上一張卡在上方，變暗、偏色 | 垂直排列的卡片軌道，離目前位置越遠越透明 | 帶走 |
| 換卡時目前的卡往上離開，下一張從光裡升上來（7.8 秒那格可以看到卡已經抬起、光膜還留在下面） | 卡片軌道一個彈簧，光膜的凹陷量另一個彈簧，凹陷目標跟軌道速度連動 | **帶走**，兩個彈簧是關鍵 |
| 光的顏色跟著卡換（Midnight 藍、Amethyst 紫、Verdant 綠、Ember 橘、Glacier、Graphite 灰） | 每張卡一個色，移動中插值 | 帶走，換成材質色 |
| 左上「Amethyst 02 / 06」，上方「Scroll, drag or use ↑↓」，右側一排刻度 | HTML 疊在畫布上 | 帶走，刻度改成可點的按鈕 |
| 右上「Background Dark/Light」「Material Glass/Metal」 | 展示用設定面板 | 只留 Material（做成 prop）；Light 背景不做，showcase 自帶暗色 |
| 第 6 張之後接回第 1 張 | 循環 | 做成 `loop` prop，預設關閉（見 4.3） |

為什麼有效：卡片選擇本來是很「平」的操作（點一下、換一張），這裡讓每次切換都有重量感：卡被放進光裡、光被壓凹、再彈回來。使用者感覺到的是「我把一張卡插進讀卡機」，這種實體隱喻正好對應會員卡、信用卡、禮物卡。

## 2. 和現有 block 的差別

| 現有 | 差在哪 |
|---|---|
| `coupon-wallet`（免費） | 優惠券扇形展開挑選，紙感，沒有光與彈簧 |
| `card-effects` 的 StackFan（免費） | hover 展開的卡疊，沒有選擇狀態與面板 |
| `spring-rig`（免費動效） | 線稿裡的彈簧，preset 有 card stack 但是插圖，不是選擇器 |
| `hero-billboard-carousel`（免費） | 橫向輪播，圖片封面 |
| `gift-card-designer`（Pro） | 自訂一張禮物卡的內容，不是在多張之間選 |
| `pricing-cards`、`upgrade-modal`（Pro） | 方案選擇，但是紙本價目表，沒有實體卡隱喻 |
| `glass-cube-hero`（Pro） | 同樣是 showcase 的發光物件，但它是 WebGL 展示品，card-dock 是可操作的選擇器 |

用 card、stack、spring、wallet、glow、slot、elastic 比對 `registry.json` 與 Pro registry 的名稱與說明，沒有「卡片插進光裡」的近親，最接近的就是上表。【已驗證】

四個問題（`免費與付費切分規劃-2026-11-05.md`）：
- **可替代性低**：Magic UI、Aceternity、React Bits 有卡疊與光暈，但沒有「光膜跟著卡片速度彈」這種兩個彈簧耦合的互動。
- **工時中高**：光的造型、兩個彈簧的耦合調校、滾輪與拖曳的分流、mask 讓卡片從光裡升起，約 1 天【估算】。
- **商業距離很近**：會員分級、禮物卡、聯名卡都是直接要錢的頁面。
- **展示價值高**：型錄卡片一眼就懂，捲一下就有感覺，也是 Product Hunt 影片素材。

結論：Pro，showcase 系列，排進型錄 B 組（免費沒有對應的招牌互動），放在 `cutaway-spec` 後面。

## 3. 元件設計（已實作）

```
CardDock     舞台（光 + 卡片軌道 + 標籤 + 刻度） + 面板（標題、價格、權益、選擇按鈕）
 ├ paintLight()   Canvas 2D，六層疊加：地面光、上滲光暈、本體、弧線色帶、白色核心、兩側細光
 ├ CardFace       玻璃或金屬卡面、晶片、線稿圖示、卡名、末四碼
 └ Emblem         六個內建線稿：frost、bloom、fern、flame、tide、gem
```

| prop | 作用 | 預設 |
|---|---|---|
| `cards` | `{ id, name, tint, emblem?, number?, price?, priceNote?, perks? }[]` | 必填 |
| `value`、`defaultValue`、`onValueChange` | 受控或非受控的目前卡片 id | 第一張 |
| `onChoose` | 面板的選擇按鈕 | 無 |
| `material` | glass 磨砂玻璃（光透得過來）、metal 拉絲金屬 | glass |
| `loop` | 最後一張接回第一張 | false |
| `panel` | 顯示說明面板；只要舞台時關掉（型錄卡片就是這樣用） | true |
| `eyebrow`、`title`、`description`、`children`、`locale`、`labels` | 與其他 showcase 場景一致 | |

互動與無障礙：
- 捲動（每次一張，上鎖 420 ms 擋住觸控板慣性）、上下拖曳（跟手，放開依速度決定，最多跳一張）、點上一張卡回去、點右側刻度直接跳、方向鍵與 Home / End。
- 按住目前這張卡，光膜被壓得更凹、卡片往下沉幾 px，放開彈回。
- 舞台是 `role="group"` + `aria-roledescription="carousel"`，可聚焦；卡片本身 `aria-hidden`，意義全在面板；換卡時 `role="status"` 念出「Copper，第 3 張，共 4 張」。
- 減少動態效果：卡片直接切換、光膜固定在靜止形狀、拖曳不留慣性；面板文字不做淡入。
- 離開畫面或分頁隱藏時 rAF 停止；靜止時本來就不跑。

## 4. 實作取捨

1. **兩個彈簧，不用緩動曲線。** 軌道彈簧 k=150、阻尼比 0.84（幾乎不過衝，卡片放得穩）；光膜彈簧 k=320、阻尼比 0.26（明顯彈幾下）。光膜的目標凹陷量 = 靜止凹陷 − 軌道速度 × 係數：卡往上走（速度正）時目標變小甚至變負，光被黏著往上鼓；卡往下壓時目標變大。停下來時速度歸零，目標跳回靜止值，低阻尼彈簧自然晃幾下。這就是錄影裡「elastic」的來源。每格分兩個子步積分，低幀率也穩。
2. **光用 Canvas 2D 而不是 WebGL 或 SVG。** 形狀只有一條二次曲線加兩條貝茲，Canvas 2D 的 `filter: blur()` 足夠，畫布以 0.8 倍解析度繪製（反正要模糊）。Safari 18 以前沒有 canvas filter，改成整張畫布套 CSS 模糊。SVG 的 feGaussianBlur 每格改 path 會重新柵格化整個濾鏡區，比較貴。
3. **光在卡片後面，不在前面。** 玻璃卡用半透明底加 `backdrop-filter: blur(10px)`，光透過卡片被柔化，看起來像光打在玻璃裡；金屬卡不透明，光只從兩側露出來。疊在前面用 screen 混合的話，金屬卡也會被洗白。
4. **卡片從光裡升起用 mask，不用裁切容器。** 每張卡每格寫一次 `mask-image: linear-gradient(...)`，淡出線固定在光池裡（目前這張卡底邊往下 6 px），所以下一張在軌道上升時是一截一截「浮出來」，沉回去也一樣。卡距設成卡高 + 42 px，確保靜止時下一張完全看不到。
5. **彩度拉高 1.35 倍再畫光。** 材質色彩度低，直接拿來當光色會整團發白；以灰階為軸拉高彩度後，色帶才看得出是玉綠或紅銅，但仍然不是霓虹。
6. **滾輪只在舞台上接管，`loop` 預設關。** 原作循環，但商業頁是長頁面：游標剛好停在舞台上、循環又開著，頁面就捲不下去了。關閉循環時捲到第一張或最後一張會把滾輪還給頁面。手機上舞台是 `touch-action: none`，上下拖曳換卡，這點寫進 watchOut。
7. **靜止不跑迴圈，所以沒有 Motion 開關。** 和 glass-cube-hero 不同，這裡沒有自動播放的動態；只有使用者操作後的彈簧，停穩就停 rAF。

## 5. 驗證

2026-11-08 在 Chrome（Apple Silicon）對 `localhost:3102/preview/card-dock` 實測【已驗證】：

| 項目 | 結果 |
|---|---|
| 首屏（zh-TW 與 en） | 上一張卡在上方變暗，目前的卡壓在光裡，光的上緣是下凹弧，兩側細光往外散 |
| 滾輪往下一格 | Fern → Copper，光從玉綠漸變到紅銅，卡片升起時光膜被拉平再彈回 |
| 拖曳 170 px 往上 | 落在下一張（修正前快速甩動會衝過頭一整張再彈回，已把放開速度夾在 ±4 張／秒） |
| 材質切到金屬 | 拉絲金屬卡面、斜向反光，光只從兩側與下方露出 |
| 聚焦舞台按 Home | 回到第一張 Linen，面板與 `role="status"` 同步 |
| 型錄卡片（19rem、`panel={false}`） | 舞台 22rem 高，琥珀卡在光裡，上方露出 Copper |
| 主控台 | 沒有錯誤 |
| `tsc --noEmit` | 通過 |

調校紀錄：第一版光太白，把卡片下半截整個洗掉，白色核心透明度 0.85 → 0.6 並往下移；色帶加粗到卡高 0.12；下一張卡的上緣在光池底部露出一條線，卡距由 +34 加到 +42、淡出區縮成 22 px。

未驗證：手機實機（觸控拖曳與頁面捲動的分流）、Safari 17 的 CSS 模糊備援、減少動態效果的實際畫面（程式路徑有寫，沒有在系統設定下實看）。

## 6. 後續可做【建議】

- 卡面吃一張圖（品牌自己的卡面設計），對禮物卡款式選擇最直接。要注意玻璃材質下圖會被光洗白，可能要強制 metal。
- 「插卡」完成的確認動畫：按下選擇時卡片整張沉進光裡，光亮一下再恢復，接到 `checkout-flow`。
- 錄一支 10 秒影片給 Product Hunt 素材：捲過四張卡、切一次金屬。
