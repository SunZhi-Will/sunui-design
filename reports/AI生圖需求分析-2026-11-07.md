# AI 生圖需求分析：哪些 block 該換成照片

> 2026-11-07。範圍：`apps/web/registry/free` 104 個資料夾（block 加動效庫）與 `pro` 54 個 block 的 demo。方法：掃描所有 demo 的圖片來源，再用 `public/og/blocks/*.jpg`（真實 block 截圖）做成對照表逐一檢視。生圖工具：Codex CLI 內建 `image_generation`（已驗證可無頭執行，輸出約 1448×1086 PNG）。

## 1. 結論

**整個型錄沒有任何一張點陣圖。** 所有 demo 的「照片」都是程式裡的 SVG data URI：線條圖示（鞋、杯、包）或扁平漸層風景。唯一例外是 `plush-portrait`（`public/blocks/plush-portrait/*.webp`）。

這對多數 block 是對的（輕、無版權、買家一定會換成自己的圖）。但有一類 block 的**效果本身作用在像素上**：濾鏡、顆粒、半色調、放大鏡、前後對比。拿扁平 SVG 示範，等於把效果藏起來。例如 `product-media` 寫著「點擊放大看釉面」，放大後只是一條線；`photo-looks` 的底片顆粒和調色疊在卡通山丘上幾乎看不出差別。

所以答案不是「全部換照片」，而是**只換效果需要像素的那一批**，再用一套共用道具照片撐起電商場景。

## 2. 判斷標準

一個 block 值得生圖，要符合以下任一條：

1. **效果吃像素**：濾鏡、模糊、顆粒、半色調、抖色、放大、遮罩擦除。SVG 平塗沒有紋理，效果看不出來。
2. **賣點是「看商品」**：放大、燈箱、熱點、多角度。線條圖示沒有細節可看。
3. **截圖會上 Product Hunt 或 OG 卡**：首頁卡、OG 圖是買家第一眼，照片比線稿更像「成品」。

不該生圖的：

- **畫圖本身就是設計**：pixel 系列（像素圖示）、`day-night-hero`（報告已決定用 SVG 換變數，比兩張點陣圖好）、`cutaway-spec`（剖面圖）、`recipe-glass`（分層向量）、`point-cloud`（數學點雲）。
- **純介面**：表單、按鈕、進度、結帳、優惠券等。

## 3. 清單

### Tier 1：效果吃像素，必換（第一批，已交給 Codex 生成）

| block | 現況 | 要的圖 | 張數 |
|---|---|---|---|
| `product-media` | 線條杯子，放大後還是線 | 石陶杯正面、側面、釉面微距（側面與微距以正面做 edit，保持同一個杯子） | 3 |
| `photo-looks` | 扁平山丘，濾鏡差異看不出 | 正午山丘公路風景（路燈、紅車、遠處一人）、淺底側面半身像（雙重曝光用） | 2 |
| `image-effects` | 六張同構圖的漸層山 | 潟湖、沙丘、峽灣、河谷、峽谷、灰色山峰、黃昏港口 | 7 |
| ~~`raster-image`~~ | 實測後退回 SVG（見下） | 香水瓶、陶瓶與鋼球、夜版香水、強側光靜物、山稜線 | 0 |
| `lightbox` | 灰色方塊與條紋 | 燕麥色美麗諾毛衣：正面、羅紋微距、三色疊放、背面、袖口、洗標 | 6 |
| `hotspots` | 線條夾克 | 橄欖色蠟布夾克平拍（熱點座標要對到領子、口袋、袖口，換圖後需微調 x/y） | 1 |
| `compare-slider` | SVG 草稿對 SVG 畫 | 燈塔鉛筆草稿（方形）對黃昏燈塔成品（16:9） | 2 |
| `brush-reveal` | 線稿檯燈 | 檯燈草稿與「同位置」的夜間亮燈實拍，像素對齊 | 2 |
| `depth-hero` | 扁平瓶子 | 去背砂色鋼瓶（透明 PNG），壓在大字前後才有景深 | 1 |

**2026-11-08 實測結果**：8 個 block 已換上照片。`raster-image` 試過拉高對比、去背景、裁 4:3 後仍不如原本的 SVG：半色調與點陣需要大面積的純黑純白剪影，照片的中間調全部變成雜訊，所以維持 SVG。教訓：**效果會把影像「簡化」的（點陣、ASCII、抖色），反而適合向量圖；效果會「保留或放大」細節的（放大鏡、濾鏡、顆粒、燈箱），才需要照片。**

### Tier 2：電商場景，用「共用道具庫」一次解決（第二批）

這些 block 的效果不靠像素，但截圖是線條圖示格子，看起來像線框稿。與其每個 block 各生一套，不如生**一套 12 件的共用道具**，全部 demo 共用，品牌感一致：

帆布鞋 Canvas Runner、工作外套 Chore Jacket、市集托特包、Field Watch 38 mm、錄音室耳機、石陶杯、檯燈、保溫瓶、花瓶、帽子、筆記本、羊毛大衣。每件兩個版本：灰紙背景 4:5、去背透明 PNG。

會用到的 block：`product-gallery`、`product-filter-grid`、`flash-sale-product-card`、`showcase-mosaic`、`drop-release-hero`、`campaign-landing`、`infinite-canvas`、`orbit-gallery`、`ribbon-carousel`、`launch-stage-hero`、`hero-billboard-carousel`（海報可用場景照）。

### Tier 3：可選

- `book-3d`：封面目前是 SVG 插畫，品質已可接受；若要更像實體書可生一張封面畫。
- `spine-shelf`：書背是色塊加字，換照片反而難讀，不建議。
- `testimonial-marquee`、`avatar-stack`：頭像。**不建議生成人臉**，AI 人臉是最明顯的 AI 訊號，用字母頭像或抽象圖案就好。

## 4. 風險與規則

1. **AI 感**：先前報告指出 AI 生成主圖本身就是「AI 網站」訊號。對策是統一的藝術指導：靜物商品攝影、暖灰無縫紙背景、左上柔光、真實接觸陰影、低飽和、輕微底片顆粒；不要人臉、不要手、不要文字、不要 HDR 光暈。風景用 35mm 紀實風格，不要奇幻色。
2. **重量**：data URI 零請求，照片會增加流量。規格：WebP、最寬 1200 px、品質 75 左右，目標每張 80 KB 以下，`loading="lazy"`。
3. **安裝不受影響**：`registry.json` 只出貨元件檔，`demo.tsx` 不出貨。圖片放 `apps/web/public/blocks/<name>/`，沿用 `plush-portrait` 的做法，只影響型錄網站。
4. **凍結規則**：這是既有 block 的 demo 品質，不是新增 block，不違反 2026-11-06 的免費型錄凍結；而且直接改善 PH 截圖與 OG 卡，屬於上線工作。
5. **深色模式**：淺灰背景的商品照在深色頁面會很亮。道具庫的去背版可以解決大部分；有背景的照片接受亮塊，或另生中灰背景版。
6. **熱點與對齊**：`hotspots` 座標、`brush-reveal` 和 `compare-slider` 的對位都依賴構圖，生成後要人工核對，必要時用 edit 模式重生。
7. **Pro 圖片**：Pro 原始碼不進公開 repo，但 demo 圖片放在 `public/` 會進公開 repo。圖片不是程式碼，可以接受；若要嚴格分開，Pro 的圖放 Pro repo 再於建置時複製。

## 5. 流程

1. Codex 生成 PNG（`codex exec` 內建生圖，edit 模式保持同一物件的一致性）。
2. 人工挑圖，轉 WebP 放進 `public/blocks/<name>/`。
3. 改 demo：把 SVG 產生函式換成圖片路徑，保留 alt 文案（四語系不變）。
4. 重新產生該 block 的 OG 截圖與首頁卡。

## 6. 第二輪盤點（2026-11-08）

> 方法：把剩下 149 個 block 的 OG 截圖做成 7 張對照表逐一看，再對照原始碼與 `PORTING.md`。

### 6.1 先講一個限制：`PORTING.md` 3.4 已經規定佔位圖的樣子

> 示意圖用中性色塊與線條（`bg-muted`、1.5px 線）。

所以第一輪說的「Tier 2 共用道具庫」不是單純補圖，而是**改一條設計規則**。看完全部截圖後，我認為這條規則大部分是對的：在 `back-to-top`、`cookie-consent`、`store-header`、`side-panel`、`sliding-tabs`、`dialog-sheet` 這類 block 裡，商品圖只是背景，主角是捲動按鈕、同意視窗、頁首、側欄。灰色色塊讓視線留在主角身上，換成照片反而搶戲。這一類**維持灰塊**。

判斷標準因此收斂成一句：**圖片是不是這個 block 的主角。** 是主角才換照片，是背景就留色塊或線稿。

### 6.2 第二批：建議做（7 個）

| block | 為什麼 | 圖從哪來 | 新生成 |
|---|---|---|---|
| `card-effects` | 和舊的 image-effects 是同一組六張漸層山（`demoArt` 是複製的），tilt、spotlight、glare 都疊在扁平圖上 | 直接重用 `image-effects` 六張風景 | 0 |
| `type-motion` | `text-mask` 是用字形挖洞看圖，SVG 條紋海看不出是「圖」 | 重用 `image-effects/lagoon` 或 `harbor` | 0 |
| `jobs-tray` | 這個 block 本身就在示範「AI 生圖任務列」，結果格卻是灰色色塊。提示詞已寫好：火車窗邊人像、睡在書堆上的貓、蕨類墨彩 | 照 demo 裡的提示詞生成，結果就是真的生成結果 | 3 到 4 |
| `step-demo` | 示範「描述 → 生成 → 發布」一張 1200 × 628 活動圖，結尾只有虛線框 | 生一張「秋季茶葉 85 折」的活動橫幅（不放文字，文字由元件疊上） | 1 |
| `variant-picker` | 切顏色是這個 block 的主角，現在切了顏色圖不變 | 同一件 T 恤、外套用 edit 模式各生 3 到 4 色 | 6 到 8 |
| `hero-billboard-carousel` | 深色電影感活動看板，主圖是一個線條花瓶，像沒放圖 | 陶藝工作室夜間、拉坯手部以外的器物靜物各一張 | 3 到 4 |
| `upsell-drawer` | 主圖佔畫面一半，是唯一的視覺焦點 | 檯燈（可重用 brush-reveal 的點燈照）| 0 到 1 |

合計約 15 張新圖，其中兩個 block 完全不用生。

**2026-11-08 實作結果**：`card-effects`、`type-motion`、`jobs-tray`、`step-demo`、`hero-billboard-carousel`、`upsell-drawer`（Pro，另生灰色檯燈與托特包，杯子與水瓶重用）已換上。`jobs-tray` 另外補了生成中的低解析度預覽與完成後的成品圖（原本完成時顯示的是參考圖）。`variant-picker` 的 7 張圖已生成但**暫緩接上**：另一個 session 正在改寫這個 block，上衣顏色已從 oat/navy/moss/rust 改成 white/fog/black/moss，等它完成後再依新色重生。

### 6.3 Pro 場景：建議做（Pro repo，另外處理）

主圖是焦點、截圖會直接拿去賣的：`drop-release-hero`、`launch-stage-hero`、`flash-sale-hero`、`campaign-landing`、`product-gallery`、`showcase-mosaic`、`curve-rail-hero`。這幾個才值得用「共用道具庫」（帆布鞋、耳機、托特包、手錶、外套、杯子），每件做去背版，約 8 到 10 件。理由是 Pro 的截圖就是商品頁，線稿會讓人以為是線框稿；而免費 block 的灰塊不會影響購買。

### 6.4 不建議做

| 類別 | block | 理由 |
|---|---|---|
| 小縮圖 | `quantity-stepper`、`toast-stack`、`morph-menu`、`cart-drawer`、`checkout-button`、`free-shipping-progress`、`low-stock-indicator`、`favorite-button`、`add-to-cart-button`、`physics-cart-jar` | 40 px 的列表縮圖，照片縮到這麼小只剩色塊，線稿反而更好認 |
| 背景佔位 | `back-to-top`、`cookie-consent`、`store-header`、`side-panel`、`sliding-tabs`、`dialog-sheet`、`skeleton-set` | 見 6.1，主角不是圖 |
| 分層向量 | `camera-moves`、`scroll-effects`、`scene-transitions` | 視差與鏡頭運動靠多個 SVG 圖層，換成單張照片就沒有深度；要做得拆成去背圖層，成本高、收益低 |
| 程序生成 | `background-effects`、`gradient-backdrop`、`loop-shader-hero`、`shader-campaign-banner`、`point-cloud`、`svg-effects` | 本來就是程式畫的 |
| 點陣化 | `raster-image`、`pixel-*` | 第一輪已實測，見 5 節 |
| 人臉 | `testimonial-*`、`avatar-stack`、`person-chip` | `PORTING.md` 3.4 規定頭像用縮寫，AI 人臉也是最明顯的 AI 訊號 |
| 已經夠好 | `book-3d`、`spine-shelf`、`day-night-hero`、`cloth-curtain`、`glass-cube-hero` | 插畫是刻意的風格 |

### 6.5 網站層級

- 換過圖的 8 個 block（加上第二批）要重產 OG 截圖與首頁卡，PH 上線前一次做完即可。
