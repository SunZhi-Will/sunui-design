# TA 模擬

> 2026-11-05。以下是**模擬**，不是訪談資料。人物依 `SunUI 商業化深度規劃.md` 的定位推演，用來找出假設中的破口，真正的驗證仍要靠第 5 週的 3 至 5 位買家訪談。
>
> 模擬當下的產品狀態：免費 58 個 block（product 21、story 3、showcase 3、其他 31），Pro 29 個，創始會員 $79 終身，Pro $129、Team $349，Pro 經私有 shadcn registry 與授權金鑰安裝，FAQ 已寫明可用於客戶專案。

## 1. 六位 TA

| # | 人物 | 一句話 | 會不會付錢 |
|---|---|---|---|
| A | 台灣接案前端（Next.js） | 雙 11 前兩週接到三個檔期頁 | $79 會，$129 猶豫 |
| B | 英文市場 indie hacker | 做 SaaS 和它的發表頁 | 看到一支 X 影片才會 |
| C | Agent 優先的開發者 | 從不開文件站，全靠 Claude Code / Cursor | 會，前提是先被找到 |

## 2. 逐一模擬

### A. 台灣接案前端，小周

**情境**：客戶要「有活動感」的週年慶頁，預算不高，時程兩週。用 Next.js + Tailwind，偶爾接 headless Shopify。

**第一反應**：「countdown-banner、coupon-wallet、low-stock-indicator、reservation-timer，這幾個剛好是我每次都要重寫的。」繁中排版處理好，是別家沒有的。

**會問的問題**：
- 「可以用在客戶案子嗎？」答案在 pricing FAQ 第三題，但他是在 block 頁決定要不要買，不會往下捲到 FAQ。
- 「$129 換算四千多台幣，一個案子的利潤會被吃掉一塊。」$79 創始價剛好落在衝動購買線內。
- 「客戶不一定是 React。」台灣中小電商多在 SHOPLINE、Cyberbiz、91APP、Shopify Liquid 上，這些他用不到。

**破口**：台灣能用 SunUI 的接案者，其實只限於做 headless 或自架 Next.js 的那一群，比「台灣電商」小得多。這和規劃書「台灣是口碑起點、營收靠英文市場」的判斷一致，但要避免把台灣行銷資源花在用不了 React 的人身上。

### B. 英文市場 indie hacker，Maya

**情境**：自己做一個訂閱制 SaaS，要發表頁、定價頁、帳單頁。已經用過 Magic UI 和 shadcnblocks。

**第一反應**：「紙感很好看，但跟我的品牌合嗎？」接著發現 quota-meter、redeem-key-input、checkout-steps、payment-status-banner 是 SaaS 帳單流程用得到的，這比 hero 特效有用。

**會問的問題**：
- 「shadcnblocks 有幾千個，你們 87 個？」她用數量比，不是用專精比。
- 「預設是紙感，我能換成我的色票嗎？」若 demo 只展示紙感，她會以為只能紙感。
- 「有沒有 30 秒內看得懂的影片？」她是在 X 上被一支 demo 打中才點進來的。

**破口**：「commerce and campaign」的定位對她來說太窄，她會跳過。但 SunUI 實際上覆蓋 SaaS 帳單流程。建議在型錄加一個「SaaS billing」的使用情境入口，用既有 block 組，不需要做新的。

### C. Agent 優先的開發者，Leo

**情境**：在 Claude Code 裡說「幫我的特賣頁加一個倒數和庫存緊張提示」。他從不看文件站。

**模擬流程**：
1. Agent 先用 shadcn MCP 搜尋。SunUI 只有在官方索引裡、或專案 `components.json` 已註冊 `@sunui` 時才會出現。**沒註冊過的人，第一步就找不到 SunUI。**
2. 若找到，`meta.usage.whenToUse` 寫得清楚，agent 會選 countdown-banner 而不是自己刻。這一段已經做對。
3. 碰到 Pro block 時沒金鑰，agent 拿到 401 與說明，轉述給他。他的反應是：「好，多少錢？連結給我。」這裡如果訊息有直接的價格與購買連結，轉換率最高。

**破口**：漏斗的最上層（被 agent 第一次發現）完全依賴官方 registry 索引。這是單點依賴，值得確認 SunUI 已進索引、健康分數如何，以及 SunUI MCP 或 skill 有沒有其他被發現的路徑。

### D. DTC 品牌行銷，Ivy

**情境**：20 人的保養品牌，網站在 Shopify。老闆說下一檔要做得「像 Apple 那樣會動」。

**第一反應**：「cookie-consent 和 store-header 好精緻，我想要這個。」但她無法安裝任何東西。

**她會做的事**：截圖或貼連結給合作的接案工程師（也就是 A 或 B）。

**破口**：她不是買家，是**需求的源頭**。如果 block 頁的連結貼出去時預覽圖好看、打開就能看到動態 demo、不用登入，她就是免費的業務。值得檢查 block 單頁的 OG 圖與手機版 demo 體驗。

### E. 電商公司 tech lead，陳經理

**情境**：10 人前端團隊，自有設計系統，要求 WCAG AA、reduced-motion、bundle 大小可控。採購要發票。

**第一反應**：「reduced-motion 和鍵盤操作預設處理好，這是加分。shadcn 複製進 repo，就算作者消失我們也還有原始碼，風險可以接受。」

**會問的問題**：
- 「一個人維護？兩年後還在嗎？」複製進 repo 能回答一半，另一半要靠公開的 changelog 與更新頻率。
- 「能吃我們的 design token 嗎？」紙感是 SunUI 的賣點，但對他是要拆掉的東西。
- 「Team 是 5 人，我們 10 人怎麼算？」
- 「MoR 開的收據公司可以報帳嗎？」

**破口**：他要的是「動效與行為」，不是「紙感外觀」。若 block 的視覺與行為綁得太緊，他會選擇自己刻。主題化能力與「Team 以上怎麼買」需要有答案。

### F. 日本前端工程師，佐藤

**情境**：做日本市場的活動頁，對禁則處理、全形標點、字重很敏感。

**第一反應**：「cjk-heading 的標點擠壓有做，少見。」接著會讀 ja 介面文案。

**會問的問題**：
- 「這段日文是機翻嗎？」不自然的敬語或用詞，會直接降低對產品細節的信任。
- 「直書有嗎？」
- 「價格是美元，日本的消費稅怎麼處理？」MoR 會處理，但頁面要說出來。

**破口**：在日本市場，文案品質就是產品品質的代理指標。ja 文案值得找母語者看一次，成本低、影響大。

## 3. 跨 TA 結論

| # | 發現 | 影響誰 | 建議 | 成本 |
|---|---|---|---|---|
| 1 | 「接案可用」藏在 pricing FAQ 底部，但購買決定發生在 block 頁 | A、B、E | 在 Pro block 頁與付費牆旁放一行「可用於客戶專案」 | 低 |
| 2 | 被 agent 第一次發現，幾乎只靠官方 registry 索引 | C | 確認已進索引與健康分數；401 訊息直接附價格與連結 | 低 |
| 3 | 紙感是吸引點，也是 B、E 的顧慮 | B、E | 每個 block 的 demo 加一個「換成你的品牌色」切換或範例 | 中 |
| 4 | 數量比較會輸，但 SaaS 帳單流程其實已覆蓋 | B | 型錄加「SaaS billing」情境入口，用既有 block 組 | 低 |
| 5 | 不寫程式的人是需求源頭，靠分享連結轉介 | D → A、B | 檢查 block 單頁 OG 圖與手機 demo | 低 |
| 6 | 台灣多數電商不在 React 上 | A、D | 台灣行銷鎖定 headless / Next.js 接案者，不追一般電商 | 無 |
| 7 | 一人維護的信任問題 | E | 公開 changelog 與更新頻率；寫出 Team 以上的購買方式 | 低 |
| 8 | ja 文案品質會被當成產品品質 | F | 請母語者校一次 ja 文案 | 低 |

最值得先做的是 1、2、5：成本最低，而且都卡在「已經有興趣的人為什麼沒有走到下一步」。

### 執行紀錄（2026-11-05）

- **1 已做**：Pro block 頁的付費框加一行「一次付費 $129，不是訂閱。自己的專案與客戶案子都能用」，四語。價格抽到 `lib/site.ts` 的 `prices`，pricing 頁共用。
- **2 部分完成**：沒金鑰時的 401 訊息、agent 的 Pro 設定說明與 SunUI skill 都加上方案說明（價格、Team、可接案、創始價開賣中時附上）。**查證結果：SunUI 目前不在 shadcn 官方索引裡**（`ui.shadcn.com/r/registries.json` 共 539 個 registry，沒有 sunui）。申請收錄要有正式網域，並向 shadcn 送 PR，尚未進行。
- **5 已做**：每個 block 單頁有自己的分享圖（名稱、描述、適用情境、FREE / PRO 標籤）與 og / twitter meta。375px 手機版 demo 沒有橫向捲動。

## 4. 這份模擬沒辦法回答的事

- 真實付費意願與價格敏感度，尤其台灣與日本。
- 紙感在英文市場是加分還是減分。
- Agent 在實際對話中，是否真的會從 shadcn 索引選到 SunUI。

這三點建議列進第 5 週訪談題目。
