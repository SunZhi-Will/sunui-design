# 微互動牆：展示與實際的落差，深度分析與實作

> 日期：2026-11-22
> 起因：使用者看完首頁的微互動牆後問：「你有這些元件嗎？有這些顏色嗎？」答案是一半一半。這份報告把落差逐項列出，決定每一項是「做成真的」、「標清楚」還是「拿掉」，並記錄這次的實作。
> 前一份：`reports/微互動同屏牆深度分析-2026-11-22.md`（牆的由來、Pro 規劃在第 8 節）。

## 1. 結論

1. **落差有三種**：顏色是頁面指定的、情境卡不是元件、漸層頭像不是元件功能。
2. **顏色其實做得到，只是沒說、也不一致。** 大部分區塊讀 `--sunui-spot`，而且是讀最近一層祖先的值，所以買家在包住區塊的元素上設不同的值，就能做到每格不同色。問題在 `micro-interactions` 讀的是 `--primary`，跟其他區塊不一致，買家要換色就得連 shadcn 的主色一起改。**修正：`micro-interactions` 改成跟其他區塊一樣讀 `--sunui-spot`，沒設時退回 `--primary`。** 首頁牆加一個切換，讓人看到「主題預設」和「品牌色」兩種樣子，並寫出那一行 CSS。
3. **漸層頭像做成 `avatar-stack` 的真功能**：`fallback="gradient"`，沒有照片的人依 id 算出固定的漸層，每次都一樣。不是新區塊，型錄數量不變。
4. **情境卡往 Pro 做，這次先做兩張離營收最近的**：`pricing-cards` 加 `layout="single"`（單張方案卡），新 Pro 區塊 `team-invite`（邀請成員）。首頁牆上這兩格的名稱改成連到 Pro 區塊並標 Pro。`feature-wall` 場景照使用者確認的 12-02 到 12-05 做，這次不動。
5. **剩下的情境（專注模式的通知、商品縮圖、發文鈕、說明文字）維持首頁展示**，首頁說明已經寫「每一格裡在動的是真的免費區塊」，不再誇大。

## 2. 落差逐項

| 牆上看到的 | 實際 | 處理 |
|---|---|---|
| 開關、勾選、送出、完成勾是藍色或綠色 | 這幾個在 `micro-interactions`，讀 `--primary`。牆上是連 `--primary` 一起改才變色 | **修**：改讀 `--sunui-spot`，退回 `--primary` |
| 愛心紅、星星金、字數圓環橘、通知紅、驗證碼藍 | 這些區塊本來就讀 `--sunui-spot`，牆上逐格設定 | **標清楚**：牆下方加切換與一行 CSS 說明 |
| 彩色漸層頭像 | `avatar-stack` 只會顯示照片或縮寫，漸層是牆自己產生的小圖 | **做成功能**：`fallback="gradient"` |
| 方案卡（功能清單、升級鈕、省 20%） | Pro `pricing-cards` 只有多方案價目表 | **做**：`layout="single"` |
| 分享卡（輸入 email、邀請、頭像多一顆） | 沒有 | **做**：Pro `team-invite` |
| 專注模式收起通知、商品縮圖、發布鈕、說明文字 | 首頁展示 | **維持**，等 `feature-wall` 的情境卡庫（12-02） |
| 評分卡 | Pro `review-request` 已經有同樣的組成 | 首頁那格的名稱改連 `review-request` |

## 3. 為什麼顏色要統一讀 `--sunui-spot`

| 讀 `--primary` 的問題 | 讀 `--sunui-spot` 的好處 |
|---|---|
| shadcn 的按鈕、連結、焦點環全部讀 `--primary`，想讓開關變藍就得讓整頁的主要按鈕一起變藍 | 只影響 SunUI 區塊的「選中、進度、優惠」部位，主題其他地方不動 |
| 跟 SunUI 其他 70 多個區塊的規則不同，agent 讀 `get_design_rules` 學到的是 `--sunui-spot` | 一條規則用到底 |

退回值仍是 `--primary`，沒設 `--sunui-spot` 的買家看到的跟以前完全一樣，向下相容。

## 4. 實作範圍

| 項目 | repo | 內容 |
|---|---|---|
| `micro-interactions` | 公開 | 選中、進度、徽章、按鈕實心的 `primary` 改成 `var(--sunui-spot,var(--primary))`，前景色同理；粒子預設色也跟著 |
| `avatar-stack` | 公開 | `fallback?: "initials" \| "gradient"`，漸層由 id 雜湊挑兩個色相，同一個人每次一樣；縮寫仍給螢幕閱讀器 |
| 首頁牆 | 公開 | 牆下方「主題預設 / 品牌色」切換加一行 CSS；評分、方案、邀請三格的名稱連到 Pro 區塊並標 Pro（Pro 資料夾不在時退回免費區塊名稱）；頭像改用 `fallback="gradient"`，不再自己產生圖片 |
| `pricing-cards` | Pro | `layout="single"`：一張卡、月年切換、價格滾動、年繳時出現省多少與只在年繳才有的功能（`yearlyOnly`），淡入不跳版面 |
| `team-invite` | Pro | 新區塊：頭像列與人數、可一次貼多個 email 並變成籤、角色選擇、邀請中、成功時新頭像滑進頭像列、格式錯誤與重複提示、待接受名單可撤回；四語；鍵盤與螢幕閱讀器 |

## 5. 不做

1. 不在這次做 `feature-wall`，維持 12-02 到 12-05。
2. 不把首頁牆的每格顏色拿掉。顏色是真的做得到的事，拿掉反而低估了區塊。
3. 不為專注模式、發文框另開區塊（四問過不了，見前一份報告 8.1）。
