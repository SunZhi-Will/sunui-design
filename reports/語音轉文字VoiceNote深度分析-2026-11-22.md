# 語音轉文字（voice-note）深度分析與實作

日期：2026-11-22
參考：uberdesigner.ai「voice to text」Ferro 外觀（`/t/voice-to-text/ferro`）
結論：做成 Pro block `voice-note`，不是免費品（免費型錄凍結中，這也不是 Pro 場景抽出的原子）。

## 1. 參考到底在做什麼（逐格看過影片）

10 秒一圈的動態研究，一張語音訊息卡把自己變成逐字稿。用 `currentTime` 逐格停在 0.6、1.8、2.3、2.55、2.75、3.0、3.6、4.3、7.6、8.3、9.2 秒截圖。

| 時間 | 畫面 |
|---|---|
| 0 ~ 1.2s | 卡片進場。左邊圓形播放鈕，中間 32 根圓頭波形條，右邊 `0:00 / 0:14`（等寬字）和圓形「Tт」轉文字鈕。卡片上方一行小字：寄件人 · voice note · 時間 |
| 1.2 ~ 2.2s | 游標點播放。播放頭左邊的條變亮，播放頭附近幾根條上下彈跳，右邊維持暗 |
| 2.3 ~ 2.6s | 游標點轉文字。每一根波形條**往左下拉長成單字大小的骨架膠囊**，一邊滑到逐字稿的位置，一邊從條狀變成圓角長條 |
| 2.6 ~ 3.0s | 骨架依序**解析成真正的字**（模糊轉清楚），卡片同時長高到三行字，波形位置換成一條細進度軌 |
| 3.0 ~ 3.6s | 「EN · transcript」小籤從下面浮上來 |
| 3.6 ~ 8.2s | 卡拉 OK 式朗讀：正在念的字落在一塊淡色底板上，**底板沿著行滑動**，念過的字變實色，沒念的字是淡灰 |
| 8.3s | 播完，暫停鈕變回播放 |
| 8.5 ~ 9.5s | 逐字倒放：字折回波形條（從尾端開始），卡片縮回一行，淡出 |

招牌只有一個：**同一批幾何貫穿三個狀態**。波形條、骨架、單字是同一組物件，數量、位置一路對得上，不是交叉淡化換一張圖。這正好就是 DESIGN.md 第 5 節第 6 條「連續性」要的東西。

## 2. 什麼值得拿，什麼不拿

拿：

1. 條 → 骨架 → 字 的三段變形（核心）。
2. 卡片外框跟著內容變高，外框不換（`gentle` 彈簧）。
3. 一塊會滑的朗讀底板，而不是每個字各自亮起。只有一個物件在動，眼睛跟得住。
4. 播放頭附近的條會彈，遠處不動。動態只發生在「現在」的位置。
5. 收合時倒放回波形，讓「轉文字」是可逆的檢視切換，不是一次性結果。

不拿：

1. Ferro 的黑底拉絲金屬舞台與白色播放鈕：SunUI 讀主題 token，播放鈕用 `bg-primary`，深淺模式自動成立。
2. 自動循環播放：block 本身只回應使用者；循環交給 demo 的 `useDemoAutoplay` 演一次。
3. 藍色朗讀字直接改成品牌專色 `--sunui-spot`，這正是「目前進度」的用途。
4. 1080 × 1080 舞台、`window.__render(t)` 錄影接口：那是他們拍影片用的，元件不需要。
5. 「Tт」字形圖示改成 inline SVG（三條長短不一的線），線寬 1.5、跟 `currentColor`。

## 3. 為什麼是 Pro

四項檢查（`reports/免費與付費切分規劃-2026-11-05.md`）：

- 可替代性：市面上的語音訊息元件只有播放與波形；條變字的連續變形找不到現成的。
- 製作時間：要量測每個字的位置、把 32 根條對應到 N 個字、雙向彈簧動畫、真實音訊同步，至少一天。
- 離營收的距離：AI 產品、客服收件匣、聊天 App、會議記錄都用得到，買家就是做 SaaS 的人。
- 展示價值：預覽一眼就看得懂，適合放首頁卡片與宣傳影片。

另外，SunUI 定位已從「只做電商」改成「質感與動態」（2026-11-18），AI 介面是自然的延伸。

## 4. 實作設計

### API

```tsx
<VoiceNote
  sender="Mira Okafor"
  sentAt="09:41"
  duration={14}
  src="/notes/mira.m4a"          // 可省略：沒有音訊時用內部時鐘模擬播放
  transcript="Landed early, ..."  // 字串，或 [{ text, start }] 帶時間戳
  onTranscribe={async () => api.transcribe(id)} // 可省略：按下才去拿逐字稿
  language="EN"
  peaks={[...]}                   // 可省略：0~1 的波形，數量不限，會重採樣成 32 根
/>
```

### 三個狀態

`wave`（波形）→ `morph`（變形中）→ `text`（逐字稿），反向同樣經過 `morph`。

- 進入 `text` 前先把逐字稿以透明狀態排版一次，量出每個字的方框（相對卡片內容區）。
- 第 i 個字對應第 `round(i × 31 / (n − 1))` 根條。字比條多時多個字共用一根條的起點，看起來是一根條裂成幾段；字比條少時多出來的條直接淡出。
- 每個字一個「飛行物」：從條的方框出發，彈簧移動到字的方框，同時圓角從膠囊變 4px，顏色從條色變骨架色；依序錯開 18ms。
- 飛行物到位後，字本身從 `blur(4px)`、透明淡入，飛行物退場。
- 收合時反過來：字淡出，飛行物從字的位置飛回條，最後換回真的波形。

### 播放

- 有 `src` 就用 `<audio>`，每一幀讀 `currentTime`；沒有就用 `performance.now()` 累計的時鐘，讓沒有音檔的展示也能動。
- 單字時間：有 `start` 就用；沒有就依字元數把總長度分配給每個字。
- 波形與進度軌都可以點擊、拖曳跳轉，是 `role="slider"`，方向鍵一次跳 1 秒，Home/End 到頭尾。

### 質感規則對照

- 卡片 `bg-card rounded-2xl`，e2 陰影（帶 1px 邊線），深色模式靠頂邊高光。
- 播放鈕凸起：`bg-primary` 加頂邊內高光；轉文字鈕是凹面 `bg-muted`。
- 所有按鈕 `whileTap scale 0.97` + `snappy`。
- 時間 `font-mono tabular-nums`。
- 朗讀底板用品牌專色 14% 的深淺，字用專色；念過的字 `text-foreground`，未念的 `text-muted-foreground/70`。
- 減少動態：沒有飛行物、沒有條彈跳，狀態直接切換，底板直接跳到目前的字，資訊不遺失。
