# secki.dev 參考分析

> 2026-11-07。來源：https://secki.dev/（實際抓取首頁 HTML，解析內嵌的 `DATA` 物件，共 332 筆連結）。
>
> 標記：【已驗證】實際抓到的頁面或資料；【推論】由資料推導；【建議】行動提案。所有建議遵守免費目錄凍結（2026-11-06 起到 2027-01-12 PH 上線前，不新增免費 block 與動效庫；新免費項目只能是 Pro 場景拆出的原子）。

## 0. 結論先講

1. **secki 不是元件庫，是「設計工程師工具」的策展目錄。** 332 筆手選連結、10 個分類、7 個主題合輯，無帳號、無廣告，只有一個每週 US$29 的贊助欄位【已驗證】。它本身沒有可以直接搬的元件原始碼，價值在三層：通路、競品地圖、少數可轉成 Pro 場景原子的點子。
2. **最大價值是通路，不是元件。** Components 分類收了 66 個元件庫，Aceternity、Cult UI、React Bits、beUI、Arc、Kobra、AffectUI 都在，**SunUI 不在**【已驗證】。投稿只要一封 email（hello@secki.dev），贊助一週 US$29，是 PH 上線週成本最低的曝光位置之一【建議】。
3. **66 個元件庫裡沒有一個做電商或檔期頁。** 分布集中在「動畫 React blocks」「AI agent / chat UI」「React Native」「圖表儀表板」四類【已驗證，見 §2】。這是第二份獨立資料證實 SunUI 垂直定位的空白（第一份是《八家 UI 元件庫競品分析》）。
4. **可轉成元件的點子不多，但有 5 個跟 Pro 場景對得上**：檔期 OG 分享圖、優惠券 QR / 條碼、滾動播放影片揭幕、價格滾輪數字、節慶紋樣與配色包（§4）。其餘特效類（border beam、liquid metal、粒子、shader 漸層）SunUI 已有對應或屬於別家主場，不追。
5. **secki 網站本身的 UX 有 4 個值得 SunUI 目錄站借**：無帳號收藏、主題合輯、程序化抖色縮圖、「Updated Nov 5」新鮮度標記（§5）。

## 2. 競品地圖：66 個元件庫的分布

【已驗證】把 Components 分類 66 筆逐一歸類（一筆可屬多類）：

| 類型 | 代表 | 約略筆數 |
|---|---|---|
| 動畫 React blocks / 特效 | Aceternity、Animate UI、Cult UI、React Bits、Motion-Primitives、Sona、Originkit、useLayouts、Atelier、Amicro、beUI Pro、Fancy Components | 15+ |
| AI agent / chat / MCP UI | Beautiful UI、AffectUI、AICSS、HextaUI、Halaska、Thinking Orbs、MCPCN | 8 |
| 通用設計系統 | shadcn/ui、Base UI、HeroUI、Mantine、Zendesk Garden、Astryx（Meta） | 6 |
| React Native / Expo | beUI、ExpoKit、Reacticx、Native Cook、quattro4maggi、Expo Glass Tabs | 6 |
| 圖表儀表板 | Bklit、BoardUI、Evil Charts | 3 |
| 「XxxCN」單一用途 registry | EditorCN、FrameCN、MDXCN、OGImageCN、PDFCN、TermCN、8bitcn、sensory-ui（介面音效） | 8 |
| 電商 / 檔期 / 行銷活動 | **0** | 0 |

【推論】兩個觀察：

- **「XxxCN」命名的單一用途 registry 是新趨勢**：一個 shadcn registry 只解一件事（PDF、OG 圖、終端機、音效）。SunUI 對外可以用同樣的語言自我定位：「commerce + campaign 的 shadcn registry」，讓讀者一秒歸類。這不需要改名，只要首頁副標與投稿描述這樣寫。
- **AI agent UI 正在擠爆**：8 筆加上 Skills 分類 30 筆。再次確認不要被拉去做 agent UI。

## 4. 可轉成元件的點子（對應 Pro 場景）

篩選規則：符合 option C（特效庫免費、Pro 賣組合場景）與凍結規則，只收「能當 Pro 場景零件，或能從 Pro 場景拆成免費原子」的東西。

| secki 收錄 | 原本是什麼 | 轉成 SunUI 的什麼 | 歸屬【建議】 |
|---|---|---|---|
| OGImageCN | OG 分享圖的 React 元件 | **檔期 OG 分享圖模板**：每個 Pro 檔期包（雙 11、黑五、新年）附一張同風格的 `opengraph-image.tsx`，分享到 LINE / X 時的卡片跟頁面一致 | Pro：加進 `campaign-landing`、`black-friday-weekend`、`festival-banner` 的檔案清單，不是新 block。「一整頁一致」延伸到「連分享卡都一致」 |
| qrcode.reactiive.io | QR code 產生器 | **優惠券 QR / 條碼原子**：門市核銷用，紙感印刷風（墨點、略錯位） | Pro 場景原子：先長在 `coupon-claim-card`、`stamp-card`、`peel-sticker-coupon` 裡；若之後要拆成免費，符合「Pro 場景拆出的原子」例外 |
| ScrollyVideo.js | 滾動驅動影片播放 | **產品揭幕段落**：滾動時影片逐格轉動商品（新品發表、開箱） | Pro：併進 `launch-stage-hero` 或 `drop-release-hero` 當一種模式；SunUI 已有 `scroll-story`、`scroll-timeline` 可當底層 |
| slot-text（textmotion.dev） | 文字逐字滾入定位 | **價格老虎機數字**：限時特價從原價滾到特價 | 已有 `animated-number`、`type-motion`。【推論】不必新增，只要確認 `flash-sale-hero` 與 `flash-sale-product-card` 的價格動畫用的是逐位滾動而非淡入。若不是，改那兩個 Pro 場景 |
| JAPANESE GRADIENTS、Pattern Craft、Repper、Nucleo pattern | 漸層與無縫紋樣產生器 | **節慶配色與紋樣包**：新年（朱紅金）、櫻花季、雙 11、聖誕的 token 與 SVG 紋樣，餵給 `gift-box-reveal` 包裝紙、`festival-banner` 底紋 | Pro：季節包的「素材層」。這正是 memory 裡記的 agency + 季節包方向，素材可以用 `theme-picker` 的 token 機制切換 |
| sensory-ui | shadcn 的語意化介面音效 | 加入購物車、刮刮樂刮開、轉盤停止的音效 | 【推論】暫不做。兩份報告都看到音效層（kobra、bencho、sensory-ui），但它是通用層，做了也是跟別家比。若要做，只在 Pro 互動場景（`prize-wheel`、`scratch-card`、`physics-cart-jar`）裡選配 |
| PDFCN | 生成 PDF 的元件 | 收據 / 電子發票 PDF | 不做。`receipt-printer` 已覆蓋視覺，PDF 屬後端產出，離「動態區塊」太遠 |

明確不追的：Border Beam、Liquid metal、Thinking Orbs、Hologram / 粒子類、Shader Gradient、Glimm 轉場、各種 ASCII 工具。原因：SunUI 已有 `card-effects`、`point-cloud`、`pixel-fx`、`gradient-backdrop`、`scene-transitions`、`shader-campaign-banner`，再做就是在別家主場比特效變體，違反 option C。

## 5. secki 網站 UX 可借給 SunUI 目錄站

【已驗證】SunUI 目錄站目前沒有收藏或合輯功能（`apps/web` 內 `localStorage` 只用在主題）。

| secki 做法 | 為什麼有效 | 套到 SunUI【建議】 | 優先 |
|---|---|---|---|
| **無帳號收藏**（Saved 分頁，存在瀏覽器） | 「no accounts」本身是信任行；收藏讓人回訪 | 區塊卡片加書籤，Saved 分頁可一鍵「複製全部安裝指令」或「複製給 agent 的 prompt」，等於讓訪客自己組一頁的 block 清單 | 高：直接接上已有的 copy-prompt 按鈕 |
| **主題合輯**（7 個，每個一句策展說明） | 把 332 筆變成「我現在要做 X，從這 9 個開始」 | 依檔期與頁型做合輯：「雙 11 一整頁」「結帳流程」「新品發表」「會員集點」。每個合輯列出 free + Pro block，Pro 的放後面，自然帶出升級 | 高：不加任何 block，只是重組現有 104 個，且是 PH 前最好用的導覽 |
| **程序化抖色縮圖**（`scene()` + `dither`，以名稱 hash 決定圖案） | 沒有 OG 圖的連結也不會破圖，且整站視覺一致 | SunUI 已有 `pixel-fx`、`raster-image`。可用在 Pro 預覽被鎖時的佔位圖，或 `product-filter-grid` 商品缺圖時的 fallback | 中 |
| **新鮮度標記**「Updated Nov 5」 | 目錄類網站最怕看起來沒在維護 | 首頁加「Updated {最近一次 block 更新日期}」，從 git 或 registry 取值 | 中：成本很低 |
| 「Try」標籤 chip 帶入搜尋 | 降低空白搜尋框的壓力 | 首頁或 `/blocks` 加：coupon / countdown / checkout / flash sale / gift | 低 |
| 「140 with a source post」，每筆標推薦者 | 社會證明而且可追溯 | 等 PH 後有使用者分享再做（「Used by」或推文牆） | PH 後 |
| 單一贊助欄位 | 不破壞乾淨感的變現 | SunUI 不賣廣告，但可以用同樣的格位放「本週 Pro 場景」 | 低 |
