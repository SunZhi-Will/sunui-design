# Pro 場景規劃：立體書門市導覽 popup-store-tour（2026-11-22）

前情：`reports/立體書房間PopupBook深度分析-2026-11-22.md`。那份拆解了 @duckwhocodes 的立體書影片，並在 `/preview/popup-book-study` 做出折紙引擎（書脊、對角線折的地板、長高的家具、彈簧、拖曳）。使用者 2026-11-22 同意排進 Pro 場景清單。這份是規劃，尚未動工。

## 1. 為什麼放 Pro

| 四問 | 判斷 | 偏向 |
|---|---|---|
| 可替代性 | shadcn、Magic UI、React Bits、Aceternity 都沒有立體書；網路上的仿作多半是影片或 Three.js，不能換品牌色、不能點 | Pro |
| 工時 | 兩天以上：折紙幾何、排序、熱點對到 3D 家具、窄螢幕、無障礙文字層、四語文案、插圖畫法 | Pro |
| 商業距離 | 近：門市、快閃店、展場、百貨樓層導覽，都是電商與檔期的周邊 | Pro |
| 展示力 | 很高，翻頁那一下就是一支短片；適合 PH 素材 | 行銷素材 |

四題都偏 Pro。另外，它是免費型錄凍結期間最乾淨的路：先當 Pro 場景，之後要開放時抽出折紙引擎當原子（凍結規則第一條例外）。

## 2. 組成

- 新 Pro block：`registry/pro/popup-store-tour/`，series `craft`，interaction `drag`，categories `commerce`、`campaign`、`navigation`。
- `registryDependencies` 只有 `utils`（遵守「shadcn 耦合要薄」）。沒有新的 npm 依賴：不用 framer-motion，彈簧自己寫（樣張已經是）。
- 匯出兩層：
  - `PopupBook`：引擎本身，受控 `index`，吃 `rooms` 資料。可以拿去做導覽、方案比較、品牌故事。
  - `PopupStoreTour`：`PopupBook` 加上門市情境：分區名、營業資訊、家具上的商品熱點與價格卡、區域清單。

## 3. 規格

### 書（沿用樣張，補齊）

- N 區要 N + 1 頁；打開的那一區兩頁成 90 度，其餘以 `gap`（預設 14 度）疊在兩側。
- 地板沿對角線折，解析解（見分析報告 3.3）；家具 72 度以上才長高，各自 delay。
- 彈簧 stiffness 170、damping 22；拖曳 220px 一區、頭尾 1/3 阻力、放開帶慣性。
- 新增 `loop` 選項：整圈模式（原作回覆裡最多人要的），頁面平均分佈 360 度，最後一區接回第一區。

### 門市情境

| 元素 | 行為 |
|---|---|
| 區域名 | 書下方，上下位移 + 模糊切換，300ms |
| 區域清單 | 書旁邊（桌面）或書下方的橫向膠囊（窄螢幕），點了翻到該區；目前區用品牌專色 |
| 商品熱點 | 掛在家具上（3D 座標投影到螢幕），房間完全打開後才淡入；點開小價格卡：品名、售價、原價、加入購物車（callback，支援 async，完成有結果記號）。做法參考 `catalog-flipbook` |
| 營業資訊 | 每區可選一行（例：「咖啡區 10:00 到 21:00」） |
| 空區 | 家具還沒搬進來的空房間，可當「即將開幕」或 404 |

### 插圖

- 每一區的牆、地板、家具是資料（`rooms` 陣列），不是寫死的元件；demo 附 4 到 5 區的門市範例（入口、試衣間、咖啡區、櫃台、倉庫取貨）。
- 配色（2026-11-22 定案）：**物件本色**。三套並排比較後選了 C，規則已寫進 `DESIGN.md`「插圖場景的物件本色」與 `lib/agent/guidelines.ts`：填色用像素圖示的 pigments，以材質角色命名，線條仍是品牌專色。光固定左上，線寬不隨投影變化，不做手繪抖動線。
- 插圖細節要比樣張再細一級（窗簾、葉形、層架上的商品），維持幾何線條。

### 鍵盤與無障礙

- 書是 `role="group"` + `aria-roledescription="carousel"`，左右鍵、Home、End；區域清單是一般按鈕列。
- SVG 是 `aria-hidden`；每一區有一段隱藏的文字描述與熱點清單（螢幕閱讀器看到的是「咖啡區：3 件商品」加上可操作的商品按鈕），熱點本身是真的 `<button>`。
- 區域切換用 `aria-live="polite"` 報區名。
- reduced motion：翻頁瞬間切換、家具直接站好，資訊不缺。

### 窄螢幕

- 375px：書縮到容器寬，區域清單變成可橫向捲動的膠囊列，價格卡改成底部面板。
- 觸控拖曳用 `touch-action: pan-y`，不擋頁面直向捲動。

### API 草稿

```ts
interface PopupRoom {
  id: string;
  name: string;
  left: ReactNode;   // 畫面左邊那面牆，x = W 是牆角
  right: ReactNode;  // 畫面右邊那面牆，x = 0 是牆角
  floor: ReactNode;
  items: PopupItem[];
  hotspots?: PopupHotspot[];
  note?: string;     // 營業資訊等
}

interface PopupHotspot {
  id: string;
  at: [s: number, t: number, z: number]; // 房間座標
  product: { name: string; price: string; compareAt?: string; image?: string };
}

interface PopupStoreTourProps {
  rooms: PopupRoom[];
  index?: number;               // 受控；不給就自己管
  onIndexChange?: (i: number) => void;
  loop?: boolean;
  gap?: number;
  onAddToCart?: (hotspotId: string) => void | Promise<void>;
  locale?: string;
  labels?: Partial<PopupStoreTourLabels>;
}
```

## 5. 驗收

- 翻頁時地板是被牆帶著攤平（不是淡入），家具不穿過正在轉的牆。
- 熱點只在房間完全打開後出現，位置跟著家具；拖曳中不能點到熱點。
- 只用鍵盤可以切區、打開價格卡、加入購物車。
- Light 與 Dark、換 `--sunui-spot`、375px、reduced motion 都看過。
- Pro 原始碼不出現在公開 repo、頁面、MCP 或 `llms-full.txt`。目前的樣張 `/preview/popup-book-study` 在公開 repo 裡，**P0 搬家後要刪掉或換成不含引擎的版本**，這件事在上架前必須完成。
