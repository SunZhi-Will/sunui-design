## 2. 對 SunUI 有用的五個觀察

1. **好 prompt 的禁止清單跟 SunUI 設計規則幾乎一樣。** twoclipping、rossaxbt、threeaus 這幾則爆紅 prompt 都寫「no glow, no particles, no gradients, springs, one accent」。也就是說，SunUI 的「去 AI 感」方向正是這批創作者在影片裡追求的質感，可以直接當行銷說法：「Opus 5.5 影片裡最好看的那種動態，SunUI 做成可以上線的元件」。
2. **「一個形狀、不剪接」就是我們的連續性規則。** button → loader → check → toast 同一個容器變形，跟 DESIGN.md 的 Continuity 一條完全對得上。差別在於他們做成影片，我們做成真的會回應點擊的元件。
3. **最常見的商務場景是「上市」與「商品內部」。** 上市影片 128 則；拆解類（手錶、鏡頭、引擎、e-bike x-ray）是 3D 互動裡被分享最多的題目。商品頁需要「裡面有什麼」，但目前 SunUI 沒有這種場景。
4. **AI 對話式購物成為新的上市畫面。** ultimaxbt 那則（輸入「想吃辣的、脆的」→ 送出鍵變成炒鍋 → 結果卡片爆出 → 最佳選擇飛回對話）是整份清單裡最接近電商的 prompt。商店開始放「問一句話找商品」的輸入框，這是新需求，SunUI 也沒有。
5. **沒有人做可近用性。** 0 則提到 reduced motion、鍵盤或螢幕報讀。這是 SunUI 跟「拿 prompt 自己生」的真正差距：生出來的是影片，不是能上線的元件。

## 3. 不採用的部分

- 光暈、Apple Intelligence 式彩虹邊框、粒子爆發、閃白、震屏：違反設計規則。
- 游標跟隨的 spotlight reveal（e-bike x-ray header 原版）：設計規則列為避免，手機上也沒作用。改成可拖、可按鍵的切面線（見下）。
- 手遊「高光時刻」開寶箱：已有 gift-box-reveal、scratch-card、prize-wheel，且慶祝效果不符合紙感。
- 純影片類（Remotion 上市影片、音樂 MV）：不是元件，SunUI 不做影片工具。

## 5. 這次做的三個 Pro 場景

### cutaway-spec：切面規格
- 來源：e-bike x-ray header、Time Undone 手錶、各種「take it apart」3D。
- SunUI 版：商品外觀上有一條垂直切面線，拖動（或用方向鍵）把線往右推，線左邊露出內部結構圖。每個零件的標註在切面線經過時一條一條出現，標註寫的是零件名與規格數字（tabular-nums）。
- 規則對應：沒有光暈、沒有游標裝飾；動作只回應拖曳；減少動態效果時切面直接跳到位置；所有規格同時有一份文字清單給螢幕報讀器。

### ask-to-shop：一句話找商品
- 來源：ultimaxbt 食物點餐上市片、「one shape, never cut」。
- SunUI 版：紙面輸入框，按建議詞或自己打字，送出鍵在原地變成一條「正在找」的細線，同一個容器長高變成三張結果卡，最符合的一張有「最符合」標籤；按「加入購物車」後那張卡縮回輸入框下方，變成一行已加入的結果。
- 規則對應：同一個容器變形，不換頁、不交叉淡入；結果由你傳入的 `onSearch` 回傳（元件不假裝有 AI）；沒有彩虹光暈。

### recipe-glass：配方杯
- 來源：Ror_Fly 調酒配方解說（空杯到完成，材料與份量一層層倒入）。
- SunUI 版：左邊材料清單，右邊一個線稿杯子。按「下一步」或點清單任一項，該材料以墨色深淺倒進杯子成為一層，份量數字捲動出現；最後一步完成時底下出現一行結果。適合飲品、咖啡、調酒組合包與食譜商品頁。
- 規則對應：只回應按鍵；每層用墨色深淺區分，不用顏色；減少動態效果時層直接出現。
