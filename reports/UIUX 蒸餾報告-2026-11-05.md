> 2026-11-05。範圍：`/Applications/Projects` 下約 40 個有 UI 的專案（Next.js、Chrome 擴充、Electron、遊戲、Flutter），分五組唯讀審查。

## 1. 你的設計 DNA（跨專案一致的部分）

這些規則在新專案（Schedary、usermeld、spliteat-web、ComfyUI、Vtuber、GoogleAIStudioTeach、autolens、voxcpm）裡反覆出現，幾乎可以直接當成 SunUI 的第二份設計語言。

### 視覺

| 項目 | 你的做法 | 出處 |
|---|---|---|
| 底色 | Zinc 中性灰，暗色優先（`#09090B` / `#111113`，邊線 white 6 至 10%） | Schedary、spliteat、autolens、VideoAligner |
| 強調色 | **全站只有一個**，只用在「今天、焦點、資料強調、主要動作」 | 幾乎所有新專案 |
| 強調色家族 | 金／琥珀：Synvize `#D4AF37`、autolens `#eab308`、WTMA `#c9a063`、voxcpm `#A9781A`；SaaS 線用靛藍 `#4F46E5` | 跨 10+ 專案 |
| 狀態色 | **顏色只放在 1.5 到 6px 的點上**，文字維持中性，一排狀態不會變彩虹 | Synvize StatusBadge、ComfyUI status-dot、usermeld app-chip、spliteat person chip、voxcpm job badge |
| 身分色 | 依 id 雜湊出色相，只上在點或頭像 | spliteat、dinner-split、usermeld、Schedary store-cover、IF CharacterGlyph |
| 字體 | Geist / Inter + PingFang TC / Noto Sans TC；故事類加 Noto Serif TC | 全部 |
| CJK 字距 | `tracking-tight` 收斂到 -0.01em，不用英文式緊字距 | Schedary、spliteat、Vtuber |
| 數字 | 金額、計時、計數一律 `tabular-nums`，右對齊 | 全部 |
| Eyebrow | 10 到 11px 全大寫、字距 0.12 至 0.2em | 全部 |
| 圓角 | 控制項 6 到 8px、卡片 10 到 14px、選單 12px、膠囊 999px；遊戲面 2 到 4px | autolens token 最完整 |

### 動態

- 緩動曲線只有一族 expo-out：`cubic-bezier(0.23,1,0.32,1)`、`(0.16,1,0.3,1)`、`(0.22,1,0.36,1)`。
- 時長階梯 90 / 160 / 240 / 360 / 560ms，阻擋操作的動畫不超過 360ms。
- 只動 transform、opacity、blur；能寫 CSS 變數就不走 React state。
- 進入視窗才播、播一次、提供重播；離開畫面或分頁隱藏就暫停。
- `prefers-reduced-motion` 一定給「最終畫面」，伺服器端也先渲染最終畫面。
- 指標效果（tilt、magnetic）只在精準指標裝置啟用。

### UX 原則（最值得變成產品賣點的部分）

1. **用復原取代確認**：刪除不跳 confirm，改顯示可復原的 toast（spliteat `useUndoable`）。
2. **輕量破壞性確認**：真的要確認時，用「2.5 秒內再按一次」或把按鈕文字寫成結果（WTMA 快速讀檔、usermeld ActionButton）。
3. **把「為什麼」寫在畫面上**：輸出降速原因（autolens 匯出）、AI 建議附信心度與影響（DirectorPanel）、排班指派附理由（Schedary）、方案卡列出「自動會做什麼」。
4. **誠實文案**：不做假稀缺、不顯示 0（報名人數 0 改「開放報名中」）、付款 webhook 延遲就老實說「確認中」。
5. **一個主要動作**：工具介面收斂成單一輸入與送出，其餘收進「+」。
6. **空狀態提供「載入範例」**，錯誤狀態不露原始例外並提供重試。
7. 鍵盤與螢幕閱讀器完全對等：`aria-pressed`、`aria-live` 合計、數字鍵快捷鍵、gamepad。

## 2. 與現行 SunUI DESIGN.md 的關係

SunUI 目前定位是「紙感電商」（紙、朱紅印章、票根）。你的專案 DNA 是「暗色 Zinc + 單一金色強調 + 點狀狀態」。兩者**不衝突但不同**：

- 共通：單一強調色、tabular-nums、font-mono 序號、反對漸層光暈、reduced motion 完整、狀態結果要有明確物件（印章 ↔ 點）。
- 差異：SunUI 用紙與朱紅、淺色優先；你的產品用 Zinc 與金、暗色優先、彈簧以外還大量用 CSS expo-out。

所以候選元件分三類標記：

- **紙**：可以直接用紙感電商語言做，放進現有 free/pro。
- **改**：功能適合，但要從暗色產品語言轉成紙感。
- **線**：屬於「產品介面 / 敘事遊戲」語言，硬塞紙感會失真，適合另開一條 SunUI 子系列。
