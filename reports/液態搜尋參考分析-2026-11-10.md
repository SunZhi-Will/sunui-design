# 液態搜尋參考分析（2026-11-10）

參考：Soybean°（@soybonjour）2026-11-08 在 X 發布的 UI/UX 探索「liquid search」，12.6 秒影片（1746×1200）。
這是同一位作者「filter navigation bar」的續作，畫面是同一組「16 results / Tennis / Cycling」。
本文件只描述觀察到的互動與動態，實作全部自寫。成品不是新 block，而是 Pro block `ink-filter-bar` 的選用功能 `searchable`（`apps/web/registry/pro/ink-filter-bar/`）。

## 2. 為什麼好用

1. **搜尋不多佔一列**。收起時只是一顆圓鈕，放在結果數旁邊；打開後跟結果條是同一個物件。使用者看得到「我輸入的字」和「它造成的結果數」在同一條線上。
2. **跟篩選列是同一套語言**。篩選是墨灌進標籤、併入結果條；搜尋是墨從另一邊倒進結果條。兩種縮小結果的方式都長在結果條上，規則只要學一次。
3. **圖示說明狀態**。放大鏡代表「可以搜尋」，打開後變成持續轉動的環，代表「正在聽你輸入」；收起時環收回放大鏡。圖示也是收起按鈕，不用再多放一顆關閉鈕。
4. **懸停預告**。小墨包探出去又縮回，告訴使用者這顆圓鈕會往右展開，而且只在懸停時發生。
5. **逆向對稱**。收起就是倒帶：墨倒回去、環變回放大鏡、結果條回位。

## 3. 技術拆解與做法

| 效果 | 參考的樣子 | SunUI 做法 |
|---|---|---|
| 墨倒出去、推著結果條 | 搜尋墨一路頂著結果條，中間不露紙 | 搜尋墨是一條左錨定的圓角矩形，寬度從 40 長到「搜尋欄寬 + 40」，伸進結果條底下一截。結果條、標籤在開合時改用跟墨同一條曲線（inkEase，0.46 秒開、0.4 秒收），算式保證前緣與結果條的距離最多 12px，goo 濾鏡會把這段黏起來 |
| 前緣起伏 | 倒墨時邊緣是波浪 | 搜尋墨單獨套一層 `feTurbulence` + `feDisplacementMap`，位移強度由動態值驅動，從 0 升到 9 再落回 0；靜止時是 0，邊緣完全平整，不會在結束時跳一下 |
| 收起時的墨頸 | 最後一刻拉出細頸才斷 | 搜尋墨與結果條都在原本的 goo 層裡，縮回時自然出現，不用另外做 |
| 懸停小墨包 | 圓鈕右側鼓出柔軟的一塊 | 圓鈕裡藏一顆半徑 0.32 倍的墨珠，懸停時往右 11px；goo 讓它長成平滑的鼓包。收起時兩者距離 12px，比 goo 能黏起來的距離大，靜止時不會跟結果條連在一起 |
| 圖示變形 | 放大鏡 → 菱形 → 四角星 → 四瓣環 | 四個形狀都用同一組參數角度各取 48 個點（鏡片圓、菱形、星形線、四瓣玫瑰線），逐點內插後用 Catmull-Rom 轉成貝茲曲線，角會自然變圓。把手是另一條線，用 pathLength 縮掉 |
| 跑動的亮段 | 一段亮筆畫沿環跑，拖著淡尾巴 | 同一條路徑畫三次：底影（不透明度 0.22）、尾巴（0.45）、亮段。路徑長度設為 1，用 dasharray 與 dashoffset 讓亮段跑；尾巴比亮段長 0.2、接在後面 |
| 提示字輪播 | 新字從下滑入、舊字往上離開 | 搜尋欄空白時每 2.6 秒換一句，`AnimatePresence` 搭 gentle 彈簧 |

### 一個參考沒有、我們加的地方

參考裡環在打開期間一直轉，看起來像「正在載入」。真實產品裡這會誤導，所以加了 `searching`：平常 2.2 秒一圈，慢慢轉，代表「在聽」；結果載入中時 0.85 秒一圈。切換速度時從目前位置接著轉，不跳格。

### 時序

- 打開：墨伸長 460ms（同時結果條與標籤被推開、前緣起伏 600ms）→ 圖示變形 500ms → 300ms 起輸入框淡入 → 440ms 起亮段縮成 30% 開始跑
- 收起：亮段補滿 160ms、輸入框 80ms 淡出 → 墨縮回 400ms，圖示 460ms 變回放大鏡

## 4. 和 SunUI 規範的對照

- 顏色：沿用篩選列的墨 `#171717 / #ededed`，提示字與 × 用淡墨 `#a3a3a3 / #737373`。沒有漸層、光暈、彩色。
- 「不用模糊」：goo 與起伏濾鏡輸出的邊緣都是銳利的。參考影片的懸停墨包看得出模糊漸層，我們用 goo 做成銳利的鼓包。
- 鍵盤與讀屏：圓鈕是有 `aria-expanded` 的按鈕，標籤在「打開搜尋 / 收起搜尋」之間切換；輸入框有 `aria-label`；Esc 收起並把焦點還給圓鈕；× 有字時清除，空白時收起。動畫提示字是 `aria-hidden`。
- 使用者主動打開才自動聚焦輸入框，外部受控打開時不搶焦點。
- reduced motion：寬度與位置直接跳到終點，圖示直接換成四瓣環且不轉，提示字不輪播。
- 四種語言：en、zh-TW、zh-CN、ja 的按鈕標籤與提示字都內建，可用 `labels` 覆寫。

## 5. 為什麼不是新 block

- 免費型錄 2026-11-06 起凍結，不能加新的免費項目。
- 搜尋墨要和結果條在同一個 goo 層才能黏起來；拆成另一個 block 就得把整條結果條、標籤排版再寫一次。參考本身也是同一個畫面的續作。
- 所以做成 `ink-filter-bar` 的選用功能：`searchable`、`query / defaultQuery / onQueryChange`、`searchOpen / defaultSearchOpen / onSearchOpenChange`、`searching`、`searchWidth`。不開時行為和之前完全一樣。

## 6. 網站展示版（preview.tsx）的範圍

展示版會編譯成公開 chunk，只放簡化示範：墨倒進結果條與倒回、圖示直接換成轉動的半圓環、固定提示字。逐格變形、亮段與尾巴、前緣起伏、懸停墨珠、提示字輪播、Esc 收起只在授權版，展示版底下的說明文字也寫了這些差異。

## 7. 驗證紀錄

- 在 Chrome 用 1/12 倍慢速逐格看開與收（同時放慢 requestAnimationFrame 與 Web Animations），Light 與 Dark。
- 修正一個問題：第一版結果條用 gentle 彈簧移動，起步比墨快，開到一半兩者之間露出一段紙。改成開合時跟墨用同一條曲線後，前緣一路頂著結果條，和參考一致。
- 輸入「lamp」結果剩 3 筆、數字捲動；搜尋開著時點篩選照常併入；Esc 收起後焦點在圓鈕上。
- 懸停：墨珠位置從 20 移到 31，鼓包出現，沒有跟結果條黏在一起。
- 網站展示版（`/preview/ink-filter-bar`，zh-TW）：打開、輸入「桌」剩 3 筆。
- `npm run typecheck -w @sunui-design/web` 通過。
