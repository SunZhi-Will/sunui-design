## [0.0.55] - 2026-11-04

### Added
- First npm release of `@sunui-design/countdown-banner`
- `@sunui-design/react` now exports Card, FileUpload, CountdownBanner and SidePanel
- Card: new variants, themes, loading modes and dark mode (2026-02 enhancement)

### Fixed
- `@sunui-design/react` 0.0.54 shipped without any JavaScript; it now builds into `dist`
- `@sunui-design/card` now ships its TypeScript declarations
- Next.js 15.3.8 security upgrade
